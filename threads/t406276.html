DDon't Dream It's OverJun 19 2008, 12:17 AM
You need to download each official firmware from 3.01-3.xx (I don't know how high the 3.95 popsloader can go, the 3.90 one can only go up to 3.71).Then you need to dump the PSAR, using this app:http://dl.qj.net/RSPsar-Dumper-v3.3-now-wi...16779/catid/151Once you have dumped each firmware, all you'll need are these two files: pops.prx, popsman.prx from each.Rename them pops301.prx popsman301.prx and so on until you have each one.So the pops.prx you got from 3.11, would be named pops311.prx. The pops.prx you got from 3.71, would be pops371.prx. etc.Here are the popsloader files for 3.80. Just take the .prx files, don't use the popsloader plugin that comes with it because it is for the M33 firmwares, not the GEN firmwares:http://www.mininova.org/tor/1214938
