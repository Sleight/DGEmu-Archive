Here are some tips to searching for addresses:(sorry if there was similar stuff before)Normally current HP values can be searched for immediately. Make it change again and you can be sure which one is real.Some may be backward-oriented. Example: your current hp is 450/1000 . The value may be 550 instead of 450. This is kind of rare though.Protection addresses may be there to prevent hacking. A good example would be the zenny address from MMBN4. Trying to hack it alone results in a permanent 0 zeny.Make sure you are using the correct data size. For values that are from 0-255, use 8-bit. 256 - 65535, use 16 bit. Any larger, use 32-bit.Compare type is useful for eliminating unwanted addresses. Use equal to search for a certain value. Hope this helps!
