To start a new topic in this section, please follow the following guide.

If your upload does respect the guidelines, chances are it will never get approved.

Topic Title:
Contains the full name of the game with the region between parenthesis.
(J) - Japan (NTSC)
(U) - North America (NTSC)
(E) - Europe (PAL)

Example: Epic Game (U)

File Guidelines:
- You may use any file hosting service.
- Do not use intermediate advertisement sites such a Linkbucks.
- Do not post a link to another website's download page or download link.
- All games should be compressed as a zip or rar file, and should be split with 800MB parts.
- Do not post password protected files.

Post Format:
<Game Cover> - An image of the front game cover.

<Amount of Discs> - The number of discs required for the game.

<Special Notes> - If applicable, any special notes regarding the game

<Download Links> - The download links to your file. If it has multiple parts, put them on separate lines.The brackets are BBCodes. Simply remove the "START " and replace "END " with "/".


<Game Cover>[END IMG]
Discs: <Amount of Discs>
Notes: <Special Notes>
<Download Links>[END CODE]
[END CENTER]
