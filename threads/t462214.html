Try ComicBookDS: http://filetrip.net/f3580-Comic-Book-DS.htmlFirst, download the manga, and put the images in a zip or rar file (or files, it's up to you).Then use PictoDS to convert these rar/zip file into CBDS file(s): http://filetrip.net/f4095-PictoDS--Comic-Converter.htmlThen open up the cbds files using ComicBookDS.
