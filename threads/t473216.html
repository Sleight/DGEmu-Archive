You can do this:1. Download VBAlink if you don't have it yet. ( http://www.dgemu.com/forums/index.php?/topic/198827-how-to-use-visualboyadvance-and-visualboyadvancelink/ )If you are switching from a normal VBA, do this to open your save file>Open your main game in it (Load ROM, Go to File>Import>Battery file (Select your SAV file). 2. Create 2 copies of the ROM you want to use (If it's Fire red, Make 2 copies) and name the copies something different. Play them USING VBALink till the second city (or wherever you can trade). Once you're there, Use VBAlink to trade the starters to your main game.Just open 2 windows of VBAlink, Import the battery files if necessary and go to the top floor of the pokecenter, the lady on the far right. Select Trade and you should be able to enter the ROOM and trade.And YES, You do need to be able to save. If you can't save using the ingame save (1M subcircuit board error) then you'd better fix it before going on.
