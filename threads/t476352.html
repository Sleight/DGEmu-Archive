[font="Arial"]DOWNLOADING[/font]
[font="Arial"]When you find a game that you think is cool click on it. It should bring you to a page with info on it such as how big the file is. If you look near the top right corner over the ad about buying DP it should say details, reviews, screenshot then download. When you click on it it should say open save or cancel. If it doesn’t check to see if you have enough DP points. Click save and another window should pop up and hit save again. Another window should pop up with a loading bar for from 4 minutes to 60 minutes when it is done loading and the winos are gone find a video on you tube on how to get the games to your ds via r4 chip. If the window loads super fast it might not be able to get downloaded.[/font]

[font="Arial"]DP POINTS[/font]
[font="Arial"]A DP point is a point system in which you have to use points to download games. It's sort of like a limit so you download all the games and never come back. Don't worry about having to buy them with lots of mola. You can get a membership for only $10 US dollars a month. But if $10 is to expensive then every day you get 10 DP points a day that can buy about 1 or 2 games a day. I would recommend you get the membership personally. [/font]
