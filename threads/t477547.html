- Windows 8: Basic edition, perfect for home. Do take note there is no remote desktop support and such features that could be very important for some of you.
- Windows 8 Pro: The equivalent of Pro and Ultimate editions of Windows 7, offers everything you can think of.
- Windows 8 RT: Optimized for ARM based processors, tablets.
