TheBX718Bomba' post='4220979 wrote on Jun 29 2008, 05:30 AM:
I'm not that bright so can someone explain to me step by step how I use gamesaves from gamefaqs on the pokemon Pearl ROM?
1) Get the latest version of Ideas, 1.0.2.5 from the official site, link is in first post. A new one was released yesterday.2) Get the save file from gamefaqs.3) You will need to convert the Action Replay Max DS (.duc) to a R4 .sav type for Ideas to read it. Use this converter:http://www.shunyweb.info/convert.php# 3A) In the first line, select browser and select the gamefaqs gamesave that you saved on your PC. 3B) In the second line(Source format:), select Action Replay Max DS (.duc/.dss) 3C) In the third line (Target format:), select Acekard 2 | CycloDS | EDGE | M3 Simply | NinjaDS | R4 | Top Toy DS (.sav) 3D) Click on Convert and save the file to where you have your rom.4) After that, rename the file that you created in 3D) to the same name of rom:ie.pokemon.nds (rom)pokemon.sav5) Open Ideas and you will have the save file from gamefaqs.
