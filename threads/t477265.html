I didn't think the hardware would be the problem but it turns out your correct! I had 60gb free so I didn't think it would be what was affecting it.... After deleting numerous films/unwanted files and using cccleaner on my computer, The FPS returned to normal!

It is also woth noting that whilst my computer was running slow, there was a number of things which increased the fps slightly (im listing these so others with slow computers might benefit from this)

config----> 3D settings -----> renderer is soft rasteriser,only enable texture should be ticked with a threshold of 0 ( leave line hack also enabled)

Config----->Sound----->Interpolation to zero. (optional increase may be found as a result of also putting "sound core" to none).

Config ----> Emulation settings -----> General----> Disable Advance BUS level timing. In fact nothing in emulation settings should be enabled.

Also, from research it seems by disabling "frame limit" in config ----->Frame skip section, some members found a slight increaseof 3-5 FPS.

NOTE: These tips can also be useful for other ROMs
