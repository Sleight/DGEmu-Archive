unless your talking about --HC file structures, in which there are two
SDHC -- The Secure Digital High Capacity SD card system with supports of up to 32GB in card size
SDXC -- The Secure Digital Extreme Capacity SD card system currently deployed with a 2TB maximum support size



I remember when I first started carting stuff to my R4DS I had to make sure I had a standard card (2Gb) because at the time SDHC did not work on it.
All hardware needs to be checked for compatibility beforehand before risking anything that might crash card or device.
