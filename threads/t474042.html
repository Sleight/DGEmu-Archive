AAzure_KyteOct 13 2011, 11:04 PM
It probably has been asked. It really depends if the game in question is compatible with the PS3. in general, actual PSP games (Those specifically made for the PSP) are incompatible with the PS3. You can download them ONTO the PS3, but when you try to run them it asks you to connect a PSP to install it. On the other hand, if you were to get a game that's cross compatible, e.g. the PSX games you can download from the PSN store, then that would work on both systems.
