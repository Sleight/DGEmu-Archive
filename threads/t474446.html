For all Administrators for DGEmu that have access to the FTP, you will notice in the root a folder called "InstallFiles"

This folder contains all the applications/hooks that are used to DGEmu. To help you find sources, this guide is simply to document the name of the source file found along with the function of the application or hook.

(e32) ibEconomy 2.0.6.zip - Application that enables bank, lottery, investment, GPs loan. Can coexist with Simple Points.
(P32) Show Online Status in User Info 1.2.0.zip - Hook to show the online/offline status of users in the information panel.(Pav32)_Selective_quoting.rar - Hook to enables the Selective Quoting function.
(RSyvarth)_Social_Groups_1.2.4.rar - Application to enable the Social Groups in the forum.
(SOS32) Enhanced Member Edit 2.0.0.zip - Hook that enables advanced member editing options that are normally only available under ACP in the forum itself. Only users that have access to ACP can use this.
(SOS32)_Manage_Validating_Members_2.0.1.rar - Hook that enables "validating member" management outside of the ACP. Only users that have access to ACP can use this.
(SOS32) New Moderation Buttons on Topic View 2.0.0.zip - Hook that enables moderators the Open/Close/Delete topic buttons within the topic view.
(TB) Show Reputation in User Info 3.0.0.zip - Hook that shows the reputation of a member in the information panel.
[P32] Reputation Profile Tab.zip - Hook that enables the reputation tab in user's profile.
_SOS32__Show_Forums_Moderators_3.0.0.rar - Hook that displays the forum moderators for each section.
fs-ajt106.rar - Hook that enables "Thanking" members. Warning: This hook takes very long to install/uninstall. Leave it a good 10-15 minutes to complete.fs-impav11732x.rar - Improved Avatars: Enables many avatar functions under IPBoard 3.2.X.
fs-ipblog250.rar - IP.Blog 2.5.0: enables a blog feature to members to use.
fs-ipseo151.rar - IP.SEO: Application that enhances search and filter options on IPBoard 3.2.X.
fs-moods300.rar - Enables a mood function on IPBoard.
inv_awards_2.2.3.zip - Application that enables an award system.
MM32-StaffOnlineSidebar.zip - Hook that shows a display box on the main forum to show which moderators are currently online.
simplepoints23300.zip - Simple Points used for GPs on this board.
v322.zip - Invision IPBoard v3.2.2, basically the whole forum interface.
