AatomicknightORIGINAL POSTFeb 03 2007, 10:05 PM
Okay, so apparently some of the little modifications that I've added over the course of the last couple of months are either misunderstood or unknown. So I'll make a short list of them here:Search: Staff members use manual search mode with no restrictions on keyword length. This means that you can search for anything (even a single letter) if you want - don't abuse it though since it can be awfully taxing on the server if you're deliberately using short keywords. Sometimes it's necessary to search for something like NDS or PSP. That's why that limitation was removed. More information on syntax can be found here: http://www.dgemu.com/forums/index.php?s=&a...t&p=1544246Point deduction buttons in search results: I always thought it was extremely annoying to actually have to visit each post to deduct points, so I added that (and the point awarding buttons).Closing/opening topics from search results: Same idea for this one. This only works for S.Mods and above right now because fully implementing it requires some PHP source file changes that I don't have time to do right now.I believe that's all. There might be some other things, but yeah.Oh, and use this topic for other suggestions if you have them.
