[OFFICIAL] Guide: How to use No$gba for GBA roms

KKiririn-shiORIGINAL POSTSep 03 2007, 02:35 PM
In the domain of GBA emulation, VBA and VBA Link are the most renown and also probably the best emulators out there. However, there are plenty others and No$gba is also among the best GBA emulators. While, No$gba has been known mainly for its breakthroughs in NDS emulation, it still remains primarily a GBA emulator as its name indicates and supports many useful features such as link and cheats. Below is a simple guide aimed at GBA emulation only since there have been an increasingly number of questions about No$gba and GBA roms. Do not discuss about NDS rom, there is already this thread for the purpose and of course as usual:

ANYONE ASKING NDS EMULATION PROBLEM IN THIS THREAD WILL HAVE HIS/HER POINTS REMOVED AND/OR WARNED.

1. Basic Functions: Playing
STEP 1: Download the emulator

The latest version of No$gba can be found here.
Download the latest version, then create a new folder and extract the emulator therein.
STEP 2: Download the roms

All GBA roms can be found on DGEmu.
STEP 3: Run the roms

Unzip the rom. Unlike VBA, No$gba doesn't support compressed roms. It's a very important step!
Just open No$gba emulator. A window will pop up asking you which file to load. Chose a rom and click on 'OK'.
STEP 4: Configure the settings (optional)If it's the first time you play on No$gba or if you want to change of settings, here are the two main panels you may want to check.

Emulation Setup

Controls Setup

Emulation Speed: Choose the speed you want. The options are quite obvious, just note that "Unlimited MHz 10%, Disaster" is the fastest setting.
Start/Reset Entry Point: Leave it as it is.
Video Output: Choose the number of colour you want. The default option is good.
GBA Mode: It's a matter of preferences, test each of them if you want.
GBA Cartridge Backup Media: The default option is "Auto". LEAVE IT AS IT IS!
NDS Cartridge Backup Media: It doesn't concern GBA roms, superfluous.
Solar Sensor Level: It concerns only games that needs sunlight. Test each of them to calibrate if needed.
Sound Output Mode: No comment.
Sound Desired Sample Rate: No comment.
Multiboot Port: Leave it as it is.
Multiboot Normal/Burst Delays: Leave it as it is.
Number of Emulated Gameboys: For now, leave it at 1.
Link Gamepacks: Leave it as it is.
Link Cable Type: Leave it as it is.
Change your keyboard or joystick settings if you want.
Leave all the other options as they are.

2. Advanced Functions
Save State

Unlike the case with NDS roms, save/load state works for GBA roms. Just go to Fle->Write Snapshot (or press F8) to save state and give it a name. To load it later, go to File->Load Snapshot (or press F7) and select a file (.sna extension). Not as handy as VBA's save states, but the functionality is the same.
Cheating

This function works fully for GBA roms and is accessible via Utility->Cheats (or press F2). Once there, press "Add New" (first button), enter you cheat codes and choose the type (Codebreaker, Gameshark, Action Replay).
Enlarge Screen

Everything is explained in this thread. It works for both GBA and NDS roms. Otherwise, there is no other possibility.
Increasing Emulation Speed

It's explained in the previous section in "Emulation Setup", first option.
Taking Screenshot

It's very easy, just go to Utility->Screenshot.
Linking

This is also a very good feature of No$gba. To link two games, here is how you should proceed:
Load the game you want to play as described in the previous section.
Go to the control setup and define the controls for the other playes (up to 12 linked players).
Go to the emulation setup and in "Number of Emulated Gameboys", choose the number you want (generally, it's two).
Make a soft reset (File->Reset).
Control each of the screens with the controls you defined earlier.

NOTE: These simple steps are for two identical games. I have always thought that No$gba cannot link two different games but thanks to atomicknight, we now have the possibility! If you want to link two different games, follow the following steps EXACTLY:
atomicknight wrote:

1) Open NO$GBA.
2) Highlight the rom you want to open in your second screen (I'm assuming two games in this example), but don't load it yet.
3) Uncheck "Autostart Cartridge."
4) Click Open and the rom will load in one instance.
5) Go to Emulation Options and increase the number of Gameboy instances to 2. Click OK to go back to the emulator.
6) Now, right-click on the first instance (the left one) and choose "Load Game" from the list of choices.
7) Highlight the rom you want to open (don't load it yet).
8) Choose "2nd machine" from the dropdown box and then check "Autostart Cartridge" in that order. If you do it in the opposite order, it doesn't seem to work for some reason (steps 2 and 3 are interchangeable, as are steps 7 and 8 - step 8 must be done in the order written though).
9) Click Open and you should have two different roms loaded

3. Frequently Asked Questions
Q: Is No$gba a good GBA emulator?
A: Yes, almost as good as VBA.

Q: Where can I download it?
A: Read the step 1 above.
Q: Does it support save?
A: In-game save and save state.

Q: The game is too slow, how can I increase the speed?
A: There are a couple of things you can do to improve the speed:
Shut down all unnecessary programs, such as MSN Messenger.
Go to Options->Emulation setup, then in "Emulation Speed" choose "Unlimited MHz, Disaster 10%".
Disable the sound in the emulator options. Sound is required by some games.

Q: Does it have sound?
A: Yes.

Q: How can I use cheats?
A: Read section 2 above.

Q: Can I use link and wifi?A: Link yes but wifi is not operational.

Q: How can I aggrandize (enlarge) the screen?
A: Please read this topic.

Q: Does No$gba have a Mac or Linux version?
A: No, only Windows (and DOS).

Q: How can you have transparent borders on your emulator?
A: It's Windows Vista's Aero.
