Anybody is free to upload and share their Wii ISOs. If you are uploading something post it in this topic so that others know and don't accidentally upload the same game at the same time. Please give the files appropriate file names rather than cryptic scene release names and have the file name end with the region so that nobody has to wonder what a file is or what region it is for. Please upload to a reliable file host and try to make the files large rather than being split into many small pieces. Do not use rapidshare as they are known to turn over uploaders info for prosecution.
