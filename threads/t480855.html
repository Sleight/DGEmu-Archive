KKirie MotobaMay 07 2014, 02:50 AM

Pretty sure DG RPG is portable.

Definition of portable in this case is:
Take all files, shove into USB stick, and play from any computer off USB stick without needing to install anything.

 

So a lot of games where you need to actually install and register with a serial and stuff can't be portable, but since I'm virtualizing them, all the registry keys and configurations are captured into a sandbox, so it'll work as if it was installed on any computer without actually touching any config on said computer.


One thing that would be cool to have is ePSXe for example.

 

That emulator, all the configs you do for the plugins on your computer are saved in the registry under HKEY_CURRENT_USERS.

 

To give a pre-configured emulator, I either:

- Dump the keys that needs to be reimported in the computer to apply the configurations, and any changes you make, you would need to back them up to transfer to a new comp

- Capture into a virtual app and the keys will always be present, and any changes you make will be saved
