How to Use iDeaS?STEP 1: Download the emulatorThe latest version of iDeaS can be found at the official site or mirrors here. Create a new folder and extract the emulator therein.STEP 2: Download the romsAll NDS roms can be found on DGEmu.STEP 3: Save settingAutomatic Save Type SelectionGo Options->Save Type. If there is an Auto-Detect option, select it. Otherwise, you'll have to manually select the save type.Manual Save Type SelectionGo to Options->Save Type and chose the correct one for the rom you want to play.A list of save type can be found here.If the information is not available, try all possible save types until you find the good one (tip: EEPROM 8KB is the most used as of yet, start with this one).STEP 4: Running the romsGo to File->Open and select the rom you want to play. Then, click File->Start. Depending on the compatibility of the rom, it can run or not. Just pray for it to work.------------------------------2. Additional FeaturesIncreasing Emulation Speed: iDeaS offers you the possibility of chooseing the speed of your play, just go to Options->Increas CPU Speed and choose the percent of increase you want. Note that depending on the rom, it can have a significant effect or no effect at all.Rotation: For some game, you may prefer have a rotated screen. Go to Options->Rotation and choose the angle.Key Setting: Go to Options->Key Config.Taking Screenshot: It's very easy, just go to File->ScreenShots.------------------------------3. Frequently Asked QuestionsA very good list of questions can be found hereQ: Is iDeaS a good emulator?A: Yes, but not as good as No$gba and DeSmuME.Q: Where can I download it?A: Read the step 1 above.Q: Can it play all roms?A: Not all but some.Q: Does it support save?A: Both in-game save and save states. Read the step 3 above to set the correct save type for in-game save.Q: Can it save state?A: Yes. You can find it in the File menu.Q: The game is too slow, how can I increase the speed?A: Go to Options->Increase CPU Speed. Turning off the sound is also recommended but some games require it. Otherwise, there is nothing you can do more since the emulator is still not optimized for some games.Q: Does it have sound?A: Yes.Q: How can I use cheats?A: Go to Options->Cheats->Cheats List.Q: How can I aggrandize the screen?A: Go to Options-> Rotation and Zoom -> and select the rotation and 1x or 1.5x.Q: My touchscreen won't work!A: Go to File -> Properties -> General and set "Touch" to "Normal".Q: Where did the compatibility list go? I can't see it anymore.A: In heavens... it wasn't updated anymore and pointless in the end.Q: Can you post an updated list?A: Not by me, but much better, hereQ: Can iDeaS play Pokemon Diamond and Pearl?A: Partially but use No$gba instead.Q: Does iDeaS have a Mac or Linux version?A: No, there is no Mac version.
