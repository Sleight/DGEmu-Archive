AatomicknightJul 06 2007, 03:16 PM
AJAX is just a fancy acronym for a method of sending HTTP requests using JavaScript. In this case, clicking on the deduct GPs button triggers a JavaScript function that sends a request to the PHP backend, which deducts the points and edits the post. There's a bit of extra JavaScript that deals with the "Processing..." box and that edits the post that's displayed on the screen. Once the request is completed, the JavaScript reads the data returned and acts appropriately.
