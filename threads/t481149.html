[MH] GGPO 0.30.0 - Collection



Yet another compilation release for ROM collectors! This 5.31GB package (when decompressed) contains GGPO 0.30.0 (Final Burn Alpha v0.2.96.74), fully configured with all screenshots and titles with a few arcade cabinet shots, along with the full 1048 arcade ROMs all audited with Romcenter.
 
Why GGPO? It allows you to play online against people with the best experience possible. Currently, only a handful of games are supported online, but since this set is complete, all the rest of the games can still be enjoyed offline on Final Burn Alpha!
 
Special thanks to the Progetto-Snaps project for taking so many wonderful screenshots for MAME, I simply created a script that would import all the related screenshots to Final Burn Alpha!

Enjoy this release!
