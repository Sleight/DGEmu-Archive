Overview:
PCSX2 is a powerful Sony Playstation 2 emulator capable of running many games without issues at the current time of writing.
This guide will help you setup the basics in order to play games on Windows.
Notice that this guide will not cover any of the advanced options.

 

What you will need:
- PCSX2 1.2.1 stable release: Download

- PCSX2 SVN*: Download
- PS2 Bios SCPH-39001: Download
- Microsoft DirectX Runtime: Download

- Microsoft Visual C++ 2010 SP1 Redistributable 32-bit*: Download
- Microsoft Visual C++ 2013 Redistributable 32-bit: Download
- 7-Zip: Download
 
*Optional downloads. Read the guide for more information.

 

[dlcguide]
 
Game formats:
On this latest version of Dolphin, you can only run disc images off your computer. You will also be able to run discs from an optical drive!
The currently supported image formats are the following:

- BIN: CDRWIN image (must be accompanied by a CUE file)
- IMG: CloneCD image (must be accompanied by CCD and SUB files)
- ISO: ISO 9660 Stadard Disc Image

- MDF: Alcohol 120% Media Descriptor image (must be accompanied by a MDS file)

- NRG: Nero Burning ROM image

 

Before starting:
Make sure all the hardware and software requirements are met.
 
The minimum hardware requirements:

AMD Athlon 64 or Intel Pentium 4 or higher

2GB of RAM or higher

Dedicated video card (ATI Radeon 9500 or nVidia 5200 or higher)

 
The recommended hardware requirements:
AMD or Intel dual-core 3.0GHZ processor or higher
2GB of RAM or higher
Dedicated video card (ATI HD4750 or nVidia 8800GT or higher)
 
The software requirements:
Firstly, you will need to have Microsoft's DirectX Runtime redistributable installed to run to emulator. You can find the download link for it at the top of the guide.
Secondly, you will need Microsoft's Visual C++ 2013 runtime installed on your computer. You can also find the download link for it at the top of the guide.

 

The SVN software requirements:

These SVN releases are WIP builds as the emulators gets updated by the authors. These are often unstable and are used only for testing purposes. These releases do not require you to download the stable release to function.

Firstly, you will need to have Microsoft's DirectX Runtime redistributable installed to run to emulator. You can find the download link for it at the top of the guide.
Secondly, you will need Microsoft's Visual C++ 2010 SP1 runtime installed on your computer. You can also find the download link for it at the top of the guide.

Preparing the emulator files:
1. Once you downloaded the emulator from the author's website, use 7-zip to extract the content to any location on your computer.
2. Download the PS2 bios and extract the content into the "bios subfolder" where PCSX2 was extracted to. If this folder does not exist, create it and then extract the bios file in.

3. Depending on the release you decided to use, please follow the instructions below correctly.

 

Configuring the emulator for the first time (stable release):

This section only applies to the stable release of the emulator. Unfortunately, this release has yet to introduce the first time configuration wizard, so a little more work needs to be done.

2. You will be presented with a "PCSX2 Message" warning you that the GS plugin file was not found. Press "OK" on that window to access the "Plugin Configuration Panel".

Configuring the emulator for the first time (SVN release):

This section only applies to the SVN release of the emulator. The PCSX2 team has made this very easy for a first time user. They've made a first time configuration wizard which the user can go through step by step to setup the emulator.

1. To run the emulator, open "pcsx2.exe" from the location you just extracted the emulator to.

///////////////////////////////////////////////BLABLABLA

1. Click on "Config", navigate to the "Audio" tab, and change the "DSP Emulator Engine" to "DSP LLE recompiler". This is to avoid a loud screeching sound at the bios screen.
2. Move to the "Gamecube" tab and uncheck "Skip BIOS" in the "IPL Settings" section. This will allow the emulator to load the bios when launching a GameCube game.
3. In the same "Gamecube" tab, click on "..." right next to "Slot A Memory Card" in the "Device Settings" section. Save your memory card somewhere on your computer. This will allow you to save game progress.
4. Return back to the main emulator window, and click on "Graphics", navigate to the "Hacks" tab and uncheck "Disable" in the "External Frame Buffer" section. Leave the radio button to "Virtual". This will allow the bios to display correctly without graphical errors.
5. Return back to the main emulator window, and click on "GCPad". Setup your controls here.
6. All the other settings can be left at their default parameters.
 
Configuring the emulator for GameCube without the Bios:
1. Click on"GCPad". Setup your controls here.
2. All the other settings can be left at their default parameters.
 
Configuring the emulator for Wii:
1. Click on"WiiMote", then on "Configure" next to "Wiimote 1 Emulated Wiimote" in the "Wiimotes" section. Setup your controls here. Remember to keep in mind the position of how you're holding a WiiMote to play certain games to configure it properly. For example, playing 2D virtual console games like Megaman 9 requires you to hold the WiiMote sideways, so you must reconfigure your controls on the keyboard to be the most "natural" as possible.
2. All the other settings can be left at their default parameters.
 
Loading a single game:
1. Click on "Open" from the main menu.
2. Browse for your game in one of the supported formats, select it and click "Open".
3. That's it, your game should now be loaded and you can now start playing!
 
Loading a list of games:
1. Click on "Browse" from the main menu.
2. Browse for the folder where your games are stored, select it and click "Select Folder".
3. If you have multiple folders where your games are stored, repeat steps 1 and 2 as many times needed.
4. That's it, the emulator should now scan the folder where all your games are stored and list them in the main window so that you can easily load them to start playing!
 
Multi disc games:
Some games will have more than one disc. The perfect examples are Goldeneye: Rogue Agent and Killer 7, both having 2 discs.
Once you complete the first disc, the game console will ask you to change discs to continue your game.
To do so, simply go to "File > Change Disc...".
A new window will appear, browse for your second disc, select it, and click "Open".

Conclusion:
That's pretty much the basics you need to know in order to start playing PlayStation 2 games.
If you have any other questions, please do ask away in our forums. We'll gladly try to help.
