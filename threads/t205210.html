LOL, that's what's called a cache server. Certain ISPs cache content (i.e. store an offline copy of it) so that they can save bandwidth and "increase" service speed by loading webpages off local servers rather than remote ones. What happens when they do this is that everyone using that ISP is given the same public IP because they're all loading the same copy of the page through the cache server.So yeah, it's more than one user :P

SSir VGJan 31 2007, 12:14 PM
You don't generally just look at the IP and go "oh, there's x accounts here so they're all dupes". Generally, there'll be a lot of other telltale signs of dupe accounts, such as similar names, email address, or pieces of them being matched between each other.So like if you see an account for NarutoFanboy with the email narutofanboy@hotmail.com and later on the same IP see NarutoFanboy1 with the email narutofanboy1@hotmail.com they're likely dupe accounts. But if you see the first with BananaEater with the email horse@gmail.com they're much less likely to be.
