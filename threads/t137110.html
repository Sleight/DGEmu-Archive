Since lately there have been several members who had problems with using cheat codes on Pokémon games, I think it's a good idea to write a guide for users who are not experienced with cheat and their compatibility with different games. In the following, I will talk only about Pokémon games that are in English (US or European version).

1. Where to Find Cheat Codes for Pokémon Games on GBA?
While there are many websites which have numerous cheat codes, I recommend to use gamefaqs. I post here the links of the cheat code files that contain almost all the codes you need in general. For codes that are not in these files, please search by yourself.
R/S: http://www.gamefaqs....le/471243/22318
Emerald: http://www.gamefaqs....le/921905/38469
FR/LG: http://www.gamefaqs....le/918915/28392

2. Rom Versions
This is the intricate part. I think many of you never notice the version you are using, perhaps only whether it's the US or European version. Anyway, please read the following to find out the version of the rom you are using. This step is very important.

I recommend everyone to use VBA Link (or VBA). Open you emulator and go to File>Rom Info and check the rom version as well as the CRC (actually CRC is only important for Emerald). I summarize the correspondence between rom version and rom number just below so that you have just to check on it:
0898 - Pokémon Sapphire -> Version 00
1237 - Pokémon Sapphire -> Version 01
2011 - Pokémon Sapphire -> Version 02
0907 - Pokémon Ruby -> Version 00
1242 - Pokémon Ruby -> Version 01
2006 - Pokémon Ruby -> Version 02
1636 - Pokémon FireRed -> Version 00
1695 - Pokémon FireRed -> Version 01
1637 - Pokémon LeafGreen -> Version 00
1691 - Pokémon LeafGreen -> Version 01
1986 - Pokémon Emerald -> Version 00, CRC 72
2185 - Pokémon Emerald -> Version 00, CRC 73
Actually for Pokémon Emerald, the CRC 73 version is named European version on DGEmu (a probable mistake), however, it's the German version. So codes mentioned before won't work on it at all (an error message will be displayed if you try to use).

For the rest, don't care about whether you have the US or European rom, only you need to verify is the version number. If you have renamed you rom and you are not sure anymore, just check using your emulator.

3. Cheat Codes and Roms Compatibility
I tested sample codes for each for these games and the result is very simple:- if your rom version is 00, then all the US codes on these cheat files indicated above work.- if you rom version is 01 or 02, then the codes don't work in general.There can be some exceptions, if you manage to make some codes work on 01 or 02, that's good for you but in general, they don't.If you are using a 01 or 02 version and you want nevertheless use cheat codes, you can either:- search for websites which have cheat codes and test them but I think it should be quite difficult and fastidious to test since these codes are often useless.- just download a 00 version and import your save state using File -> Load... If you have an in-game save, import it using File -> Import -> Battery File...

4. Imputting Codes in VBA Link (VBA)
Open your game on VBA Link (VBA) and go to Cheats>Cheat List, then click on Gameshark. Just copy and paste codes from the files. Congratulations, your codes are enabled.

5. Conclusion
I hope it would help you to solve your common problems with cheats on GBA Pokémon games.

If you have comments or suggestions, please feel free to PM so that I can correct any mistake but don't do it on this thread because it will add further confusion.

Good luck.
