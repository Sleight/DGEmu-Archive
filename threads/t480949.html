Predicted release date: April 24 2014

Welcome to the game that is full of my childhood memories!

This is my second portable release on the Internet, using my knowledge from my every day work to deliver a portable version of Starcraft with the Brood War expansion, which you can bring everywhere on your thumb drive!

 

The game is updated to version 1.16.1 so it's a simple download and run! You also have the option to install it if wanted.

 

Note that you cannot play on Battle.net with this release (for obvious reasons), but this does not prevent you from playing multiplayer on the LAN. :)

 

This has been tested fully working on Windows Vista 64-bit, Windows 7 64-bit, and Windows 8.1 64-bit. It should work on Windows XP and any 32-bit variant of computers.

Just make sure you have the minimum hardware requirements to run this game on the computers you try to run it on (which in fact, it shouldn't be much since it's an old game)!

Any issues with the game? Just post in the topic!

 

I'll be releasing more portable versions of games as we go. :)

 

Enjoy this release!
