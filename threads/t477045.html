I've created this thread to allow for requests for specific ROMs or for someone to put together a specific set you'd like.

[center]RULES:[/center]
1. DO NOT request new games for NDS or 3DS here. Those will be posted on the main page as they are dumped.
2. DO NOT request ISOs for systems that have their own sections. For Example: GameCube, PS1, PS2, PSP, Dreamcast etc.
3. DO feel free, however to request for systems that do not have sections, such as Sega Saturn or 3DO.
4. DO request specific translations for specific ROMs. Want Pokemon Red in Portuguese? We'll see what we can do.
5. DO request series sets. If you'd love to get a full set of all the Earthworm Jim games, let us know and we'll put it together in a reasonable amount of time.

I'll update the RULES as this progresses. Feel free to ask any questions.
