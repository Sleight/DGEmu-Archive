The new ATB system looks very interesting though, at first, I thought the game might be lacking if you control one character and it's not a real action RPG, but looking at the trailer several times, battle system looks more interesting than FFXIII's with three characters at once!

 

 

- Paradigms(blue box) is the base of the battle system again.

 

- Instead of having access to all learned moves, looks like you can pre-assign four moves to the four face buttons(4 for each paradigm). Thunder = triangle, Lesser Guard = Square, etc...

 

- You can equip three paradigms during battle, each come with its own ATB bar(red box) and HP(green).

 

- You can execute way more attacks with single full ATB bar now than in XIII, see: 

 

 

As the player press circle(circle assigned to attack here, you can see the attack rectangle popping up with every attack) ATB gauge is reduced by little, however, looks like ATB gauges fills up way slower than before, so once your ATB bar is low, you'd have to switch paradigm while you wait for it to fill up(see blurred second and third ATP gauges filling up slowly in the gif)

 

- Each paradigm has its own sword/shield, not sure if they come with the paradigm or you can equip them yourself(fingers crossed for equip, that will be a lot of customization).

 

- Not sure what that circle thing on the side is(yellow box), looks like some kind of gauge for a special attack!

 

- Purple box is the enemy name + HP(duh!), the small box thing is what's intresting here though, it shakes and changes color as the enemy takes damage, in other scenes the small boxes seemed fill with de-buffs status signs! This might be the new system to replace stagger gauge from XIII.

 

- There seem to be some form of platforming now based around red objects! If it's red, you can interact with it, how silly!

 

- Divinity looks like the main paradigm, it's using the same sword/shield we see in the CG scenes/images.

 

- While some paradigims have guard, others have dodge, curious how dodge works, do you have to time it(would be cool) or does it just gives you a higher value for dodging attacks while active?!

 

Battle system is the only thing looking good in the trailer, but it's enough to capture my interest.
