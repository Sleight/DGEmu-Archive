Do not open another thread on Max Media Dock, all discussions and questions go in this threadSee lists at bottom of tutorial for compatibility lists for ROMs that require donor cards, patch types etc.This tutorial is for the Max Media Dock. There is also a Max Media Player. The only difference between the two (that I know of) is that the Max Media Player comes assembled with a 4GB CF HDD while the Max Media Dock (MMD) isn’t assembled and you have to provide your own CF card or CF HDD. So this tut should work for both. In my case, I didn't need to flash or modify my NDS Lite in any way in order for the MMD to work and mine is brand new, so I am assuming until they release NDS lites with new firmware or something then you should not have to flash or mod your NDS in anyway to use it with the MMD or MMP.Lets Start with what’s in the box:Max Media Manager mini CDMax Media Player cartridgeUnassembled Max Media DockUSB CableUser ManualFirst thing you should do is put your CF Card or CF HDD in the case and screw the Max Media Dock together (This is explained on page 4 of the user manual).Next download some NDS ROMs.Once you have your ROMs downloaded you need to patch them. I will explain how to do this using Max Overload. Max Overload is a FREE program that you can easily download by searching for it on google or by clicking the link provided. It should come in a .zip file that contains a "max overload.NDS" file and a "Max Over Patcher.EXE" file.First unzip the files (If they are zipped, they probably will be) once the ROMs are unzipped, you can rename them however you want for the moment. For this tutorial I will use Animal Crossing - Wild World for explanation.Open the Max Overload Patcher. You should see this:Click the open button (in the upper left corner) and browse to the folder where your NDS ROM is saved like so:Click on the .NDS file and click open in the Open dialog box.After doing so, you should see something like this:Now your ROM patched. The reason for needing this patch is that you are playing the NDS game through the GBA slot, so it needs this patch so it can be read through the GBA slot. After patching a new .PAT file will appear with the same name as the .NDS file like so:Now hook your MMD up to your PC and open the CF card so that you can drag and drop the files onto them. You can either put your files in the root folder or in my case I have a folder names “NDS ROMs” and then have each ROM in its own folder. This is easier to keep all of the ROMS together with their .PAT and .SAV files. So in my case, I drag the folder “Animal Crossing” over onto my “NDS ROMS” folder that is on my MMD.You also need to drop the Max Overload.nds file onto the root of your MMD.Once you turn on NDS on with the MMD and Max Media Player cartridge inserted you should see this screen for a brief second (after the NDS warning message comes up)Then your Max Media Player software will load like this:As you can see I have my NDS ROMS folder which contains all of my ROMs in their own separate folder as well as the MAX OVERLOAD.NDS file.Now power off your NDS and hook it to your PC and Defrag your MMD. If the ROM files are fragmented they will not load. If you don’t know how to defrag a disk click here.To begin your ROMs double tab on the MAX OVERLAD.NDS file (the full file name isn’t shown it’s shown as “MAX OVE…” on the screenshot)Once you double tab this icon, MAX OVERLOAD boots and you should see something like this (depending on what ROMs you have on your MMD)On the bottom screen are listed all of your ROMs along with an icon (this icon is automatically in the ROM file, you can’t change it) as well as the name of the ROM. This name is internal, no matter what you name your ROM file won’t affect the internal name shown on the Max Overload screen.Simply use the up and down on the D pad to scroll up and down the list of ROMs, when the ROM you want to play is selected, push the start button on the NDS. Your ROM should load. Some ROMS may take several seconds to load for the first time. Once they are loaded once and the .SAV file is created, they should load very quickly from then on.You’re not ready to play just yet though.After the ROM is loaded Max Overload automatically creates a .SAV file. It gives this file a name depending on what the name of your ROM is. In my case the save file automatically created is named “ANIMAL~1.SAV” This .SAV file is created in the same folder as your ROM and .PAT file.Now, this is very important before you begin playing in order to save your game progress. Your NDS file, PAT file, and SAV file must all have the same name. So in this tutorial you either have to rename the NDS file and PAT file to “ANIMAL~1.NDS” and “ANIMAL~1.PAT” –OR- you have to rename the .SAV file to “Animal Crossing – Wild World.SAV” It doesn’t matter how you rename the files, the point is all three files have to have the same file name. In order to rename the files you have power off your DS and hook your MMD up to your PC again and browse to the folder on you MMD where your ROM is stored. In my case I renamed all of the files like so:ANIMAL~1.NDSANIMAL~1.PATANIMAL~1.SAVNotice all three file names are the same now, and they are all three in the same folder. Now I simply drag the "Animal Crossing" folder onto the "NDS ROMS" folder on my MMD and you are ready to play and save your games. Remember, everytime you drag and drop files onto your MMD make sure that you Defragment you MMD disk. If the ROMs, PAT or SAV files are fragmented THEY WILL NOT LOAD! Analys the disk everytime you add files to it to make sure it doesn't need to be defragmented.Once all three file names are renamed correctly you should now be able to successfully play and save your game.Some game file require you to either check the Disable Turbo Load or the Disable Save Patch while patching in order for the rom to work. CLICK HERE for a list of what settings work best for what ROMs. ROMs that require you to check the Disable Save Patch box require you to use donor carts to save your game.WHAT ARE DONOR CARTS?In order to play some NDS games (mostly newer games) you need a donor cartridge. Out of the 118 ROMs I have tested so far, only 18 of then need donor carts to play. In this example of how to use donor carts I will user the games New Super Mario Bros. as the ROM and Super Mario DS as the donor cart. You need the original Super Mario DS cartridge (or other donor cart).First boot up your MMD with the Max Media Player cartridge. Once Max Overload is booted remove the Max Media Player cartridge from the DS slot and place the Super Mario 64 DS cartridge in the slot. Now select the New Super Mario Bros. ROM from the list and load it. Now, all of your game play for the New SMB rom will be saved the the Super Mario DS cartridge.Now once you save your New SMB game to the Super Mario 64 DS cartridge you can no longer save a Super Mario 64 DS game or it will overwrite your New SMB save file. Most NDS games do not need donor carts and not all original NDS cartridges will work as a donor cartI will put a compatibility list of what ROMs will and won’t work as well as what ROMs need or don’t need donor carts.Until then, if you have a question about if a game needs a donor cart or if it will work, PM me about. The MMD can only play videos in the d3v file format so you will have to convert your mpegs and avis into d3v files using the Media manager. You do not need this disc for use in playing ROMs on your MMD.TROUBLESHOOTING:When I Plug my MMD into my USB my PC doesn't recognize it:If you are using windows XP then it is because the cord that comes with the MMD is crap. Darklugiaxcross' post='1994801 wrote on Dec 24 2006, 12:58 AM:
Are all compact flash card the same size.
I'm not sure if you mean are they the same physical size or if they hold the same size amount of data, but the answer to both questions is no. There are two types of CF cards - type I and type II. They have the same dimensions except type II cards are slightly thicker - about 1.2mm or so. I am fairly certain that the MMD will accept both types. As far as data storage, CF cards range from 16MB up to 8GB maybe even higher. Keep in mind that there are also CF HDDs which are the same size as CF type II cards, but the CF HDD have moving parts like your PC HDD and runs slightly slower then CF flash. I've never tested this, but have heard that using a CF HDD will cause some games to lag on the MMD while CF flash won't cause lag.
