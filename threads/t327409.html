Moderators often find themselves using the same types of messages repeatedly throughout the forums, so we have some fixed messages that can be generated with shortcuts. Study the content of the messages below and make sure you know when it is appropriate to use each one. Type the "code term" above the listed messages to quickly produce them for usage in threads. Any terms that you find in a code box are custom BBCode, and you must type the entire code in the correct format to make it work. Otherwise, the terms work via the word filter and you simply need to type them. Make sure to read any additional instructions with these terms so you know when it is most appropriate to use them.

"How to gain GP/DP" Message
Type: /gp]
someone wrote:

Read:How to get DP and GP!Also read about the DP Loan if you are interested in downloading large files:How the DP Loan system works.

[rom]<insert ROM name>[/rom]
