[OTHER QUESTIONS]
Q: Is it true that I can't install this if I update my Wii Firmware to 3.3?
A: The original Twilight Princess Hack (alpha versions) will no longer work with firmware 3.3. However, the Homebrew Channel can be installed via the beta version of Twilight Princess hack. It will display a warning message, but it'll still install correctly. However, since the 3.3 firmware fixed the Trucha bug, installing via burnt DVDs is not possible with this firmware.

Q: Can I install this if I have Wii Firmware 3.4?
A: Yes, but you need to use the Twilight Princess Beta2 hacked save, or else use BannerBomb or Indiana Pwns.

Q: Can I install this if I have Wii Firmware 4.0 or 4.1?
A: Yes, but you'll have to use BannerBomb to install it instead of Twilight Princess Hack, which doesn't work on 4.0 Firmware. You can also use the Indiana Pwns hack.

Q: Can I install this if I have Wii Firmware 4.2?
A: Homebrew Channel 1.0.5 is the first to work on Wii System Menu 4.2. It can be installed via the Indiana Pwns hack.

Q: Does the Homebrew Channel still work with Firmware 3.3 or newer?
A: If you have System Menu 4.1 or less, you can use the Homebrew Channel. If you have System Menu 4.2, the Homebrew Channel will be deleted. There is no way to get around that at this time (09.28.2009).
