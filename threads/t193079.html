Getting Started
When you first get your M3 simply you'll need a micro SD card. Follow this guide to install Wood R4 onto it. Once you have that on your card you're ready to go, copy any NDS rom(No .zip,.rar etc, only .nds) onto your card and its ready to run. Stick you card into your M3 and start your DS, select game and pick the game you want to play from the list, if its a new rom it'll ask if you want to create a saver, select yes if you want to be able to load the game in the future)

Save files
The M3 Simply stores its game sav data as .sav so if u got a M3 you can convert your .dat saves to .sav saves using the M3 slot 2 adapters game manager, with the Sav convertor file which you get from the CD or download from their site

Skinning
Skinning your M3's background is simply all you need to do is to create a folder called "_system_" in the root folder of the card, create a theme folder inside the theme folder you can have up to 12 themes stored in a separate folders called theme01 to theme12.
This should help you when checking whether or not your folders are correct, this is for theme 5 of your card
X:\_system_ hemes heme05
'X' standing for the letter of your drive
Inside each theme folder are 4 bitmap files with 256 x 192 for their dimensions and a theme.Ini file.
Here are what their names should be and where they'll appear:
bckgrd_1 - top screen of the list menu where you start you games
bckgrd_2 - bottom screen of the menu where you start your games
icon - the bottom screen of the main menu(the icons are part of the background)
logo - the top screen of the main menu
Theme.ini - a text tile that will set your themes font colors

To switch between skins on your M3, simply press select in the main menu which will switch the theme setting from automatic where the theme changes every month or manual where the theme is set on one of the themes you have pressing select again will move to the next theme until after theme12 where it'll become automatic

Cheat Function
With the firmware 1.04 The M3 Simply has a cheat function, you can get the cheat database from the R4 site. Put the Cheat.dat file into your _system_ folder and if your game is in that list you'll notice that there is a Cheat button on the touch screen when u highlight your rom, Press "Y" to enter it. From here you can turn on cheats for your rom by touch Cheat Enable and use the controls to activate your cheats. Hit Save and Exit and you return to the game menu start up the game like normal and the game will start with the cheats avtivated. If the Cheat.dat file doesn't have cheats for the rom your playing then you can wait for a new release of the cheat.dat file or make your own with the R4_Cheat_Editor found here http://www.linfoxdom...om/nintendo/ds/
under the R4 section. Open the cheat editor select new database under the file tab. Now you can give your cheat database a name in Description. now click on Code© and then "add game". click on the new entry on the left box and give the game its name.
For the next part go to http://www.codejunkies.com/ and find the rom your looking for cheats for(make sure that if it (U) get the US version etc. copy the game code and put it in the game code in the cheat editor.
now go to Code© and select add code give the code a name then copy the cheat from code junkies into the cheat data and click update code. You can group codes togther by making a folder that will become a drop down menu on the M3 simply with the add folder function. After making your cheat database save it in your _system_ folder on your Micro SD. You don't have to overwrite the Cheat.dat file as the Simply can handle a second .cheat file called usrcheat.dat.

Multimedia
The Multimedia button can be used to start moonshell to start playing Mp3s or dpg encoded videos. If you have a another program to use other than moonshell, you can set the multimedia button to start that rom, to do so rename your desired homebrew or rom to "_DS_MSHL.NDS".
If your moonshell doesn't soft reset back to the main menu, you can download a new soft reset plug in to fix the problem here
http://www.linfoxdom...reset_mse01.zip
just extract the new reset.mse to your moonshell's plugin folder

Other things
The M3 Simply can be change the brightness settings on your DS light, also a feature that allows you to soft reset from a game back to the M3 Simply Menu can be turned on and off after selecting games, they can be found on the touch screen in the top left and right corner of the screen, you can toggle this feature by touch the icons or pressing L for the brightness and R for the soft Reset function.

If the Icon is red then the soft reset feature is disabled, if it is green then you can soft reset while playing a rom by pressing L+R+A+B+Y+X together at the same time

Here's some help on your M3 moonshell problem-Once you have the shell folder in your M3, you're ready to put files on it. All you need to do is drop your media files (.mp3, .jpg, .txt, .ogg, and .bmp) into your card. You can make a folder to organize them if you want. For videos you can only watch them in .dpg fromat. Thankfully, the disc you got with your M3 has converter tools in it. Go to the dpg tools folder and select the dpgenc.exe file. Once you execute te file you will get a box that is probably in a different language. To fix this click on the label that has an (L) next to it and choose your language. Then you need to choose the output path for the file, which is where the converter will send the file when finished. Once all of this is set up just drag the .mpg, .mpeg, .avi, or .wmv video file where it tells you. The file will be converted and it is now ready to put on your M3.When you start up moonshell on your M3, the file selection is on the top screen (just navigate to the files you want).Hope this helps.

The rom size and the file size are going to be the same. If you download say, Final Fantasy 3, the file size of the unzipped rom will be 128MB. Now, the actual size of game is around 98MB, but the carts only come in 4, 8, 16, 32, 64, 128 MB sizes. So, the developers of the game add filler bytes to make the game 128MB in size. If you put that rom on the card, it will register as 128MB, what you can do is download a trimmer and then it'll allow you to take out those useless filler bytes and cut the file size down to 98MB. In the end, a trimmer will allow you to add more roms.Does that answer your question?
