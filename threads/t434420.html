SShidou MariyaMay 31 2009, 12:01 AM
The random restart is as pointed by hackerx, most probably a hardware failure on the level of ram components (ram itself or the slot on the motherboard) and not a problem with the emulator.If you're running Windows Vista, you can run the "Windows Memory Diagnostic Tool" that can be found in the Administrative Tools in the Control Panel.If you're running Windows XP, do as hackerx suggested.Another trick that can help you pinpont the problem is that when your computer reboots like that for no reason, at the menu that Windows offers (the black screen with white writing offering the choices of Safe Mode, Last Known Good Configuration, etc), choose the option "Disable automatic restart upon system error".Like that, if the error persists again, you will receive the blue screen of death instead of a direct restart. Write down the full error code and that should help guide you into looking up what the problem is.
