For all of these steps, I'll assume you properly followed my steps earlier and installed the Homebrew Channel. While there are other ways to do this, this will be the easiest for all Wii firmware versions.

[center]Installing WiiWare and Virtual Console Games[/center]
This is the section I'm sure a lot of people want to be able to do. WiiWare and Virtual Console games on the net can be found in files called "WADs" (not to be confused with WADs used by games like DOOM and Quake). To install these, you will need a program called WAD Manager.

WAD Manager 1.3 for the Homebrew Channelhttp://www.adrive.com/public/0146bed416c0051012e8a11abffd38e48e318e84c88c705138ab12355e30db2c.html
Open up this file with Winzip. There are 4 files. All of them need to be extracted. After opening Winzip, just click Extract. On the next screen that appears, make sure Use folder names is checked. Now select the drive that your computer has for your SD card, then click Extract (By having Use folder names, Winzip will put the save file into the proper directory). Now, you need to find a WAD file of whatever VC/WiiWare game you want to install. You need to extract the WAD file into the WAD folder on your SD card.

Once you're done with this, eject the SD card from your computer and put it in the Wii. Proceed to start the Homebrew Channel on your Wii.You should see a screen that says WAD Manager. Click that and run the application. Follow the instructions to install the WAD or WADs of your choice. You can also use this application to uninstall any WAD or WADs of your choice.
- This will install the selected WAD. - This will uninstall the selected WAD. - This exits the application and returns you to the Wii Menu.
[center]WARNING[/center]
DO NOT install too many WADs at once. If you install too much and use up all of your Wii's storage blocks (or channel spaces), you'll get some problems.For those that want to keep all of your WADs on a USB drive instead of an SD card, WAD Manager 1.3 is compatible with USB drives.
[center]

WAD Manager Install Channel (Optional)[/center]
For those that want to have a channel to install/uninstall WADs from, you will still need the program above, however you can use that to install the WAD Manager 1.3 Channel.http://www.adrive.com/public/0638ea801925a4e38c26b63623426afb9227f25e5190e681afe5428d094226d7.html
Open up this file with Winzip. There is 1 file. After opening Winzip, just click Extract. On the next screen that appears, make sure Use folder names is checked. Now select the drive that your computer has for your SD card, then click Extract(By having Use folder names, Winzip will put the save file into the proper directory). Use the WAD Manager 1.3 in the Homebrew Channel to install this WAD. Once you've done that, you may choose to remove the Homebrew Channel App.

[center]Installing Homebrew[/center]
Installing homebrew for the most part is very easy. But each homebrew program may have its own little qwark, especially the emulators.The best way (and easiest) to install homebrew is to get what's called the Homebrew Browser.http://www.codemii.com/download/Open up this file with Winzip. Extract the homebrew_browser folder into the apps folder on your SD card (so you'll have /apps/homebrew_browser when you're done).Once you're done with this, eject the SD card from your computer and put it in the Wii. Proceed to start the Homebrew Channel on your Wii.Now start up the Homebrew Browser application. You MUST have online capabilities to do this.Once you get in, you'll be bombared with TONS of items to download. To download, it's very simple. Point at the app you want with the wiimote and click on download. Watch this video for an example (It's an old version of the browser. A few features have been added, but this should give you a general idea): http://www.youtube.com/v/Ic7bnxrmZj4


If you want a complete list of all applications available, click here.
Some homebrew may need additional items or folders. This will vary from homebrew item to homebrew item, but mainly applies to the emulators.

[center]Alternate way to install Homebrew[/center]
If you have a homebrew application to install that isn't on the Homebrew Browser, it needs to go into the following location for the Homebrew Channel to see it: X:\apps\(Homebrew Folder Name)\Where X is the drive letter for your SD card and (Homebrew Folder Name) is the name of a folder for your Homebrew application. Your homebrew app needs to be a DOL (the old ELF standard has been removed in Homebrew Channel 9). DOL files MUST be named boot.dol or they won't work.
