KKirie MotobaJan 17 2014, 12:19 AM

There's a lot of new stuff in comps nowadays.

 

Classic bios boot vs UEFI boot.

Classic MBR vs new GPT.

 

Thing is, on a GPT drive, it seems that some Linux tools can't recognize it, such as the regular fdisk.

 

An official guide to get it up and running on a drive that's clean:

https://help.ubuntu.com/community/InstallUbuntu11.10OnLenovoEFI/GPT/WLAN/Power/BIOS

 

Ignore the wireless parts, it's more the part where you want to make sure that Ubuntu fetches the latest updates, and that when you come to the partition portion, you select Manual mode instead of automatic.

 

As stated, GPT, on the first partition, it should be the EFI partition (should already be there since Windows 7 is present)
