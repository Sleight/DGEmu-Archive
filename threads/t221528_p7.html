AatomicknightJun 05 2007, 08:01 AM
Eh, you're probably going to have a hard time with it if you don't already know what it is. CRC stands for cyclic redundancy check, which is a means of checking if the data you actually have matches the data you should have. The easiest way to calculate it that I can think of is to compress the file and then open the compressed file with 7-Zip, which will tell you the checksum.

I'm not sure if anyone else has posted this here, but I find running with the sound set to 44kHz results in slightly better performance. I also have it set to Realtime, Auto. There are still times when it slows as far as 50%, especially when there are a lot of trees and when you start a battle in the snowy areas, but there are times when I'm pretty sure it's hitting 30+fps (haven't found an option to display actual fps in this emulator, perhaps they'll add it later), something that never really happens at 10kHz sound. My theory is that 10kHz sound actually slows it down for this game, as the sound samples are probably at 44kHz anyway. The conversion to 10kHz adds one more thing for the emulator to do, resulting in slightly lower speed. Also worth noting is that running under Vista knocks the speed down a few notches vs running under XP.
