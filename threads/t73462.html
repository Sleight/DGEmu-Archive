-UPDATE- As of March 9th 2007, there are no known viruses on DGEmu.com at the moment. However, we will leave this thread here in case it happens again. -END UPDATE-It seems there have been pop ups on the site recently. Some of them have been known to be harmless, but others install viruses and junk on your hard drive. The thing is, we can't do anything about it until Dragons Master fixes it. He's the only one who deals with the advertisements. For now, make sure you have an active anti-virus program running at all times when you browse www.dgemu.com/forums. If you wish to report a virus, post in this thread and do not start a new thread about it. Also make sure the advertisement you report is a harmful one, and make sure it hasn't been reported previously. All the current virus topics will be merged into one to make things easier. We're sorry for the inconveniance, and I hope you understand our situation.UPDATE: Here's a fast and easy way to get rid of the installer.exe issue for Firefox users:
qcarachato wrote:
1. Get AdBlock extension (after installing, you'll need to restart firefox to activate it). 2. Press <CTRL> + <SHIFT> +

(AdBlock's Preferences) 3. In "New Filter" field, type "http://*.web-nexus.net" (withouth the "quotes"). 4. Press OK. 5. In "New Filter" field, type "http://*.regvista.com" (withouth the "quotes"). 6. Press OK. That's it.

Now for Internet Explorer users:
qcarachato wrote:
For Internet Explorer users:Choose:Tools > Internet Options > Security > Restricted SitesJust add them damned "*.web-nexus.net" there.Add "*.regvista.com" as well.
Another solution to the problem:
qcarachato wrote:
Edit your "HOSTS" file:Win98\MEC:\windows\Win2K:C:\winnt\system32\drivers\etc\WinXP:C:\windows\system32\drivers\etc\and add the following lines:127.0.0.1 www.web-nexus.net127.0.0.1 ax.web-nexus.net127.0.0.1 196.regvista.comMake sure you save it to its previous name. It is not "hosts.txt", "hosts.sample", "hosts.filename nor "hosts.etc". It is just "hosts" (no file extension).If notepad adds a ".txt" to the file name, delete/move/rename the original one and rename the newly saved "hosts.txt" to "hosts".
