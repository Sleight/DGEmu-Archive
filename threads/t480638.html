Metro Apps vs Windows Apps.

Closing Metro Apps, press at the top, drag down.

Shutdown in Windows 8.1 is at bottom right, when the Windows button appears, right-click, shut down. In Windows 8, you click at bottom right, or slide right to left a bit, click on settings, click on power, then click on shut down.

I did a good amount of research before I bought mine. I've only had it for less than half a day and not all of the stuff that I bought for it have come yet so I haven't done much with it.

 

Initial thoughts

 

-Pros:

 

Nice aesthetics. The body and screen and everything are all really nice. It's all flat surfaces so you can get a nice solid grip on it any way (my iPod touch 4g has smooth, rounded beveled sides all over and is super slippery and easy to drop and a pain to pick up). Buttons include a power button on the top, a volume control, and the windows logo on the front is essentially a Home button like an iPad where pressing it switches between your active stuff and your home screen. The built in stand is pretty good, supports horizontal standing (though only at one angle as in it isn't adjustable) and somewhat supports vertical/side standing, though this is more likely to drop. The pen is a really nice touch, it works and feels almost identical to a real pencil/eraser when writing/drawing. Writing with this thing is pretty damn accurate and one thing that I thought was cool was that the virtual keyboard has an option where you can just write whatever you want to type and it'll convert your written text into typed text. It's a totally auxiliary thing but pretty fun.

 

It runs really well. I've been running Google Chrome on it since I didn't think FireFox would be appropriate on this + it auto synced up my previous GC settings/extensions and mobile bookmarks (not to mention dem voice searches using the built in mic). It loads 1080p youtube videos instantly (my shitty desktop can't even display 1080p). Switching between traditional Windows and the metro apps and all that shit is pretty seamless too, I can have a youtube video playing and then switch over and draw something with one of the drawing apps. Windows 8 definitely takes some getting used to if you're like me and have never used it before. Once you get used to it it's ok and it actually has integrated pen/touch screen use (doing a short swipe to the right on the center of your screen with the pen automatically functions as a "back" button for both folders and web browsers). Bonus points for being able to use torrents and install pirated software, Daemon Tools Pro especially helps for installing .ISO files since there's no CD drive. I'm not sure but I think the cameras are 720p, you'd have to look it up to get a true measure. It's not bad, definitely capable of skype and whatnot (though I don't use skype).

 

-Cons:

 

Weight. It's about 2 pounds so that really cuts down on the portability. It can be held comfortably with 1 hand but you won't want to hold it for very long, if being used in a portable sense you'll really want to find a table or something where you can put it down. Also it heats up when doing a lot of stuff. The fans are already doing all they can to keep it cool but if you're powerloading with a lot of processes or using it with a lot of settings (i.e. max brightness, volume, wifi, bluetooth all at once) it starts heating up. Not too hot but not very comfortable to hold or have in your lap. It definitely FEELS like it would be easy to drop BUT from what I've seen on youtube it's a pretty tough tablet, the glass especially.

 

Keyboard. The virtual keyboard is pretty sweet, but you definitely aren't going to want to type up anything longer than a facebook status with them. Definitely going to want to get a keyboard if you have any intention of typing with this. That then leads to the touch and type covers which both add on another $100+. However there ARE alternatives. It has a single USB slot so you can use a USB keyboard + mouse (though IMO an external mouse is really not necessary with this, the pen just works way too great) or you can use a generic bluetooth keyboard such as this one (if you don't mind using a BT KB this is a pretty sweet deal. Though the price on Amazon has been all over the place, before it was $60 and now it's $53).

 

Windows 8.1 is annoying. I like Win 7 better. Also fuck internet explorer. Replacing it was the first thing I did.

 

Side Accessories:

 

-Only 1 USB port. If you're looking at this as a tablet, that's great. If you're looking at it as a laptop not so much. Personally I don't think it's that big of a con, but say you use a USB keyboard AND want to use a USB gaming pad or something, you'd need a pretty good USB hub in order to support all those things.

 

-HDMI. One of the main reasons I bought this was to connect it to our HD TV so my family can see computer/internet stuff on the big screen and also for big screen gaming. Turns out it doesn't have an HDMI out. If you want to use HDMI you have to buy one of these (pretty pricey but there are alternatives. I bought one from eBay for $20, don't know about the one I just linked to, can't vouch for it. Also keep in mind that there's both HDMI and VGA adapters for both Surface and Surface Pros: http://www.microsoft.com/surface/en-us/accessories/browse#accessories5). So basically if you plan on doing anything HDMI related expect to drop a few more bucks and have to have this accessory with you whenever you need it.

 

-Size. It's already pretty bulky while naked, any cases or keyboards are only going to add to width/weight. Not really a con but something to keep in mind. I think it'd be worth it if not mandatory to buy a laptop style carrying case for portability. On the bright side, the power adapter has a USB slot on it so you can dual charge your tablet AND charge your phone at the same time via USB charger.

 

 

Overall: You pretty much have to treat it as more of a laptop than a tablet. It requires a bit more dedication to use comfortably than the average tablet but is capable of doing the same and more than the average tablet. One thing that's truly great it being able to use windows OS to do whatever. Kind of a fuck you to tablets that use "IT CAN DO 2 THINGS AT ONCE! SUPER HOT MULTITASKING ACTION!" as a marketing point. Keep in mind I haven't used it a whole lot and this is just my thoughts while setting it up and putting some software on it. I'm still waiting for my Xbox 360 controller, portable 1TB harddrive (almost essential if you plan on buying the 64gb. 64gb only has about 30gb of free storage) and Surface -> HDMI adapter before I can give a true opinion on it. As of right now I love it. It's already more capable than my shitty desktop computer and more fun to use (seriously, I can't praise the pen and touch system enough). If you're seriously considering on getting one of these I think it might be worth it to look into getting a Surface Pro 2 if you can afford twice the price however. It seems they made some well needed improvements on that model though I haven't really researched the 2 so I don't know much about it.
