I just discovered this Firefox addon while looking for another one (something to quickly paste text temporarily like a mini-notepad which I never found) and I have to say, this is extremely useful if you're like me and can't really stand these embedded text editors (profile comments anyone??) in the browser (especially when they are so small). The name of the extension is "It's all text" which places an "edit" button onto all text fields allowing you to open the text in any word processor and/or editor where you can quickly edit the text and place it back into the browser once you save the file (I use editpad pro with this and it worrks really well). I'd say this is excellent for those of that post a lot (and yes, I'm using it now to post this). Also nice when you're using Gmail and your browser happens to crash before Gmail auto-saves (i.e. you don't lose your message). Let me know what you think.If you're interested, you can download it here.
