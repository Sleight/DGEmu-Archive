Yeah a lot of games clock your PSP at 333mhz. If you notice a lot of the earlier games that came out for the PSP had horrendous loading times. So if you clock your PSP to 333mhz and load it off your memory stick, instead of a UMD, you'll get much faster loading speed.Most newer games, will automatically clock your PSP to 333mhz to avoid this problem, considering the PSP isn't supposed to have a custom firmware where you have that option.

its because its compressed. if you were to decompress it, which would take the original ISO file out (which by the way is about 1,100 megabytes), it wouldn't lag.while playing games, if the file is compressed, it has to be decompressed on the fly. this can be bad for games that are more graphics heavy, because the psp has to work harder to decompress faster. if the file is totally decompressed, lag will NOT exist at all. I have a Dissidia ISO fully decompressed, and I have no lag at all.

how do you do this UMD caching?
If you have a psp slim, its located in settings/system settings. by default, its turned on. when a game is loaded, it automatically caches files to RAM.if you have the original psp (fat) then you can't use this feature due to the original PSP only containing 32mb ram instead of the now standard 64mb.
