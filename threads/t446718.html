This is a pack with nearly every English game Epic published for Dos. I left out Drum Blaster because it wasn't even a game, just a (bad) "drum" sequencer.This pack uses the portable version of Dosbox .73 and a Dos menu/launcher for the games. I have it configured to NOT start in full screen since some of these games use resolutions that may not work correctly with some monitors. Just press alt+Enter to switch to full screen if you would like.This is the first test release. I think I have all the games configured correctly. The menu layout is mostly filled out with only a few tweaks being needed. Most of the games don't have icons for the menu yet. I believe I have Dosbox configured with settings that will work for most users. All games are configured to use the keyboard for control but some will auto detect if you have a joystick/gamepad and use that.Just download, decompress, and use the batch file to start the collection, You can just use the dosbox portable exe but the batch file hides the extra dosbox status window.http://www.megaupload.com/?d=KTJ9PYIELet me know if anything doesn't work correctly, if any of the games need their default settings changed, if you feel a game is filed in the wrong category, or if you think you know of a dosbox setting that should be changed.
