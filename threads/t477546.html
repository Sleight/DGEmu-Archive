Wally (MSFT)
For reference, this is the wrong forum for this. You should ask this in the Setup/Deployment forum, which is for SCCM setup issues.

However, you indicated that the clients did upgrade fine - correct? If so, then this is to be expected. As part of the upgrade, the Ccmexec.exe service (SMS Agent Host) service is stopped. That causes this error in the logs, which is not really an error.

But Ccmexec.exe is replaced by Ccmsetup.exe, which successfully installs the new client.

So, as long as the client did indeed upgrade to SCCM, and has reported in to the site as running version 4.00.5931.0000, then you are fine.

Yes, I do understand you. And I'm answering your question - IT DOES REPORT AS A FAILURE!

It does not retry by default, so you must have changed the advertisement to Rerun if previous attempt failed. If you set it to not rerun, then it will fail (as expected), and not rerun.

Yes, upgrading from SMS 2003 to Configuration Manager via software distribution is a supported scenario.

Maybe if you play with the command line parameters you can get a success status, but I've never seen one - only failures. I complained about this in the beta, but nothing was changed for it :-(
