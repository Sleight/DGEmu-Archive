PProtoKunDec 09 2005, 02:22 PM
Flash is no piece of cake. For someone who just started using multimedia tools, Photoshop CS2 would be a nice intro to the tools.Flash is, pure and simply, a hard bone to chew. It takes a whole while to finaly be able to reach the "making animations" step. You need to understand how animation works (timelines, frames, X and Y locations), tool usage (what each tool does and etc) and other simple things that built up to make someting good.IF you wish to start on Flash, get Swish 2.0. It's a nice intro to learn Flash, but don't expect to create games or other stuff using Swish (it's a flash menu maker), but if you're thinking of making games using Flash, you should consider it... cause it's not easy.
