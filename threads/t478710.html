KKuisanagiJan 29 2013, 12:31 AM

Interesting that you asked this now, cuz in the past 2 months there were some pretty big advancement in PS3 hacking

And actually 2 years ago, it was far less complicated, you kinda missed out

 

First of all, what you need to get CFW on your PS3:

1) A PS3 with OFW 3.55 or less (only way you're getting this is if you haven't updated your PS3 in 2 years, or on EBay)

2) A PS3 and a hardware flasher to downgrade it back to 3.55 (such as E3 Flasher or ProgSkeet)

 

I personally bought a PS3 before 3.55 and never updated it, so I never had to downgrade... though I'm sure you could find some tutorials online for downgrading.  Such as this

The hardware flasher will probably run you $50-$100

From what I know, E3 Flasher is by far the easiest to do, doesn't require soldering, and allows you to dual-boot OFW and CFW: http://www.wiihacks.com/ps3-hacking-tutorials-guides-faqs/100553-guide-how-downgrade-w-e3-flasher-any-cfw-ofw-3-55-lower-advanced.html

 

 

Once you have a PS3 on 3.55 OFW, you can install CFW.  The best one out now is Rogero 4.30 v2.05 (subject to change frequently)

You do it exactly the same way as on a PSP, basically put the system update file on some sort of USB media and run it in XMB (or more safely through recovery menu.  There are tutorials for that too)

 

What you get for having CFW 4.30:

 

1) Play any game from HDD (formatted FAT32).  It used to be that you could only pirate games that ran on 3.55 or lower or got eboot hacked down to 3.55, now you can just pirate anything.  Since I upgraded to 4.30 CFW I've DL'd like 150 GB worth of games on 4.xx firmware, and they all work.

 

2) Run homebrew.  This includes lots of really useful utilities like game managers, playing h264 anime or whatnot, media server, cheats, FTP server so you can access your PS3's internal HDD, etc

 

3) Go online.  Yes you can go online now since all you need to go online is be on the same firmware as the most current OFW, and 4.30 is the most current atm.  You even play online with hacks (if you want to tempt getting banned), synch trophies, talk to people, use PS store, etc 

 

So basically all the normal features + being able to run unsigned apps (and thus pirated games).  In other words, the same level that PSP hacking is already at...in another other words, totally worth the price of a hardware flasher if you pirate more than 2 games.  Quick note here though, some games won't run without a real BD disc in the drive, so you might have to buy a cheap game.

KKuisanagiFeb 28 2014, 04:24 PM
I much prefer piracy to PS+ lol. Its not for old games, but rather playing new releases as soon as they come out...and I'm not limited to the games that Sony decides on.

Anyways, if you're using E3 flasher its not a one-and-done piece of hardware, it stays attached to your PS3 forever and provides a port to plug in a 2nd hard drive that you will dual boot CFW from. This is the advantage it has over an old PS3 that's on 3.55, it allows you to also boot the latest OFW whenever you need...which is usually when Sony updates their firmware, it takes devs several days to update CFW to the same version, so its safer to be on OFW.

If you take it to a shop to do it, they'll probably use a NAND/NOR flasher and give you back an OFW 3.55 machine...much cheaper that way for them as they don't need to give you any hardware so you just pay for service. Of course if they use E3 you pay for hardware + service
