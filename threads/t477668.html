DGEmu Radio v3.1: Setup and Deployment Guide [WIP]

Introduction
The purpose of this guide is to walk you through the steps to properly setup a new radio album for users on DGEmu based on version 2's source code. Unfortunately, since my site got taken down, many parts of version 1 were broken. On top of that, the setup with the older (and less clean) Flash MP3 player does not work properly with DGEmu's latest server.

This guide will consist of three parts:

- Changes: A list of changes and features of each version.
- User Guide: This will instruct how a third party can fully prepare a soundtrack package for the administrator to use.
- Admin Guide: This will instruct the site administrator how to deploy said package onto the server.
- VBScript Sources: This section will contain all necessary source codes for the scripts.

Required tools
- Playlist and Album Information Generator VBScript

- MP3 Tagging Utility (This guide will use Mp3tag)

Preparing the music files
There are several prerequirements that need to be fulfilled before an album is eligible for DGEmu Radio:
- All music files must be in MP3 format.
- All music files must respect the following naming convention: "XXX - Title.mp3" where XXX is the track number.
- All music file names must not contain any special characters.

For an easy solution to manage all your music files at once, you can use Mp3tag to mass rename your files according to their ID3 tag. The two important fields that need to be properly filled are the track number and the track title. The following steps will guide you on how to batch rename an album with Mp3tag:
1. Launch Mp3tag.
2. Select all your tracks from your directory and drag them into Mp3tag.
3. Select each track one by one and edit the track and title fields on the left. Make sure to not use any special characters in the fields. Don't forget to click save before moving on to the next track.
4. Once all the tracks have been edited, select all the tracks on the right hand side.
5. Optional: While having all the tracks selected, you can now batch edit the common fields such as the album name, artist, comment, audio ripper, and embed a new cover to your MP3 files. Once the changes are done, click save and it will apply it to all the tracks.
6. While having all tracks selected, click on Convert > Tag - Filename.
7. Make sure to set the format string to the following: $num(%track%,2) - %title%
8. Click on "Ok" to convert all the tracks file names.
9. If everything was done correctly, your files should now be in the correct format for DGEmu Radio.

Preparing the album art
This is the easiest part to get ready. Simply prepare an image file in jpg format and resize it to exactly 250x250 pixels. Once that is done, rename to file to front.jpg.

Preparing the package for submission
Once the album art and the MP3s are ready, put them together in a directory on the computer. Now, you will need to copy over the script to prepare the album. You can either use the encrypted VBScript located here or simply take the source code from the bottom of this guide to have your own script. The usage of the script is simple:
1. Copy the file over in the same directory where the MP3s and album art is located.
2. Run the script file by double-clicking it. If at any point an invalid entry is submitted, it will fail to create the necessary files.

Admin Guide

Required tools
- Album Validator and Post Generation VBScript
- FTP Access Utility (Recommended: Filezilla)
- File Archiving Utility (Recommended: WinRAR)

Connecting to the server through FTP
For this part, you will need root access to DGEmu. Only Dragons Master is able to supply you with such an account. Once you have the proper connection address, user name, and password, you can configure any FTP client to connect to it, such as FileZilla.

Preparing album files and forum post
Before we can start, make sure you have the Album Validator VBScript ready. You can download the encrypted VBScript here or simply take the source code from the bottom of this guide to have your own script. Once you're ready, you can continue with the steps below:
1. Download and decompress the album package if required.
2. Copy the Album Validator and Post Generation VBScript file into the same directory as the content.
3. Run the script file by double-clicking it. If the check does not meet all requirements, the script will tell you exactly what is wrong with the package. If everything is well, just continue with the next steps.
