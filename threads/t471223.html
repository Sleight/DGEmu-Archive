sam_c' timestamp='1304172506' post='4949032 wrote:
There is a DS emulator for android but apparently it runs really slowly even on the best phones so guessing would be same for iphone...
To put this in perspective. I have the Evo 3D and it only runs smoothly. It has a dual core 1.2GHz processor and 1GB RAM with automatic task kill. The iPhone 4/4S has a single core 1GHz Processor and 512MB RAM with a manual task kill and most system tasks are protected. This means the iPhone with less processing power, half the RAM, and less available active capabilities, would have a harder time running it. The bright side is that Apple devices have always been set up in a way that makes RAM optimisation more reliable. If a DS emulator were made for the iPhone, I'm sure it would take less system resources than the current Android one. Having said that, it is impossible to tell if it would be enough.
