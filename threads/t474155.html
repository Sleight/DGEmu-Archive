KKirie MotobaFeb 10 2013, 09:10 PM

I might need to work on checking the MAME romsets.

If you don't know about the arcade scene, every new MAME release usually adds new clone romsets and such, and some parent romsets are modified as newer more conform dumps are identified, thus rendering the same rom completely useless.

 

Just to give you an idea, romsets for arcades are usually a zip file with a bunch of PCB rom dumps inside with different names.

For a rom to work correctly, every single one of those files inside + the name of the zip file must be properly renamed for it to actually be picked up by an emulator to load.

And for a rom to work correctly without crashing, the CRC of the files must match up with what's in the database. That's where rom manager applications such as Romcenter comes in very handy.

 

I don't know what version of MAME romsets we have on our site, but I'm nearly sure they might be outdated by a few versions. I'm working on a pre-configured Kawaks 1.63 upload, so if you don't want to fight with it, you'll have a nice emulator with 100% the roms correctly identified. Just got to be patient though. :)
