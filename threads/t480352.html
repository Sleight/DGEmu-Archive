KKirie MotobaJan 07 2014, 12:56 AM

@Kui

 

Quick fix:

1st thing to do:

- Windows key + R

- services.msc

- Go to "Bluetooth Support Service", if it's running, stop it for now.

 

2nd thing to do:

- Motionjoy will take over TONS of drivers, causing things such as wireless keyboards and mice to die.

- Windows key + R

- devmgmt.msc

- Expand driver sections that can be hijacked, such as Mice and other poiting devices, Universal Serial Bus, etc.

- Find anything related to MotionJoy, right-click uninstall

- Make sure to check "Delete the driver software for this device"

- Once gone through all that hell, restart your computer, install the PROPER bluetooth drivers stack for your bluetooth adapter

 

Everything should be back in order.


And if you insist on using MotionJoy, try to figure out the PID of the things that conflict with it, and edit them out the inf file of the driver before installing it.

By doing so, theoretically, it won't hijack for those devices anymore.
