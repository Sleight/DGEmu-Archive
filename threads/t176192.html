Lemme write this here for people wanting to know more about the game. First of all this game is Isometric so if you like Gauntlet Legends, this is the game for you. It has TONS of puzzles, and make sure if you hear a blipping sound in a room, theres a keycard, FIND IT. Whether or not you have to enter the room from all angles, theres a way to get the card, and you use all keycards so if you miss one it can be frustrating to backtrack. Make sure you grab all keycards!! Aside from that, natural progression through the levels is easy and straight forward, so there isnt any backtracking unless you missed something, it just takes common sense :) . Oh for those guys who are stuck with the 2 panels you have to press down, you need to get the cryogenic freeze and use it on the enemies to turn them into blocks of ice, then pull them onto the panels. To get it in that room, shoot the cylinders scattered around within a fast amount of time to activate it so you can grab it. All gaming aside, yes this is similar to Metroid Fusion, you are a female bounty hunter, yadda, yadda, its still got its own unique gameplay, so it is by far not the same thing as Metroid Fusion. Metroid enemies didnt absorb attacks you make of a certain element, and the certainly didnt have as many puzzles or need keycards. This game is fun ^_^
