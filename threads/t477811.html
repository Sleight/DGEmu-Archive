You use a burning software such as Nero or something to burn the ISO image to a CD, the data in the ISO is what makes the CD (or DVD) what it is .... it could be a PC Game, another console game, a Music CD (though ISO for that is strange), a group of data files (your mum's recipe book for example?), etc ....

You can mount the ISO File using something like Daemon Tools to a virtual drive and see what is in it if you are unsure ....
