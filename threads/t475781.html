Do you get something like 'Could not be detected. Please reinsert the cartridge message and restart'?You always get that with No$ because it doesn't auto-detect save-types. You have to manually go and set the save type in the emulation options. But this means you have to reset it everytime you play a ROM that has a different save-type. I once lost my save file because i didn't do it properly :oAlternately, Use No$Zoomer.
