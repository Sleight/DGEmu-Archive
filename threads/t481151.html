[MH] GGPO 0.30.0 - Collection



Yet another compilation release for ROM collectors! This 5.31GB package (when decompressed) contains GGPO 0.30.0 (Final Burn Alpha v0.2.96.74), fully configured with all screenshots and titles with a few arcade cabinet shots, along with the full 1048 arcade ROMs all audited with Romcenter.

Why GGPO? It allows you to play online against people with the best experience possible. Currently, only a handful of games are supported online, but since this set is complete, all the rest of the games can still be enjoyed offline on Final Burn Alpha!

Special thanks to the Progetto-Snaps project for taking so many wonderful screenshots for MAME, I simply created a script that would import all the related screenshots to Final Burn Alpha!

Enjoy this release!

KKirie MotobaAug 11 2014, 03:17 PM

What I was asking is what were you trying to achieve?

 

Playing with friends online with netplay or just offline with local multiplayer.

The base MAME is an emulator with command lines only.

 

For an emulator with a GUI, you either go with:

- MAMEHub for netplay

- MAMEUI for offline

 

Also, MAME 0.153 is now obsolete, the latest version is 0.154.

 

When you hunt for ROMs online, you need to audit them since arcade ROMs are picky on the CRC: When you check inside the zip file, you'll notice a whole bunch of files, which are dumps of different chips on the board for:

- video

- audio

- program

etc etc.

 

Basically, if any one of those files does not match the CRC of what the emulator is expected to receive, it might not/will not work.
