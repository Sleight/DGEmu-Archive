Quick guide to set up Java security:

 

Start > Control Panel > Java

In the Java Control Panel window, switch to the security tab

Make sure the "Enable Java content in the browser" is checked.

Lower the security Level to Medium.

Apply, OK.

 

Close and restart your browser.

Try again, you should now get a security prompt asking if you're sure you want to run this applet. Click on "Run"
