One thing to note is that the PS0ne is not capable of reading from a DVD-r or otherwise. it can read from CD-r Those are the kind you need, as for modchips, it depends on the the model of Playstation there are some cd based boot programs available that allow booting backups and games from other regions.  Don't recall the exact name but it will work on a PS2 to lanch a ps1 game as well.  For PS2 it would be easier to instead of doing a modchip it would be easier to make a FreeMcBoot memory card.  Then you could send games to it wit the network Adapter and a SMB (windows share) from a computer on the same network.
