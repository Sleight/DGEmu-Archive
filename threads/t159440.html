This tool is for moderators and up. Since I believe there is no reason to keep complete reports hanging in the report center as nobody is going to double check them to make sure they were done correctly (there are better ways to see if a moderator is doing their job). Therefore, to make it easier on Sentinels and up (especially tm24), I've created a script that can purge complete reports. The idea is for you to set your reports to complete once you finish them so you can still make corrections if you've made an error. Once you are sure everything is fine run this:http://www.dgemu.com/forums/purgeReports.phpAll completed reports will be removed from the "Moderator Center". As soon as I figure out how, I will embed a link right into the moderator center itself.Enjoy ^_^
