ok here goes my attempt at a tut (all images are links, dont want to make the whole page take ages to load)step one:create a new background:350 px by 20 px,go [edit] [fill] and choose black.http://i18.photobucket.com/albums/b103/spl...fin2/tutno1.jpgpress ctrl+shift+n to create a new layer, and use the rectangle tool to draw a white box from the top left cornet to the bottom right.http://i18.photobucket.com/albums/b103/spl...fin2/tutno2.jpgnow set the foreground and background colours, the bg colour should be black, the foreground should be the colour of the sig you want. i used colour ff00cc (pink)http://i18.photobucket.com/albums/b103/spl...fin2/tutno3.jpgright click on the layer with the white box and apply these settings:http://i18.photobucket.com/albums/b103/spl...fin2/tutno4.jpghttp://i18.photobucket.com/albums/b103/spl...fin2/tutno5.jpghttp://i18.photobucket.com/albums/b103/spl...fin2/tutno6.jpghttp://i18.photobucket.com/albums/b103/spl...fin2/tutno7.jpgclick ok and you should have something that looks like this:http://i18.photobucket.com/albums/b103/spl...fin2/tutno8.jpgnow press d to reset the fg/bg colours and select the gradient tool, make sure it has these settings:http://i18.photobucket.com/albums/b103/spl...fin2/tutno9.jpgctrl+shift+n to create a new layer, hold shift and drag the gradient tool from the bottom of the layer to the top, then set the blend mode to screen and the opacity to 32%:http://i18.photobucket.com/albums/b103/spl...in2/tutno10.jpgselect the elipse tool with the settings:http://i18.photobucket.com/albums/b103/spl...in2/tutno11.jpgwith it draw an elipse over the layer like this:http://i18.photobucket.com/albums/b103/spl...in2/tutno12.jpgthats the main part done, now add your text and go to blending options, choose outer glow and leave it as default:http://i18.photobucket.com/albums/b103/spl...in2/tutno13.jpgpress ctrl+j to duplicate the tezt layer, go edit, transform, flip vertical and move the layer till it is 1 px below the original text layer. go to layer, layer mask, reveal all. now select the gradient tool again and draw from the bottom of the text to the top.http://i18.photobucket.com/albums/b103/spl...in2/tutno14.jpghopefull you'll end up with something a little like this if you want to insert an image make sure it is underneath layer 2, and it looks good it you set it to have an outer glow (change the glow colour to the main colour you used and decrease the opacity a little untill it looks good)hope this help[if a mod or someone gives me the all clear ill make it so all the images display on this page, there are 15 images ~ size about 35Kb each)
