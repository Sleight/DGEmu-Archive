KKirie MotobaJul 30 2015, 06:01 AM

Reporting in temporarily.

 

Laptop and primary HTPC are upgraded to Windows 10 using the ISO you can build through this tool:

https://www.microsoft.com/en-us/software-download/windows10

 

Both computer were upgraded from Windows 8.1 Pro to Windows 10 Pro.

 

Experience during upgrade:

- Extremely painless. When upgrading, just make sure to "not check for latest updates" to save yourself some time. Litterally a few clicking next next, wait for like 3 reboots, then the redesigned, yet still familiar setup of Windows 8 screen will appear, and within 3 clicks, you're back into your desktop, everything exactly the way it was.

- Laptop running Intel integrated graphics and Core i5 went well, not a single issue.

- HTPC running AMD APU processor (A10-7850K), upgrade went well. After first login, small issue with AMD drivers not having proper licensing, required to upgrade to the latest AMD drivers that was released on the 29th of July, and everything went on fine and dandy.

 

Experience so far with latest things in OS:

- The Start menu is far from being the familiar menu people knew in Windows 7, but it is much more friendly than the Metro UI. The new advanced Microsoft Search is even more intuitive than the Windows 8 version, and makes Windows 7 search look obsolete. Basically, from the start menu, you can search the web, files, and apps within 1 query. Unforutnately, both machines do not have microphone, so I couldn't test out Cortana. I did try Cortana on my Windows Phone, and already there, it was promising, wouldn't see why they would make it worse here.

- Microsoft Edge... Is... I don't know, I'm not used to how it is presented...

- File Explorer is far more intellegent. When launching it, it basically presents you with the most recently accessed folders and files, and from there, you can decide to navigate to "My computer", "Network", or other places. Smarter design over the old where you had to give in a few extra clicks to work things.

- The control panel is just... wow. The way it is now organized, it's clean and very easy to get what you need. No more digging around, none of that Windows 8 badly put together UI organization that requires you to dig to find something. Even the new presentation for Windows Updates is good for now.

- Boot, shut down, restart speed, so far, it is pretty much on par with Windows 8.1. Windows 7's turtle days are over for now.

 

Unfortunately, no test on gaming and such, so can't tell my experience there.

I'm making sure that at least everything else runs smooth, before I upgrade my main desktop. Multi-monitor setup will hopefully rejoice from all this.

 

Anyways, signing off, and possibly be back before my vacation ends. :)
