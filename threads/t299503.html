Windows Vista includes a Start Search function to make navigation of the Start menu easier.Some Features that Vista lacks from other versions of Windows:1. Total compatibility for certain programs (though this can sometimes be worked around with the Compatibility Wizard).2. Windows Vista does not include the Pinball game.
