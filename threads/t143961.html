Basically how our donating system works is as follows:

<pre class="_prettyXprint _linenums:0"> $q = $payment_amount; if ($q < 10) $dps = $q * 50; elseif ($q < 20) $dps = $q * 55; elseif ($q < 30) $dps = $q * 60; elseif ($q < 40) $dps = $q * 70; else $dps = $q * 85;</pre>

Where $q is the amount you donate and $dps is the number of dps you will get.
To those non php readers, here's a few examples:
$2 donated = (50 x 2) = 100 DPs
$5 donated = (50 x 5) = 250 DPs
$10 donated = (55 x 10) = 550 DPs
$20 donated = (60 x 20) = 1200 DPs
$30 donated = (70 x 30) = 2100 DPs
$40 donated = (85 x 40) = 3400 DPs
$50 donated = (85 x 50) = 4250 DPs
$100 donated = (85 x 100) = 8500 DPs

Once the donation has been made, you will be given User DPs, which do not reset and are used only when your Daily DPs have been spent. Which brings you to the next point.

If you plan to/have been donating regularly, try the Power Membership scheme!

Finally, after many requests from our recurring donators (thanks guys!) and after a lot of fussing around with the PayPal IPN, I'm glad to announce we now receive Power Members once more.

What is Power Membership?
In short, this is a higher level of membership that is gained by giving a monthly 10$ support to DGEmu, which will be used on the servers, yay!What you get as a power member is:

  • 100 Daily DPs everyday instead of 10 like a normal member
  • Daily DPs accumulation limit set to 1000 instead of 100 like a normal member
  • If you have less than 150 Daily DPs, it will be reset to 250 the next reset. For a normal member, when has less than 15 Daily DPs, it's reset to 25.
  • 500 User DPs every month immediately after the monthly payment
  • Belonging to the Power Members group in the forums - prestige
  • Knowing that you help keep this site up for the sake of everyone who uses it
  • As of the end of July 2013 we have introduced a new Power Members Forum (Only Power Members and Staff will have access to this forum).  This VIP Forum will have exclusive early access to new material and details before all other members!  When staff decide the forum will get something new then within a few days we will post allowing Power Members to know about it, Power Members will also be able to comment and suggest improves on these ideas, and once in place they will also get to be the "beta testers" in some cases, trying out the staff's hard work to make sure things work before we release it to the public (normal members)!

Why Monthly Membership?
The reason we need the monthly membership is because we need a more realistic estimation of how much money we have and will have by the end of the month, so we know how much we can use. For a practical example, I'm currently looking into getting another server so we can add more improvements and systems to DGEmu, but a new server costs money every month, and I cannot go on making a contract and start paying for another server until I can be at least somewhat certain we can afford it in the long run. That's the main reason we're doing it.For those who wouldn't like to commit or would just want a one time kaboom of DPs, the one time donations are still going to be available.
