Nifty little program to remove Word document passwords for all versions (Word 97, 2000, XP, 2003 doc files and Word 2007, 2010 docx files).

Simply execute, open the Word file. The application might seem frozen for a few seconds, that is normal.
Once it finishes scanning, it will provide you with either the passwords if any, or else, an option to remove the password.
The application also makes a backup file (.bak) of your original document in case it messes up something. :)
