Welcome to the official M3 guide. If you find I have forgotten something, or you still need help, don't hesitate to ask and I will be happy to respond.


1. Introduction

The M3 is a class of flashcart (a flashcart is a device you put into the GBA slot of either a DS or GBA). If it is a DS, you will need either to have your DS flashed (easier then you think) or to use a passcard such as passcard3. Flashcarts are mainly used to play home brew applications (homemade software) or commercial roms illegally. most flashcarts have inbuilt memory, but the M3 among a few others have a slot for various memory cards, which gives it unlimited storage space depending on how many of what size memory cards you are willing to buy. I have a 512MB SD card and its fine, I can usually have about a dozen of roms depending on what roms I am using at the time. All information can be found on the official website.


2. Difference Between all the Different Types of M3

First things First. The only thing you need to know is what memory card you want to use and whether or not you have a DS Lite. But simply put all M3's no matter what shape, size or name are basically the same hardware using the same software, therefore can all use this same guide.

Secondly you may come across it with different names such as 'perfect' or 'adapter', this is simply because it was originally named 'the M3 adapter' then later renamed to 'M3 perfect', same thing, different name. Similarly some sites will name each M3 as slightly different names, just look at the description/picture of the product to be sure you are getting what version you want. I will now go through the different M3's to help you decide which is best for your DS;

M3 SD Slim

This is the one I have. Here is a picture:



It takes standard SD cards, and should be best for a DS original as it sticks out by like half a centimeter (2 cm for every inch). Not recommended for DS lite as it will stick out too much. It is able to play most home brew and all compatible roms (same for all M3).

M3 CF



Due to the nature of CF cards, it will be significantly larger then the SD slim. However CF cards are slightly cheaper and play more home brew then SD can (developers prefer it more). Recommended for DS original and anyone who wants a flashcard mainly for home brew applications.

M3 Mini SD



This is the same size as the M3 SD slim, except it takes mini SD cards. Mini SD cards are more expensive then normal SD, but they are extremely small for the 'cool' factor. There is no difference in mini SD vs SD, apart from size. So its virtually the same as the SD slim.

M3 Micro SD lite



And here it is for you DS Lite'rs. Will fit a DS lite slot perfectly with no stick out, accepts micro SD cards only. There has been a correction, it will fit the DS phat if used with the GBA shell that comes with it. use of the Lite shell will not fit thou, unless used in a Lite.



3. Gamemanager and How to Play Rom

Introduction
Gamemanger is a program for your PC that comes with a new M3. similarly the latest version can be found on the main site here. I suggest upon buying a new M3 to forget about the disc and just download the latest version now, as it will stop a lot of the "this game won't work" threads.

Installing
Download the newest version, by clicking on the link for the "full install [your language]". Once you have that, use Winrar unzip its contents and install Gamemanger, while you are at it upgrade M3's firmware by copying over the firmware upgrade file found in one of the subfolders to your memory card and then when you run M3 on your DS press 'start' to install it... will also stop a lot of the "this game doesn't work" threads. Once installed, you wont need that file on your M3 again.

Using Gamemanger
When the program is first run, it will ask you where the folder for your roms is, this is helpful as for each time you use Gamemanger, it will default to use that folder, saving time and effort. Once Gamemanger is running, in the left dialog box browse to find your memory card (assuming its plugged into your computer already, if not, do so now). there are 2 buttons to click on the right; "Write NDS" and "Write GBA" depending on what type of game you want to write. Let's say we want to write a DS game. Click on the "Write NDS" button and it will open a file select box, choose the NDS rom you would like to Write to your card. it will ask you for certain settings, now most will work with any game in any setting, however some do not, for more information on which settings to use please consult M3Wiki's compatibility guide (Alternative). Once that is done a dialog box will either say "Write OK" or "Disk is full". Almost done.

Playing Roms
Now its time to start playing! pop in the M3 into your DS, select "Games" from the main menu, select the ROM you want to play, press A to load it up. If it all goes smoothly the next thing you should see is the title screen for your chosen game. Happy playing :smile2:

M3 Save Manager
Using the Save Manager, this is use to either backup you save game or put one a different one, eg moving your save
game from the GBA emulator to the M3. Heres how you do it.

Firstly open the game manager browse around and find the rom that you want to change the save file on your media card, double click it or right click it
and select saver manager. This will open up the save manager. At the top it will tell the the game type and the file name. On the bottom of the Save Manager there are a couple of buttons, we'll only need to use a around 7 of them.

Here are the main buttons that you'll use and what they do:

General Format
Write .Sav - writes the selected save file with on your pc to the M3(use this one to transfer saved games from emulators)
Read .Sav - writes the selected save file on your M3 to your pc(use this one to transfer saved games on the M3 to your emulator)

M3 Format
Delete - Deletes the selected save file (you should have already known that)
Rename - Just what the button names suggests
Write - similar to the Write .Sav function but uses .Dat files instead (.DAT files are the save file that the M3 uses)
Read - like the Read .sav function but uses .DAT files instead.
Create Blank - Basically formats the save file so you can start again

The read and write function is normally used when you download save files and want to add it into you M3

Now if you want to transfer a save game that you were playing on a emulator then click on the save file in the middle box then click write in the General format section, browse to you emulator and find the save file of you game(it should have the same name but have a .sav at the end instead of .gba or .nds) double click it and when the writings done you get a notification.

For transfering save file from your M3 to your emulator can be a bit more tricky.
Click on the read on the general format section, now it'll ask you where to save it, save it in the same place where your emulator save file is. Now delete you old save file and rename the new save file to what you old save file was. Eg is your save file from your M3 was named "Pokemon Red dungeon.sav" and on your emulator it was called "Pokemon Red Rescue Team.sav". Then you new save file should be renamed to "Pokemon Red Rescue Team.sav"

MP3 playback

Introduction:
within the M3 firmware the hombrew application known as moonshell is already installed into it. unfountatly it is kinda confuing to the first time user since it is named 'extend' on the menu and yet called moonshell everyeher esle.

MP3:
ok firstly i will say that MP3's will play perfectly fine, so no converting or patching required. just chuck the MP3's onto your SD/CF card anywhere u like (i like to put them into a folder named 'music' but you can do whatever you like). next boot up your M3 in your DS, select extend, select the music icon. broswe the fodlers until you get to where you put the music, select the song you want and voila. music is now playing in your DS. you can close it and use the L and R buttons to pause and go to next song while the songs are playing. there are also ther settings on the music window that opens in moonshell, but they are obvious so just mess around with them.

Video:
ok heres where it gets a little confusing. first you must convert all of your movies that you wish to play. to do this you will need moonshell tools (google it). within moonshell tools you must sleect the program dpgenc.exe (DPG Encoding). run this program. this may look a little overwhelming but all them settings are more for the advanced users, dont touch them if you dont know what ur doing, the default settings are fine.

now, see that bar at the top. next to it there is a button named something along the lines of 'select video', clcik this and then broswe for your video file that you want to encode (note this works for most video files, except WMV9 and above, for that please use another converter first and encode to mpg first). once that is done select encode or convert or whatever that button says that will result. it may come up with something about 24fp/s depending on the video, just press 'yes'. it will then convert to a .dpg file.

then its the same as the MP3's, chuck'em onto the memcard wherever, in moonshell sleect the video icon, and then select the video to play it. simple as that.
