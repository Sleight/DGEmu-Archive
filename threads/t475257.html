Overview
Windows 7 is Microsoft's latest operating system at the time of writing of this article. Most of the users around the world use Microsoft Windows, but not all of them know the details about the installation discs. This guide will cover the basic things to know prior an installation of Windows 7 for end users at home. This guide will not show you how to prepare corporate deployments, nor will it show you or link you to any crack of patch of circumvent the Windows Genuine Activation. I also assume you know how to follow simple on screen instructions to get the installation going. This guide is only intended to be a resource to help you when you have a computer with a valid license key, but no disc to help you.

Knowing the difference between the different version of Windows 7
There are many flavors of Windows 7 released to the market. Here's a quick overview of all the different versions available of Windows 7:
- Starter: This version of Windows will not be available as an ISO download. More specifically, this version of Windows is packaged by OEM manufacturer with distribution of netbooks. This version of Windows has its own share of limitations: The Windows Aero theme disabled, the ability to change your wallpaper disabled, and the ability to create a Homegroup is disabled.
- Home Basic: This edition of Windows is a stripped down version of Home Premium intended to be used in emerging markets.
- Home Premium: The most distributed Windows version on the market. This version basically how all the missing abilities of Home Basic enabled. The only limitations with this version is the inability to join a domain and the lack of the Windows XP mode.
- Professional: The edition most widely used within businesses, this edition offers everything that Home Premium does, as well as the ability to join a domain and the ability to use the Windows XP mode.
- Professional N: This version offers exactly the same as its Professional counterpart, except with the Media Center capabilities stripped from it.
- Ultimate: This is the most complete edition of Windows 7, offering everything that the Professional edition has, and adding the Bitlocker security and the ability to change between the 35 different language packs.
- Enterprise: This edition is the exact same as the Ultimate. The difference is that this edition is distributed under volume licensing only for large companies, as to the Ultimate edition is distributed on a per-license basis to end users.
- Enterprise N: Again, this version is the same as the Enterprise edition, minus the Media Center capabilities.

Knowing the difference between OEM, RTM, VLK, and Retail
- OEM and RTM edition are the same. Original Equipment Manufacturer, or Release To Manufacturer editions are dedicated to computer builders. The software licensing on those versions are usually meant to be bundled with a new computer. The activation of those products keys for the first time will be associated with the hardware profile of the computer, and the license is not transferable.
- VLK, or simply Volume License Key, is a key that is destined for business use to bulk activate a series of machines depending on how many licenses are allowed with it.
- Retail licenses bought off the shelf are licenses that can be installed on your own computer of your choice, and the license can be transferred from one computer to the other.

32-bit or 64-bit architecture?
- 32-bit operating systems (referred as x86) are compatible with 16-bit and 32-bit applications. Unfortunately, 32-bit operating systems have a maximum of 4GB of allocatable memory (that includes memory dedicated to video, and other devices, leaving you with approximately 3.2GB of RAM depending on your hardware profile).
- 64-bit operating systems (referred as x64) are compatible with 32-bit and 64-bit applications. 16-bit applications will not work, and you will need 64-bit compatible drivers for your hardware. The maximum amount of memory supported by Windows 7 are as follows: 8GB limit for Starter and Home Basic editions, 16GB limit for Home Premium, 192GB limit for Professional, Ultimate, and Enterprise.

Secrets behind Microsoft Windows 7 keys and discs
- An OEM key can be activated on another computer without any problems. It might fail the automatic activation online, but the phone activation process will never fail, as long as you mention that the key is being used on a single computer. Do not attempt to have more than one computer simultaneously using the same product key, you might get your key blacklisted.
- An OEM key for a specific version of Windows does not prevent you from installing different architecture versions (32-bit or 64-bit), nor will it prevent you from installing a different language of Windows (English key can be used to activate a Chinese version, a French version, etc.)
- You can use an OEM key with a retail disc version and vice versa. The automatic online activation might fail, but once again, the phone activation won't.
- When you install Windows 7 without a license key, the operating system will be installed as a 30 day trial.
- You can do a clean install with an "Upgrade" key. Simply do a clean install Windows 7 as a trial version. Make sure you do not check the "activate Windows when online" option during setup. Once you're in Windows for the first time, re-run the setup from the same disc, but this time as an upgrade. Enter your license key, and it should now upgrade your trial version to a full version.
