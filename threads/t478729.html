KKirie MotobaNov 18 2013, 04:31 AM

Previous job:
Team lead of comp techs, retail store
Basically training my minions into doing work such as base installs of software and stuff for clients, and they earn grades I give them.

Deal with clients, completing sales, managing complaints, and taking charge of any more technical computer issues.

Managing any request for repairs to our repair depot or manufacturer, meaning HP, Acer, Toshiba, etc.

 

Current job:

Hybrid position of software package (physical and virtual), software analyst, and SCCM administrator (and for the past 2 weeks, packaging team coordinator)

Software packager (physical):

Take home developped software and create an installation MSI out of it

Take company packaged software (MS Office, Symantec Endpoint Protection, Adobe Creative Suite, etc), apply any configurations, licenses, and tweakings for a silent installation.

 

Software packager (virtual):

Take any of the above software and virtualize it into a single exe where the app will run within its sandbox (basically, a bit like what portable apps does).

Challenge here is to integrate drivers, ODBC connections, and interaction between physical parts and virtual parts of the app

 

Software analyst:

Before doing any of the stuff above, we need to first see:

- What kind of environment we're affecting (WinXP boxes, Win7 boxes, Win7 VDI terminals)
- What are all the hardware and software requirements (RAM, HD space, Visual C++ runtime, etc)

- What are all the security requirements (read write permissions, network storage access, firewall ports to open)

- How do we install the software (next next next, or custome setup, choose these components, no shortcuts on desktop, etc)

Document all that shit above and once done, our packaging portion will need to do everything we wrote here in a single double-click of a script or something.

 

SCCM administrator:

That's a soft from MS that allows us to seize control and gather info from all our workstations and servers in the network to:

- Rollout or rollback any Microsoft update we want

- Mass rollout scripts

- Full software, file, hardware inventory of machines, what users logged in where, what bs they tried to run, etc.

- Mass install or uninstall whatever software was packaged above.

 

So basically, combining all the roles together, I do in order:

- Receive software to analyze and document.

- Package all that shit for a single-click install that is able to return proper error codes for reporting

- Deploy that packaged software on a schedule onto say 4000 machines in 1 evening, gather report, and submit

 

That also means:

- I know exactly what the company has on every PC

- I have access to every single license keys of the software of the company

- I know how each package is engineered behind

 

 

But then, of course, there's just so many different fields under IT you can work with, depends on your qualifications and what you aim for.

Generally speaking, people usually tend to think of IT as:

- Programming

- Network Administrator

- Windows Server Administrator

- Windows workstation administrator

- Web developer

- Database Administrator

 

But there's quite a few more people forget about:

- VMware ESX Administrator

- Linux Server Administrator

- AS400 Administrator

- Microsoft Exchange Administrator

- Security Administrator

- Project Manager

- Project Coordinator

etc...


Oh, I forgot to mention what coordinator was supposed to do:

All sorts of different project managers come to me and go:

Ya, We need this software / this drivers packaged and delivered by this date.

 

I just look at them and go:

Cool. You got all the source files we need to work with? A basic installation guide if possible?

Target production machines? Licenses bought? Planned pilot machines for deployment? Request for changes appropriately filled in?

 

If any of the above is a no:

Well, I ain't putting it in our workload until you go get me all that info.

 

If all yes:

Sure, our team is occupied on these dates, deployments are scheduled here, we can have it delivered by this date. Provide your project billing codes, I'm assigning this guy to package your stuff, allocate him 5 days of 8 hours work to your project budget for his services, bla bla bla.
