Hm... not really a point in having a good computer when the emulators can BARELY play psp games. The only one worth trying is jcpsp and that isn't an all to good emulator. Now there are two things with it:1. It's written in java, which isn't considered very efficient for this2. The psp hasn't got as much dedicated hackers as the nintendo consoles and handhelds doNow the first one isn't really an issue, I mean java might impact the performance somewhat, but the second reason is much more significant. Because people know much better how the ds works specifically, it's much easier to write an emulator for it. For the psp, there is much less documentation to be found and there are less people dedicated to write a psp emulator. So if you want to run psp games properly you have to make workarounds, which will impact performance.To give you a sketch of how abysmal the performance is, here's an example:I've got an intel i7 920 at standard clock with an nvidia gts450 graphics card and 8GB ram. All that is good enough to let the game final fantasy dissida duodecim run at a whopping 15 FPS with a lot of the sounds missing and some (minor) graphic glitches.For comparison, I'll emulate tales of the abyss on pcsx2 (ps2 emulator). The emulator has much more dedicated support so it's only natural to assume it runs games better. I run the game and it works practically fine, with a few extremely minor hitches here and there, while the ps2 is arguably more complex than the psp.Bottom line is that psp isn't emulated propely at this time to enjoy playing psp games, unless the emulator was optimized for that specific game (there are a select few). I'd just wait a few years for the devolpers to optimize the code so that the games run much smoother, because other emulators can emulate much more coplex systems with bigger ease.
