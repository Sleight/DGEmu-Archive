That's actually wrong. It's since Vista that flip 3D was made available.

What's new in Windows 7 were the thicker taskbar with preview panes, window snapping, and shake.

 

My co-worker in IT with me didn't even know about window snapping, and I was like: wtf? It's like the selling point of Windows 7 for window management.

 

For those that don't know:

Drag your window to the left or right border of the screen with resize the window to exactly half the screen (perfect to open say 2 documents or 2 folders to compare and transfer stuff), and dragging it to the top will maximize your window.

You can do the same by hitting windows key with the left, right, and top arrow.

 

Another feature, even more useless, windows shake.

Just grab the title bar or any windows and while holding it, shake it around like an idiot. Look at all the windows below minimize! Do it again, they all go back in their original positions! (very useless).

 

Other very useful shotcuts:

Windows key + E : Opens windows explorer.

Windows key + R : Opens the Run prompt.

Windows key + L : Lock your computer.

Ctrl + Shift + Escape : Opens the task manager without that annoying screen that Ctrl Alt Del brings you to.
