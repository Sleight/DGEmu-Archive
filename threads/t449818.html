FFirst Child ReiJan 13 2010, 03:07 PM
I've bought this game recently and started playing. I'm still in the beginning but so far the game didn't impress me as much as I thought it would, considering all the excellent reviews it received... I guess I prefer JRPGs when it comes to RPGs. But three things really disapointed me in this game:- the character creator: it's hard to create interesting faces and the presets don't help at all. Wish the developers worked a bit more in creating interesting characters for those that don't want to spend hours trying to create a character.- problems with input hardware support: my Microsoft mouse and keyboard are not perfectly supported in the game.- performance: the game requires a lot of computer resources. In the other hand I liked the control system and the battle system is interesting since it mixes strategy and action (still getting used to it.. died many times already... :o ). The depth of this game's world seems to be a strong point as spiralbound mentioned, characters and story have a lot of background to explore.
