Installation of the application is like any IPB application:- Upload folders to respective places from FTP.- Install through "System > Manage Applications & Modules" After installation is complete, make sure to change the points system from "ibEconomy Points" to "iPoints/IBStore/ibMarket/Perfect Points ('points')" so that our current GP system based on "Simple Points" continue functioning as it would. This is located under "Other Apps > (e32) ibEconomy > Frontpage > General Settings" Make sure to test editing options for a forum group. If you get an error like the following, read further below on how to fix it:
someone wrote:
Fatal error: Uncaught exception 'Exception' with message 'ecoclass is not an object' in [...]
To fix the issue, modify the file found in "admin/applications_addon/other/ibEconomy/extensions/admin/group_form.php" through DGEmu's FTP.Find the current line in the PHP file:$moreGroupSettings = $ecoAcpClass->buildPluginGroupSettingsSaver($ecoclass->plugins ? $ecoclass->plugins : false);Change the "false" parameter to "true", save the page, and replace the old one on the FTP with the modified one. That should fix the issue.
