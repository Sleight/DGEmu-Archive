So it’s been quite a while since the last ds emulation topic has been updated, and because there have been quite some developments in emulators on the ds over the years I figured that we needed a new topic with the best slot-1 emulators per platform. This list will NOT focus on the following:- Emulators that need a slot-2 cart- Emulators that specifically require a DSi- Emulator tied to a certain flashcartI will mention however if a certain emulator has different versions that take advantage of any of these, but do not expect emulators like the dstwo’s gba emulator to appear on this list.This topic will contain preferably one emulator per platform. I will also look at the compatibility rating of the emulator before adding it to the list. Some emulators however, are emulators that are notable because of what they can do on limited hardware, they are added to the list, but you have to take note that emulators like these can have a lot of problems.Note: most roms and emulators are usually packed in a *.zip or *.rar file, you need a program to get the actual contents from the archive. You can either use pezip or 7zip to extract files from these (an other) file formats.Note: If your flashcart does not support it, you need to DLDI-patch the *.nds file, before attempting to run the file. Most modern ds flasharts however, do this automatically.NesdsEmulates: Nintendo entertainment system, famicom disk system, light gun peripheralDownload link:: http://filetrip.net/...esDS-0-56a.html (filetrip will put up a notice if there is a new version)Project link:http://gbatemp.net/t...tes-about-nesdsA great nes emulator that has good compatibility. Initially lacked updates by the original team to fix certain games, it is now actively updated by huiminghao. Since these updates, custom hotkeys have been added, as well as light gun support and famicom disk system roms now work with the emulator as well.Notable features include: (custom) hotkeys, rewind function, debug option, save states, cheat (maker) function, light gun support, famicom disk system support, *.ini file that can be edited while the emulator is running, several display options and gesture support.Setup instructionsDownload the *.zip file from the download link. Unpack all files. You can copy the *.nds file and the *.ini file to any location on your flashcart as long as you keep them in the same folder. Your nes roms need to be unzipped (zip support is being considered) and can be either *.nes or *.fds The roms do not need to be in a specific location, but do note that it takes considerably longer to load the rom list if you have a lot of roms in a single folder.DSx86/DS2x86Emulates: 80286 processor/ 80386 processor computer (mainly dos programs)Download link:: http://dsx86.patrick...com/DSdown.html (also includes download links to some good tools)Project link:: http://dsx86.patrickaalto.com/Although still in beta, dsx86 is made by patrik aalto and has accomplished the impressive feat to emulate a pc on the ds. Be it a pc that can mainly run dos programs, or windows 3 with limited features >.>"This emulator can be very daunting for first-time users. It requires quite some steps to set up, and compatibility is not great. Updates are frequent however, and patrick aalto is very driven to make his emulator better. The emulator can map ds buttons to certain keystrokes on a keyboard by altering the *.ini file. On the bottom screen the user can either use a full keyboard, or a mouse for input. Note that there are two versions of this emulator. The normal version dsx86 can run faster on dsi if you have a cyclods irevolution or use sudohax. DS2x86 is a special version that takes the DSTWO’s built-in CPU to its advantage. If you either use a dsi, or dstwo the compatibility rises and there will also be an overall speed boost.Setup instructionsThese instructions will tell you how to set up dsx86 with 4dos. You can use another command line interpreter like commodo commander, but the maker of the emulator recommends it, and it is freeware ^.^Download dsx86 from the download link. Then go here: ftp://jpsoft.com/4dos/files/ And download 4dos.com (you can also download the other files, but they’re not necessary to run dsx86). Now that you have all necessaryfiles, make a folder called “DATA” on the root of your micro SD. Inside the DATA folder make a folder called "dsx86" Put all files you downloaded in the dsx86 folder. You can put the *.nds file anywhere on your micro sd. After that you can download the DOS games and install them like you would do with an ordinary dos program. Sonic collection appears to be using a modified version of JenesisDS with various fixes and minor alterations to make it look and sound closer to genesis sonic games.Setup instructionsDownload the *.zip file from the download link. Unpack all files. You can copy the *.nds file to any location on your flashcart. Your genesis roms need to be unzipped and must be either *.sms or *.gg files. The roms do not need to be in a specific location. You first need to load the game, then you can insert cheats, and after that the game can be loaded. Save states are supported, however, you must either access the menu while the game is still running, or choose to make a save state if you change the game.JEnesisDSEmulates:: Sega Genesis/megadriveDownload link:: http://filetrip.net/file.php?id=4562Project link:: http://www.workingde...s/jenesisds.php (download links have been removed)Not perfect, but does run a good deal of games. The emulator features vertical scaling, to make it fit the ds screen, but horizontal scaling is not supported. Instead, the user can pan the view to the left and right with the L and R buttonsFurther development has stopped, because the author of the emulator, Lordus, was probably approached by sega to help with the development for the sonic collection for the ds. You may need to switch the emulator to either NTSC or PAL in order to make the emulator run the games correctly.LameboyEmulates:: Gameboy, Gameboy color, Super GameboyDownload link/project link:: http://lameboy.nutki.com/A lot of people were disappointed that the original ds and ds lite did not support gameboy and gameboy color games, despite having gba slots. This emulator has good compatibility and quite some features and a pretty good replacement for a gameboy advance. Developed by the nutki team, lameboy supports super gameboy borders and colors, scaling options, a menu that can be easily accessed by buttons, fast forwarding and save states that can be saved to several slots.Setup instructionsDownload the *.zip file from the download link. Unpack all files. You can copy the *.nds file and the *.ini file to any location on your flashcart as long as you keep them in the same folder. Your gb/gbc/sgb roms need to be unzipped and must be *.gb, *.gbc or *.sgb files. The roms do not need to be in a specific location.Special note: Lameboy does not save games, unless you exit properly. You can either exit and make a save state, or make the emulator apply the changes made in the game to a save file.A5200DSEmulates:: Atari 5200Project link/Download link:: http://gbatemp.net/t...lator-dsi-entryMade by Alekmaul, this is pretty much a no-nonsense emulator, and is nearly identical to stella ds and A7800DS. There are barely any options to be configured and the only settings that can be set are the in-game settings, or changing the controller to the paddle. Emulation lags a bit throughout games, distorting the sound effects somewhat, however, the overall slowdown does not significantly impact gameplay. This emulator is also compatible with the dsi, giving it an overall speed boost if used with sudohax, or with a cyclods iEvolution. Has a very high compatibility with roms.Setup instructionsDownload the *.zip file from the download link. Unpack all files. Put the *.nds file wherever you want, preferably in the same folder as your atari 5200 roms (note: if you have a lot of roms in the same folder, it slows down loading the file list) because the default rom folder is the folder A5200 is in. You also need the bios (“5200.bin”) which is in either NTSC format, or PAL..
