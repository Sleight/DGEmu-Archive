Please, CAREFULLY review programs you choose to use for compatibility before you download. Many programs have a separate version specifically for 64 bit operating systems.Please, ensure that tools are "Run as administrator" in Windows Vista and 7.The Recommended Procedure:1. Check for spyware/malware/viruses and eliminate them as per your suspicions using Malwarebytes' Anti-Malware or the Emsisoft Emergency Kit if it's in a bit more trouble than your average machine. Update definitions before you scan. Neither offers latent protection for free. You have to pay for it.Comodo Internet Security takes the prize for the most complete prevention system, free or otherwise.My thoughts on Anti-Spyware/Malware products are presented in further detail near the end.If you are really infected, you may take out your hard drive and scan it from another computer as an external USB drive by using an enclosure.Rootkit.Win32.TDSS escapes most conventional scan methods. ComboFix detects it, but it won't necessarily clean out the infection. In cases where Kaspersky's TDSSKiller fails, Norton's FixTDSS will do the trick.2. Update Windows and all other installed software including drivers. Try and retrieve drivers manually from a component manufacturer's website or find it from the system manufacturer in limited cases. This includes chipsets, graphics cards/display adapters, audio cards, network adapters, printers, and other peripherals. Use the Device Manager to figure out who made what on your machine. BIOS and firmware updates carry a certain level of risk for your machine, but the rewards can be great. Update your router as well whenever possible.When running Windows Update, make sure that you are updating all Microsoft software by using the option to switch to Microsoft Update (Windows XP) or by looking for the option to scan for all Microsoft products (Windows Vista and 7). Remember that although there may be entries listed in the optional section for Windows updates, those updates are usually recommended as well.Install any necessary tools for future steps and include any additional software. Have any desired portable software ready on a flash drive. Anything that can be used as a portable application is best used as such, except for something that has constant utility such as CDBurnerXP or something like 7-Zip or PeaZip.Remove any software you no longer wish to use and clean out any other undesirables.Below are tools (all portable) to help you remove stubborn things:AOL Removal ToolMcAfee Consumer Products Removal ToolNorton Removal ToolPC DecrapifierRemove Office 2007Unlocker (portable version available) - Great for stubborn files/folders that refuse to be deleted. Use with caution.Special Notes: Personally, I endorse Google Chrome as the most effective browser. Adblock Plus is a must have extension for it.Regardless of the browser you actually use, it is still important to update Internet Explorer even if you're on Windows Vista and you don't need it to do Windows Updates. Too many things are tied into IE still. Update all browsing components (i.e. any toolbar that you actually use, Java {64 bit acquired by going to the site on IE 64 bit}, stuff from Adobe like Flash and Reader, etc.) on both IE and your preferred browser (get both versions of Flash regardless of what browser you use).Pay the same attention to Windows Media Player as you do with IE in terms of updates and run/configure each at least once (special thanks to TheAnonymous). Please update all other media players and file format viewers used as well.Remember that after updating Java you should check Add/Remove Programs or Programs And Features in your Control panel to ensure you only have the very latest version of it installed. It seems that before a certain version of Java, Sun preferred to retain old runtimes rather than replace them.Gamer's Note: Gamers should take special care to update DirectX to the newest version. Manually downloading from here and running the update is the only way as Windows Update does not cover DirectX SDK updates. The latest release was made 04/18/2011.Windows XP specific note: Please go to the Windows feature/component installation and ensure that MSN Explorer isn't checked. Remove it if it is installed. Run all cleaners as well for the Administrator account. Run cleaners once per account.8. Run command "fsutil usn deletejournal /n c:" in Safe Mode under the built-in Administrator's account.9. Let whatever indexers (i.e. Windows Search 4.0) compile their databases, let all protection software update their definitions, and let all disk activity settle down before restarting. Do this for all user accounts (you may choose to log off and log in instead of rebooting/restarting if you are switching user accounts).12. Run command "fsutil usn deletejournal /n c:" then run MyDefrag's "Optimize Daily" script.13. Run command "fsutil resource setautoreset true c:\". Reboot and repeat step 12.14. Re-enable System Restore if desired (those preferring speed over redundancy based protection will choose to opt out of this).
