K.O' post='2479095 wrote on May 3 2007, 03:24 PM:
What's the difference between "Real Support Clean ROM" and "Common Support Clean ROM"? And why should this entice me?
It's not always easy to tell when it comes to broken english, but from what I can gather from their claims: Common Support Clean ROM: You don't have to patch roms before transferring them to the card (Clean ROM), but the cart modifies the ROM on the fly to get it to work with its hardware. Wifi and download play support can be patchy, since a lot of games don't respond well to the changes outside the flash cart.Real Support Clean ROM: You don't have to patch roms before transferring them to the card. The card then runs them directly without modification (Real Support). This would theoretically allow 100% wifi and download play compatibility, since the data you send over wifi hasn't been altered.The Real Support Clean ROM thing is apparently false though, which is one of the big letdowns. Wifi/download play support is the same as other slot-1 solutions like the R4, SC-1, etc... The R6 Real has essentially turned out to be a fixed-size M3S, much like the G6 Lite is a fixed-size M3 Lite.
phoenix121' post='2479134 wrote on May 3 2007, 03:35 PM:
I know it was said to be impossible, and I heard a rumor that it might be able to, so I just asked.
You must be in GBA mode in order to run GBA games, and being in that mode cuts off all access to NDS-only hardware, making it impossible for a GBA game to read its data from slot-1. You can't switch back to NDS mode once in GBA mode, so "swapping" methods are out as well. You could work something out with additional hardware, though... Like a slot-2 cartridge with some RAM in it. You would "run" the GBA game from the slot-1 cartridge, which then copies the rom to the slot-2 RAM pack and switches to GBA mode.
KyuubiWarrior' post='2493106 wrote on May 7 2007, 05:34 AM:
And I don't see why they think built in memory is a bonus, now you're limited to just that much memory.
The upshot is that devices with built-in memory use NAND flash, which is slower to write to but much faster to read from than the NOR flash used in SD cards. Card speed is not an issue with NAND devices.
