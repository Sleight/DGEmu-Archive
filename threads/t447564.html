The site used to covert saved games is:ShunyWeb Savegames ConverterConverting a GameFAQ/Flashcart/No$gba save file to a Emulator/FlashCart save fileSavegame to convert:Click "Browse ...", find the save file you want to convert.Source format:Select the format of the file you selected above. For example, if you are converting a file from GameFAQs then most likely you will select "Action Replay Max DS (.duc/.dss)"Target format:Select the Format that you require to use on your Emulator/FlashCart, for example No$GBA (.sav) files or M3 Simply/SuperCard FlashCart (.sav) files. For DeSmuME use the "Acekard RPG | EZ Flash V | RAW Format (Autodection) [.sav]" format (more below).Converting a No$gba save file to a DeSmuME save file1. Go to File -> Import Backup Memory2. Look for your No$gba .sav file, which is inside the BATTERY folder. Select it.3. Import it, and load your ROM as per normal.Converting any other save file to a DeSmuME save file on Shunyweb1. Convert the file using the correct Source format. Select "Acekard RPG | EZ Flash V | RAW Format (Autodection) [.sav]" as the Target format.2. On DeSmuME go to File -> Import Backup Memory. Select the save file you've just converted.3. Load your in-game save as per normal.Converting a DeSmuME save file to a Flashcart's save file1. Go to File -> Export Backup Memory on DeSmuME. This will produce a Raw Format save file.2. Go to the Shunyweb Converter. Use "Acekard RPG | EZ Flash V | RAW Format (Autodection) [.sav]" as the Source format, Target format is the format the flashcart uses as usual.Alternatively, use the UniqueGeeks Online Converter, or download and use its Offline Converter. These support the DeSmuME save format directly, so you don't need to Import Backup Memory.UniqueGeeks does not support the No$gba sav format though, so you need to convert your No$gba saves to Raw saves before conversion:Close No$gba/No$Zoomer. Go to NO$GBA.ini. Change "SAV/SNA File Format == Compressed" or "SAV/SNA File Format == Uncompressed" to "SAV/SNA File Format == RAW". Save your changes.Go back to No$gba or No$Zoomer, run your ROM, save your game normally using the in-game save. This will produce a Raw save.More:NDS Emulation FAQNDS Flashcart FAQDeSmuME FAQ - "Can I convert a save file from (a different format) to DeSmuME .dsv"
