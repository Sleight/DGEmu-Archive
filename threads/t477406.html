The Playstation network hacking was not as detrimental as you think. All that was hacked was the account login server and only some usernames and passwords were hijacked. Credit card numbers and what not were stored in a different, more secure server. Now that doesn't say that playstation network is easy to hack, all it says is that Sony didn't think to far ahead when they made it.

The controller thing is a non-issue because on the PS3 there are Xbox 360 style/shaped controllers available. same with how the Wii can use Playstation 2 controllers if you have the right devices. (ps2 to gamecube or ps2 to wiimote connector cable.)

As for the games looking better on one system over the other, that is not an issue of whether the system has more power, it's a matter of which system the game was originally written for because all they do is recompile them with control changes programmed in to match the system it is compiled on. So if the game was originally written for a PS3 then compressed and compiled for xbox360 then of course the Xbox version is going to not look as good because the ps3 has more data room on it's media. but if it's a xbox360 game recompiled for PS3, the game won't look any better but the controls will likely be less responsive or less intuitive due to the way the ps3 controllers analog shoulder triggers and the way the analog sticks are set. An even worse example is if the game is set up for xbox and going to the Wii, How do you make a game that has a controller in mind work with a wii's control set? Usually that ends very badly in control and graphics. That is why Wii versions tend to use different game engines I figure.

Usually though between xbox360 and PS3 the only thing you gain from PS3 is the possibility of less compressed textures and audio. All that comes from the higher data space on the BluRay, but you already knew that didn't you?

Now I am not a Sony fanboy, just wanted to set the record straight on that one. I would personally get the PS3 because of the utility of the system and lack of extra costs beyond the device for subscriptions and what not. The main thing I would want the xbox360 is for the Forza games. That is it for the reason for Xbox360, It really is all a matter of what games you are looking for. if you don't find the exclusives for one system appealing, then get the other one. Always check the exclusives. that is where your choice should be based. My rule of thumb for video games is the system must be reasonably priced, have all the features I expect in a game system, and have at least 10 exclusive games that I would want to have.

To tell you the truth I think this topic was just created to incite rage in the way that trolls tend to do.
