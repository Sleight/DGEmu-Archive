KKHRSNov 23 2011, 05:08 PM
wow, I just looked at the guide and they make it look a lot more complicated than things need to be, but it's a very thorough/well put together guide. Basically, the only things you'll really need your SD card for is Apps or Wads. Apps are things you run in the homebrew channel (i.e. Wad installer, emulators, etc.) and go in the Apps folder. .WADs are usually installed into the Wii (2 kinds, ones that install internally and ones that install as channels on the wii menu) so once you install whatever WAD you need you're done with the .wad itself. You only need the SD card if you want to run apps and a few other things (i.e. downloading game covers for your USB loader). Once you have a channel that can run your wii ISOs you're good, the SD card isn't crucial. Although one thing I have to specify is FORWARDERS. Forwarders are channels (channels on the wii menu that basically work like desktop shortcuts) that run Apps (located on the SD card) directly off of the wii menu instead of making you go through the homebrew channel and stuff. If you try to run a forwarder without an SD card it probably won't work (I haven't tried it yet, just recently started using them). Also, don't go to the shop channel, you need to install something or nintendo will put their finger up your butthttp://7cde333f.dyo.gs/this (I think) lets you enable shop channel (taken from the same guide on wiihacks), should you need to visit it for some reason. If you want games and stuff click on the link on my profile that leads to a bunch of wiiware and stuff. Download the .WAD files, place them in the "wads" folder on the root of your SD. install them using a WAD Installer/Manager (in the apps folder) and bada-boom bada-bing(the only time I've needed to be able to visit the shop channel was to "re-download" the DLC for Just Dance 2)
