QqcarachatoDec 12 2006, 11:04 AM
Question: what is the difference between Mod Preview (member warning) and Flood Control (mod util)?Not really sure on how to use the last one.
AatomicknightDec 12 2006, 02:31 PM
Mod preview allows the user to post but requires a moderator to approve the post before it is shown on the forums. Flood control suspends the user for some amount of time, essentially preventing him or her from posting or doing anything on the forums.In essence, use mod preview for possible spammers and flood control on flooders (hence the name). Using flood control almost invariably leads to a ban, so just keep that in mind.But yeah, currently the only way to put someone under mod preview is to warn (or to do it via ACP). Making a script should be pretty simple though.
