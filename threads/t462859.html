Another option is to rename the save file once you make a copy of it.The VBA uses nameofgame.sav as the save file. To get it to work in VBALink, you rename the file you copied to nameofgame.sa1 (This save will open in the first VBALink that you open). If you want it to be in the second VBALink than rename it to nameofgame.sa2.
