SshadowmanwkpJun 26 2010, 07:45 AM
Snapshots (or commonly referred as save states) only work for gba games in no$gba if you try to use them for DS roms you will crash no$gba. Only DeSmuME supports save states for DS games and if I'm not mistaken they don't work with different versions... I don't think you can convert gba snapshots from no$gba because the emulators aren't made to work together, so you practically have lost all progress up to the point you saved normally....In the pinned topic about converting saves there are also special instructions on how to convert no$gba saves to DeSmuME saves. This may not help you now, but it may help you in the future if you want to convert normal saves.
