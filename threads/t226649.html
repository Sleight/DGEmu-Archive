MAME Plus!/MAME32
MAME Plus! is the recommended version of the emulator to use, although it is an unofficial build/update of the original MAME/MAME32 versions, so if there are any problems/major bugs in coming releases, then it is recommended that you try one of the MAME32 builds or an older version of MAME Plus! Another thing to note about MAME versions is that some ROMs get updated now and then, and some of the older versions of ROMs do not work on newer versions of MAME. So, if one of your ROMs does not work on your latest version of MAME, try to download an earlier version to play it or get a newer version of the ROM. Ok, so this guide is here to teach you the basics about getting started on MAME, in case you don't know already. So first, let's make sure you at least have the emulator.

Getting Started
Now that you have downloaded the emulator, you should set everything up so you can play the ROMs properly. Firstly, you should create a folder to store all of the files that come with the download. If you have 0.64, then all of the files necessary for the program will be bundled and you need to extract them all into one folder. If you have 0.95, then when you run the installation exe file, you will need to show what directory to install everything into. It's ok if you didn't create a directory beforehand; you can just direct it into a new folder that doesn't exist yet and the program will create that folder for you. So basically, just make sure all the files that come with the downloads are put into a single folder designated just for the program. This is essential for making everything easier.

The next step in setting everything up is to put your ROM files in the correct place. In the folder with all of your MAME stuff, there should be a folder titled "roms". The only file that will be in this folder when you first install everything is "dir.txt". Quite simply, this folder is where you are going to put all of your ROMs, unless you want to make things harder for yourself. So, when you download a MAME ROM from DG (or anywhere else, I suppose), put it into the "roms" folder that is already there. There is no need to unzip or rename anything. Doing so is likely to make things not work.

ROMs downloaded from DGEmu come bundled with all versions of the ROM necessary for playing the game, so it is best to download them from here. Something to note if you download from other places though is that if it is an expansion ROM, such as Super Street Fighter 2 Turbo, then it is necessary to also have the original ROM, which in this example is Super Street Fighter 2, in order to play the game. So make sure you have all parent ROMs and subroms necessary before trying to play.Now, to get to playing the games. When you open MAME, on the left hand side of the screen you will find a list of directories set up in a menu. On the top of the list is a folder called "All Games". "All Games" is just a list of all the games that can be played on the emulator. It is not the games that you already have available to play. In order to get to these, go to the folder called "Available" directly under it. Whenever you add new ROMs to the "rom" folder, go to the main screen of MAME and press F5 (the Refresh command for MAME). This should put any added games into the "Available" folder on the left side and allow you to play them. Once you have the game you want to play in the menu, double click on the title to start.

When the game starts up, you can easily set the controls you wish to use for that game by pushing Tab. If you want to only set the controls for the game you are currently playing, select "Input (this game)". If you want to set general controls for all the games in your list, then select "Input (general)".

This is basically all of the essential information you will need to start playing ROMs on MAME. You should be on your way to a good time now if you read all of this carefully, or at least looked at the bolded parts. Have fun!

Network Play
The easiest way to start a network game is to right-click the game that you want to play and select the "Play Network Game" option. Alternatively, you can highlight a game on the list and then go to File->Play network game. When you do this, the server screen will appear. When this shows up, the program will start generating the list of servers you can play on. The servers with the lowest ping will usually be at the top of this list. At the bottom of the screen, you can input a username and change the connection type that it says for you. It is recommended that you select the server with the lowest ping when you want to play. There are other tabs on this screen that you can go to, as well. The "Waiting Games" tab shows you people who are waiting for someone to connect to their server and play with them. The "Recent" tab is a list of every server you have ever been in, with the most frequently visited ones on top. The other tabs are very self-explanatory. This should be enough information for you to start enjoying network play if you wish to use that feature of MAME.

MAME on Linux
This guide was written by Manatee x360a.org

This guide was written for all of those linux guys out there like me. I used Xubuntu 7.04 Feisty Fawn, but Kubuntu, Ubuntu, Red Hat, and anything Debian will work this way.You might to get some Graphical and Sound libraries and GTK runtimes, but a quick run in Synaptic should do the job.The best emulator for Linux is AdvancedMAME. It has not received an update in close to a year, but it is the smoothest running without having to get WINE involved. The link to the advancedMAME site is here It utilizes Mame 1.06, which is a pretty stable build with good compatibility. You´re going to run the games you´re going to want to play, so that fixes that.

Once you tar or unzip AMAME, Running advmame in konsole, shell, Gterm, or terminal will tell you to set up a configuration file, which you can do with advmame --default. Once done that, you can to edit your ~/.advance/advmame.rc file. Under the dir_rom entry, you can change the directory if different than default, which is ~/.advance/roms/.

As always, all of the ROMS are available here at DGEMU. Starting up a game is as simple as advmame romname. As long as the ROM you want is in the right directory, it should start up quickly. At first, the navigation might seem a little complicated, but you will get a grasp on it quickly. Once inside, you can push your TAB key to open up a menu which allows configuration of all kinds, video, input, audio and so on. Luckily, gamepads are supported, so fun is only a few minutes away.

I highy recommend an Xbox 360 controller for the job, Xpad360 modified drivers are available Here Configuring that is in the attached thread @ ubuntuforums.org. Your methods may slightly differ between distributions, but those instructions worked in xubuntu.

Capcom Play System 3 (CPS3) Emulation on MAME
The Capcom Play System 3 (better known as CPS3) is a semi successful arcade board that hosted only a few, but good games. The hardware featured 2-D fighters that are rich in audio and visuals. Some people actually consider the CPS3 as the best 2-D arcade hardware since it's raw power and storage space allows for fluent animations and high quality sound.To start on our CPS3 journey, we will need a few files to start with; the ROM itself (found here), the CHD and the NO CD files which I hosted here:
http://www.megaupload.com/?d=1VB6OZSK
And the latest version of MAME++: http://ddememame.hp....119-20070917.7z
1) First thing's first; create a roms folder, since the 7zip doesn't come with one packed in, this will be where all your roms are going to be held.

2) Next, take your sfiii.zip, sfiii3_chd, and sfiiin.zip in the roms folder. This is what it should look like:

3) Now that we have our roms in place, its time to configure MAME, open mameppkgui-vc.exe. Wait until the emulator searches for available ROMs. Click the 'Available' tab on the side to see the games that are playable. Please continue with this guide, regardless of what games appear on screen.4) Go into Options > Directories and find the folder where your MAME++ roms folder is held and browse to it, OK out of both screens and wait for the emulator to search again:


5) Now, go back into Options and choose Default Game Options. By default, the setting Run In Window is unchecked, make sure to check that box if your system isnt quite up to snuff. Adjust Display settings to fit your needs

6) Once the game loads, follow on screen instructions to begin emulation, hit the Tab button to configure your game and start playing!

Neo-Geo Emulation on MAME

MAME is also capable of playing Neo-Geo ROMs. You only need one additional file to do it, too! It's a pretty simple process. First, make sure you have read these instructions if you have no set up your emulator already:
Downloads
Getting Started
Next, download the BIOS file for the Neo-Geo system, which I have hosted here:
http://www.megaupload.com/?d=02GZLOCR
*WILL NEED TO REUPLOAD SOMEWHERE!*

Once you have set up your emulator, extract the BIOS file called NEO-GEO.rom (it is compressed in RAR format, so download WinRAR if you haven't yet) and insert it into your "roms" folder. You can also put all of your Neo-Geo ROMs inside of the folder with it when you get some. Now just open up the emulator, push F5 to refresh everything. and BOOM! You are all set to start playing Neo-Geo games! Simple. :)

Everything else is set up as the same way as most MAME ROMs are, including the settings. So refer to the first section of the guide to solve any problems that may arise. Of course, if the link for the download dies or you face additional problems, do not hesitate to ask me or another qualified staff member for assistance.
