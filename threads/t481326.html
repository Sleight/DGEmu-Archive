Find here all the albums released by EastNewSound. It is sorted by alphabetical order instead of release date so that you can easily find the albums you want.

For more information about this group, visit this page: http://en.touhouwiki.net/wiki/EastNewSound

A preview of the whole Sacred Factor album can be found here: http://www.dgemu.com/forums/index.php/topic/475414-eastnewsound-sacred-factor/

 

All these releases are in MP3 format (320 or VBR), and may or may not come with scans.

If any of these links go down, don't hesitate to reply to the topic or PM me.

You will need WinRAR or 7-Zip to be able to extract the files. See below for more information.

 

The password to all archives is: doujinstyle
