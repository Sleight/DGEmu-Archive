In short Perl is an interpreted/scripting language. Most people will say that it isn't technically a programming language and they are correct since you can't compile the code and have it run without an interpreter on the target platform. And since most people only care about running stuff on mainstream PC OSes they don't care that an interpreter is required since it is already built and included for the main platforms.
