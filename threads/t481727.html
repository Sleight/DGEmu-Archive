Kiririn-shi wrote on Nov 28 2006, 06:44 AM:

Q: How can I get my VBA save file to VBALink save file or vice versa?
A: There are two options that you can do. Either...
1) You can use the import and export function to transfer the file over to the other emulator. In VBA, you would export the battery file. In VBALink, you would import the the battery file. If you want it the other way, than do export in VBALink and import in VBA.Or...
2) You can make a copy of your VBA save file (nameofgame.sav) and rename the save file to nameofgame.sa1 (first opened VBALink will see this save file), nameofgame.sa2 (second opened VBALink will see this save file), etc... To get it from VBALink to VBA, you rename the save file from nameofgame.sa1 or nameofgame.sa2 to nameofgame.sav.

Should be similar enough for No$GBA to VBA .... if the No$GBA saves a .sav file then simply open VBA and select IMPORT from the menu (File menu most likely).
