BlakGost' timestamp='1324747101' post='4983022 wrote:
I downloaded a file but it won't open when I try to open it. Any solutions?
When you download a game from dgemu, it's compressed, this means that you have to extract it before you can play the game. All of our files that are hosted on the site (this means the main site, not the download center) are compressed as *.zip files. By default, windows xp and up can extract zip files. To extract zip files, select the file that you want to unzip and right click on it. After that choose the option "extract all" after choosing this, just follow the instructions given to you. After that the zip file is extracted and you will get a few things: a html file, an nfo file, a jpg file and the nds file. The html file and nds file are always included, the others are optional. The nds file is your game, the html file lets you know what site you downloaded the game from, the nfo file gives you some info on the game (you can open it with the notepad) and the jpg file is a screenshot. If you do not have the option to extract all, or if you're on a lower windows version than xp, you can install either 7zip or peazip to extract it.
