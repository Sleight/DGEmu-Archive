However, it is developping rather quickly and can run quite a few roms.Below are the instructions to run the emulator and a FAQ.[center]----------------------[/center]Read the instructions properly and thoroughly. Anyone who asks a question where the answer is posted here already will have points deducted.1. How to Use NeonDS?STEP 1: Download the emulatorThe latest version of NeonDS can be found at the official site (mirrors here). Download the latest version, then create a new folder and extract the emulator therein.STEP 2: Download the romsAll NDS roms can be found on DGEmu.STEP 3: Install the latest DirectX9To see whether you need or not to do this step, just open the emulator (double-click on NeonDs.exe). If an error message appears about a missing file d3dx9_31.dll, then you need to install the latest version of DirectX9. Otherwise, ignore this step.If you are using a genuine copy of Windows, then download it from here (click on "continue"). If you are not using a genuine copy, then I have no idea about whether it will work or not. Use Google or P2P network to find the installer. I (or any staff) may upload it later if I find the time.STEP 4: Open the romsUnzip the rom. Honestly, if this didn't occur to you, you shouldn't be here.Just open NeonDS emulator. Two windows will pop up: one named "Display 0.0 fps" (designated below as "Display" window) and the other "Untitled - NeonDS" (designated below as "Control" window). In the "Control" window, go to File->Open, chose a rom and click on 'OK'.STEP 5: Set the save typeAfter you opened a rom, you will be asked to choose a save type.You can find the save type at PocketHeaven or at dualscene.If the information is not available, try all possible save types until you find the good one (tip: EEPROM 64KBytes is the most used as of yet, start with this one).STEP 6: Run the romsClick on the "Control" window, either maximize the window or scroll down. Then on the bottom right, there is a button named "Run". Click on it to make the rom start or you will wait an eternity for nothing.[center]----------------------[/center]2. Frequently Asked QuestionsQ: Is NeonDS a good emulator?A: Not bad at least.Q: Where can I download it?A: Read the step 1 above.Q: Can it play all roms?A: A partial compatibility list can be found here.Q: An error message appears then the emulator shuts it down, what's the problem?A: Change the color quality from 16 bit to (Highest) 32 bit.Q: Does it support save?A: In-game save only, read the step 6 above to set the correct save type.Q: Can it save state?A: No.Q: Does it have sound?A: No.Q: How can I use cheats?A: You can't.Q: Can I use link and wifi?A: No.Q: How can I enlarge the screen?A: You can click Config -> 2x display to enlarge the screen, but framerate will drop considerably.Q: How do I rotate the screen?A: You can't. Only DeSmuME and iDeaS support screen rotation at the moment.Q: Some games require microphone support, does NeonDS have it?A: No.Q: Can NeonDS play Pokemon Diamond and Pearl?A: No.Q: Does NeonDS have a Mac or Linux version?A: No, only Windows.Q: OMG, it's Ody!A: It's not a question...Credits: Ody, RockmanRotties, phoenix121Edit:7/10/08 -0.2.0 released. 7/12/08 -0.2.1 released.GBATEST
