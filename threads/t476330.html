This guide is intended for staff that will test the new DGEmu Arcade in development.

What will be needed:
- A simple text editor such as Notepad or Notepad++
- Filezilla FTP Client

Configuring FileZilla FTP Client
- Launch FileZilla.
- Navigate to File > Site Manager.
- In the new windows, click on "New Site" and give it any name you want.
- Select the new site from the list on the left.
- Enter all the information in the following sections and click "OK" when done:
General tab
Host: mhhq.serveftp.net
Port: 21
Protocol: FTP
Chiffrement: Simple FTP Connection
Authentification type: Normal
Username:
Password:

Transfer Parameters tab
Transfer Mode: Active
