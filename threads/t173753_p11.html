@erich1008, If you have v2.6a, you can skip step 5 since v2.6a has automatic save detection. If you are not using automatic save detection, you have to reset the emulator since the emulator will use the save type that it was set on when it was started. So if you start the emulator with EEPROM 64KBytes, and you change it to a different save type, the emulator will still have the same settings as it started. This is the reason to reset the emulator. After that, you can play the game and use the in game save.
