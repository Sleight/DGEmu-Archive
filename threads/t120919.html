HHound Of ChulainnORIGINAL POSTMar 29 2006, 08:21 AM
Anyone brave enough to still venture into them knows that the console forums are a mess, but particularly the Help, Hints & Tips sub-forums. I would guess that a good 33% of the threads in these sections are created solely for the purpose of getting points and with no actual need for help.Then, these topics get filled with the most inane posts: "check gamefaqs", "use cheats", and the ever-popular: "paraphrase what everbody else said" post.Part of the problem as I see it, is that so far, there is a different thread for every different problem and piece of advice sought. There are 12 pages of topics in GBA HH&T for Pokemon Emerald for example, and I don't even want to think about how many there would be for any of the Final Fantasy games. So I'm proposing that there be a single official help topic per game, and automatic warnings for new ones. I thought about the practicalities of merging existing help topics, and decided that it would render the end result useless and unreadable; (it'd be even nicer to be able to delete the dead ones, but the n00bs complain enough as it is). But I still think that creating an official topic for the big games would stop these sections getting any worse.I'm also proposing that automatic warnings be given out for the afore-mentioned "check gamefaqs" answer. Most people don't bother to check if gameFAQs actually has a walkthrough for a given game, but even if they did, it's a no-brainer. It's just a lazy answer that gives easy points.Anyway, if you have any feedback, or you want to point out glaring flaws in my idea, go ahead.
