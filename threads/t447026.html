Yeah as the topic title suggests, The DesMuMe guide is definitely going to need to be updated. DesMuMe seems to have come a very long way since its last official release and as I might have told some of you on MSN, it's now gotten to be far better than even no$gba 2.6a (about time another emulator caught up and you can finally throw away those third party applications that try and make no$gba better despite the authors lack of updates (e.g. no$zoom, etc)). I have now changed the NDS Emulators Download page to point to (and recommend) the latest build of DesMuMe instead of no$gba. I have already tested it quite a bit and while this is not a final version (feels like a release candidate to me), it's stable enough for general usage. I will update the page again when the official v0.95 is released.Now getting back to the guide, here are some examples of changes that would need to be made. Perhaps someone can do some testing with DesMuMe as well but if not, I can start re-writing the guide myself:
someone wrote:
Q: How can I use cheats?A: Unavailable as of yet.
That is now FALSE. The latest SVN fully supports cheats including editing memory addresses directly and even "action reply" codes.
someone wrote:
Q: How do I make Megaman ZX work?Read this post.
Megaman Zx "just works" now without any tweaking required (thanks to the improved save type autodetection).
someone wrote:
Q: Some games require microphone support, does DeSmuME have it?A: No.
Yes!!! :(But seriously, microphone support has been added. I am not sure if it only supports simple "blowing" or if voice commands will work (I have only tried games like Bomberman Touch and Ontamarama).There are of course many more these FAQ entries that need to be updated and DeMuMe has many more features worth mentioning as well. For example, under "3D Settings", you can choose "Software Rasterizer" instead of "OpenGL". I found games work better with it (e.g. Dragon Quest V no longer has those black screens thus making the game fully playable). This reminds me of when the author of no$gba introduced his alternate rendering engine that worked far better than the original OpenGL. Now the same thing has happened with DesMume.There is of course a lot more to cover too such as how Phantom Hourglass is fully playable whereas before it would lock up with a white screen in previous versions or just refuse to retain your saved games.
