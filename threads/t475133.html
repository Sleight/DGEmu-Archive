You mean on your personal web server?

You will need to load them as an applet with parameters.
For vnes:

<applet archive="vNES_215.jar" code="vNES.class" height="480" width="512">
<param name="rom" value="rom.zip" />
<param name="sound" value="on" />
<param name="stereo" value="on" />
<param name="scanlines" value="off" />
<param name="scale" value="on" />
<param name="fps" value="off" />
<param name="p1_up" value="UP" />
<param name="p1_down" value="DOWN" />
<param name="p1_left" value="LEFT" />
<param name="p1_right" value="RIGHT" />
<param name="p1_a" value="X" />
<param name="p1_b" value="Z" />
<param name="p1_start" value="ENTER">
<param name="p1_select" value="SHIFT">
<param name="p2_up" value="" />
<param name="p2_down" value="" />
<param name="p2_left" value="" />
<param name="p2_right" value="" />
<param name="p2_a" value="" />
<param name="p2_b" value="" />
<param name="p2_start" value="" />
<param name="p2_select" value="" />
</applet>


Just replace what you need. Preferably, no spaces in the filename of the zip file to avoid issues.
Also, if you use zip files, makes sure the compression is set to Normal and nothing else. The emulator might fail to load the rom if zipped otherwise.
For full compatibility, you can just upload the .nes file onto your server, but loading the rom will eat more bandwidth.

Another note:
I don't recall, but I think vnes was the emulator that when downloaded, you had all your class files apart.
You can jar them up with the Java SDK like I did for better file management.
