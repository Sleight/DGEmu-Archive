Don't open any thread about which game is compatible with which emulators. Test it yourself, you are almost sure to make it run on one or another emulator. Warn and/or points reduction will be issued otherwise.Since most games now work either on No$gba, iDeaS, NeonDS or DeSmuME, there is no more point to maintain the compatibility lists for all emulators.
