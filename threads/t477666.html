Here's an interesting tool for people who are audiophiles. a few weeks ago gbamusripper was released. This tool rips most music and sound effects from a gba game and turns them into midi file, with an accompanying file that contains all instruments. It works with about 90% of all gba games.

Link on RHDN: http://www.romhackin...ic,14785.0.html

How to use

1. Download and install the java runtime environment here: http://www.java.com/...nload/index.jsp
2. Download gbamusripper here: http://www.romhackin.../utilities/881/
3. Extract the whole package by using an extraction utility like 7zip, which can be found here: http://www.7-zip.org/
4. Navigate to the extracted folder. Put your gba game in the "bin" folder
5. Open your command prompt by going to start-->command prompt (operating systems up to windows XP) or by going to start and type in cmd and hit enter (windows vista and 7). A black window with white text should appear
6. Type in the black window cd, followed by the folder where you just put your gba game in and hit enter, for example: cd "C:\Users\<username>\Desktop\gbaMusRiper_v1.1\bin" NOTE: you need to use double quotes this time, if there is any space in the folder path, you will get an error
7. Type in java gbaMus.GBAMusRiper "<gba game filename>.gba" (use the double quotes this time as well) and hit enter
8. If the game is compatible, your midi files will be put into the bin folder.
9. Download and install the bassmidi driver: http://www.mudlord.info/bassmididrv/
10. Go to the bassmidi folder in your start menu and choose configure bassmidi driver
11. go to the tab soundfonts (port A) and hit add
12. Navigate to the bin folder of gbamusripper and select the newly created *.sf2 file
13. Go to advanced and change the default midi driver to bassmidi driver(port A)
14. Your media player should now be able to play be the midi files correctly

Don't forget to change the *.sf2 file when you load music from other games! Change your midi driver back to the GS wavetable if you want to listen to regular midi files!

Note: you can use an *.sf2 file with the inappropriate midi files, but this will sound horrible.

More detailed functions are explained in the readme file.
