What you need:
1. a PS1 game that has not already been posted.
2. ImgBurn can be downloaded here. There are a few programs you can use, but I'll go over how to use ImgBurn.
3. A zipping program. I'd recommend this one here.
4. It helps to have at least a basic account at mediafire, filefactory, etc. Whichever you prefer.

That's all you need. No modding necessary.

Instructions:
Open ImgBurn. You should see this screen:



Click the button that I highlighted with the black box that says "Create image file from disc". It should look something like this if you don't have a disc in your drive yet:



If you haven't already, put the Playstation disc in your CD-ROM drive. Give it a sec, and ImgBurn will analyze what you've inserted and look something like this:



First, you may want to set where it saves the image file to. Do this by clicking here:



It will pop up a Save As menu. Select the folder you want to save it to. I suggest creating a New Folder just for this Image. This is also the only point at which you can alter the name of the image if you want. Once selected, you'll be back at the last screen with the location updated. Now, there's a nice big button at the bottom here:



Click this and it will start ripping. You have some options while waiting. You can click the box to have it eject when it's done, close the program when finished, or even shut down the computer when done. Personally, I usually click the eject disc box then work on something else until the disc pops out.
Now that you've ripped your game, put it back in its case and open the folder you had saved the image to. I suggest making sure the name of the folder is the name of the game plus its region. For example, Final Fantasy IX (U). Once in the folder, you should see two files; one BIN file and one Image file. Their file name may or may not be "Image". That isn't important, but it is common:



Both files are essential to the upload. Highlight both and right click. You should see an option to "Add to "Final Fantasy IX (U).rar"". Click that and your files will be zipped together into one, more compact file, though this may take several minutes with larger files. Once the zipping is finished, it is ready to be uploaded.
Feel free to upload to whichever site you prefer, though MediaFire and FileFactory currently seem to be the most stable and reliable.
Once you are ready to post a topic, be sure to read and follow the topic guidelines and thanks for uploading!
