There are two ways to fix this on an original R4: use alternative firmware, or patch your game.I'd recommend using wood R4 alternative firmware instead of patching. It's much less tedious, is way more stable and also replaces the crappy menu. Here's how it works:1. Back up all the files on your micro SD, in case something goes wrong2. download the latest version from here: http://filetrip.net/...od-R4-1-45.html3. Unzip the folder and go to Wood r4 vX.XX (with x.xx being your version number). You're in the right spot if you see some txt files, a dat files and a folder called _root)4. Copy the contents from this folder to the root of your micro SD, the root of your micro SD is E:/ F:/ or a similar letter5. YOU WILL get an error from windows stating that you have files of the same name on your micro SD, proceed as normal and let it overwrite the old files6. Start up your R4 and wood should run fineNote: save files will be saved as *.nds.sav as default, you have to change a setting in the menu to let it use your old *.sav filesNote 2: This will only work with the original R4, like in rcj's case, or he r4i gold (don't forget to download the special wood for r4i gold though!)If you don't like using another firmware, you can patch the game using this program: http://filetrip.net/...build-1102.html1. Set up the tool for first use by letting it update the database and downloading the usercheat.dat cheat files.2. Go to file--> open and select your rom.3. After the rom is loaded into the program go to the Ap patch tab and look if a patch is available4. Go to the export tab and check apply ap tab, also select "no repack" at the "repack to: " dropdown box.5. click export rom and the game will be patchedNote: trimmed or roms that have been altered will not be recognized by the program
