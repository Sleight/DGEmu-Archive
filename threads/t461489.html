Oblita Divinitas' post='4872944 wrote on Oct 2 2010, 09:48 PM:
So is there anything worthwhile about U3? So far, the only perks I'm noticing are a flashy start menu-looking thing and the option to password protect it.
Using it the way they intended? No, there is no advantage. Password protecting it is better done with something more robust like truecrypt. The launcher is better handled by stuff like portable apps.The one real advantage is using it with the tool I linked so you can change what is in the ISO section of the drive. Another EXTREMELY useful side effect is that without the special tool to write to the ISO partition nothing can change what is there.
