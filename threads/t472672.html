Here's a basic guide to PSP hacking and homebrew. If you want more I suggest you read around in websites like Wololo and PSP-Hacks and PSP Slim Hacks. If you just want to learn how to install a CFW, though, dive right in!

Why hack the PSP?
In this context "hacking" refers to using custom firmware (CFW) instead of official firmware (OFW), "firmware" being the software which runs the PSP. You can check what firmware you are running under Settings -> System Information on your PSP.

CFW allows you to do more with your PSP than usual. It lets you play homebrew (programs made by non-official developers), as well as ISOs (games), make backups of your PSP and your UMDs, and so on.

Sounds good to me! How do I do it?
First determine what model of PSP you have, using this image from a PSP Slim Hacks Tutorial:



If it's a PSP 100X, PSP 200X or PSP Go, the recommended CFW is 6.20 Pro permanent.

If it's a PSP-300X, use the PSP Module Checker to find out what module you have.
Just download it, extract it to obtain the "MCHECKER" folder, and place that inside the "/PSP/GAME" folder in your memory stick. Then put your mem stick back into your PSP, turn it on, and select the module checker under "Games".

If it is a 05g or below use 6.20 PRO permanent. If it is a 07g or 09g, use 6.60 PRO, because you cannot run 6.20 PRO on those models.
6.60 PRO is not a "permanent" CFW. This means that when you completely shut it down you will have to load it again (sleep mode is ok).

**If you are already running OFW from 6.30 - 6.39, and have a PSP which can run 6.20 PRO, either downgrade your firmware first, or just use 6.60 PRO, the non-"permanent" CFW.**

Installing 6.20 PRO permanent (from the GBATemp Softmod guide)
If you are not already on OFW 6.20...
1. Download 6.20 official firmware for PSP 100X/200X/300X or for PSP Go.
2. Copy the UPDATE folder to the /PSP/GAME/ folder on your memory stick (or the Go's internal storage).
3. Launch the 6.20 update on your PSP, and tell it to update. **If you are on CFW already DISABLE OR DELETE ALL YOUR PLUGINS FIRST**
If you have older CFW already installed, e.g. 5.50 Prome-4, you might see the "Firmware is already 9.90. There's no need to upgrade." error message. If so, just change its version txt.

**Now to install the 6.20 hack!
1. Download 6.20 PRO.
2. Copy the "620PRO_Permanent" and "PROUPDATE" folders to /PSP/GAME/.
3. Run the 6.20 PRO-B Updater (the icon has "UPDATE" faintly in the middle) on your PSP and when it runs press X to install and launch the temporary 6.20 hack.
4. After the PSP restarts, run the 6.20 PRO-B Permanent Patch (the icon says "PERMANENT BOOTLOADER").
5. Press X once to choose to install, then press X again to choose to test it.
6. If your PSP successfully rebooted after the test, then run the permanent patch again, but this time press X and then Circle to install.
(If your PSP did not successfully test, try removing your "/seplugins/" folder from your memory stick and try again, because not all 5.x plugins work on 6.xx)

To uninstall it just run the Permanent Patch again.


Installing 6.60 PRO (also from the same GBATemp guide)
If you are not already on OFW 6.60...
1. Download 6.60 official firmware (for PSP 100X/200X/300X) or (for PSP Go).
2. Place the "UPDATE" folder into the /PSP/GAME/ folder on your memory stick (or the Go's internal storage).
3. Run the 6.60 update on your PSP and allow it to install. **If you are on CFW already DISABLE OR DELETE ALL YOUR PLUGINS FIRST

Now to install the hack!
1. Download 6.60 PRO
2. Copy the "660PROUpdate" and "660FastRecovery" folders to /PSP/GAME/ on your memory stick (or Go's internal storage).
3. Run 6.60 PRO Updater on your PSP, and press X to install.
4. Your PSP should restart into hacked mode. This will last until your PSP is shut fully off (sleep mode is okay). To hack it again quickly, run the Fast Recovery to get back into 6.60 PRO.

To uninstall it just shut it down fully.


So...now I can run PSP homebrew and games?
Yes. Homebrew comes in a folder, with an "EBOOT.PBP" inside. Place this folder inside the /PSP/GAMES/ folder of your memory stick or PSP Go internal memory. Then run it from your PSP, under "Games".
Place your ISOs (games) inside the /ISO folder, and run it from your PSP under "Games".

How about CSOs? What's the difference between them and ISOs anyway?
CSOs are compressed ISOs (hence the 'C'). They should still work like ISOs, just that they might take longer to load or lag at cutscenes or so.

How about online play or the PSN?
You should be able to play online and access the PSN, if you follow this guide.
