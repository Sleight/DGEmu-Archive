FAMICOM DISK SYSTEM EMULATION

Nintendo's Famicom Disk System had a number of unique titles that could not be found for the regular Famicom/NES system. These include famous titles such as Super Mario Bros. 2 (the true sequel, not the North American one), Eggerland games with a level editor (this is the Japanese version of the Adventures of Lolo, which had no level editor on the NES version), Doki Doki Panic (eventually became the North American SMB2),and the Famimaga Disk series. For a complete list of FDS games, visit this page on Wikipedia:

<pre class="_prettyXprint _lang-auto _linenums:0"> http://en.wikipedia.org/wiki/List_of_Famicom_Disk_System_games</pre>

A few of the game titles on this list are different than what you would find with an exact search on DGEmu's search engine, so make sure to use partial searches if the exact name brings nothing up. Also, be aware that Wikipedia can be edited publicly, so there may or may not be some mistakes that arise on that page. The original source page for the article is in Japanese but can be partially translated by Google. That list is organized by publisher. The link is at the bottom of the article.

 

Famicom Disk System ROMs work on most of the same emulators as NES games. The file extension of these ROMs are .fds instead of .nes, though. You will need the Famicom Disk System BIOS file in order to play these games. The recommended emulators for playing FDS games are FCEU or FCEUXD, both of which have download links provided in the previous section. You will have to make sure that the BIOS file name is "disksys.rom" when you are attempting to use it with FCEU. I have already renamed it for you in the downloads I am providing.

 

Famicom Disk System BIOS Downloads:

 

ZIP:

<pre class="_prettyXprint _lang-auto _linenums:0"> http://www.megaupload.com/?d=EQ9S2USR</pre>

RAR:

<pre class="_prettyXprint _lang-auto _linenums:0"> http://www.megaupload.com/?d=1R04H917</pre>

Once you extract the file, make sure to put it in the same folder as your emulator. This will allow you to properly start the games. Once you start the game, sometimes there will be various points where it asks you to flip the disk. It will usually say something about switching to side B, or if you have already done that, switching back to side A. There are times when it is written in Japanese, so just make sure you keep an eye out for "B" or "A" in that case.

 

In order to flip the disk on FCEU or FCEUXD, you simply push ctrl+F8, ctrl+F6, and then ctrl+F8 again to literally eject the disk, flip it, and then reinsert it. This should allow you to continue playing. Some games, such as Super Mario Bros. 2, do not require any disk flipping, so don't expect to have to do this all the time. Well, now you should be able to play FDS games any time you feel like it. If you have further questions or find one of the links to be dead, make sure to PM me.

 

VIDEO RECORDING

I have seen a couple of members ask about video recording before, and while I am not all that into it, there are members like Sir VG who excel at it. Sir VG is pretty well known in the world of speed runs, it seems.

 

There does not seem to be any emulator for Macintosh that can record videos, but if this is not the case, then someone let me know and Iï¿½ll fix this portion of the guide. On Windows, however, FCEU seems to be the best emulator for recording movies. NNNesterJ also can directly record AVIs, but FCEU tends to be favored by most users. The newest version of FCEU, 0.98.16, is apparently recommended for video recording, but 0.98.15 still works just fine for playing. Here is a link for the download of 0.98.16:

 

FCEU 0.98.15 (Recommended over 0.98.16)

FCEU 0.98.16 (Some videos require this emulator)

FCEU 0.98.16 for Linux

 

Most emulators for Windows can make movies in some format, although some can only be viewed through the emulator. FCEU can make a movie specific to itself (fmv) or can record an AVI file that can be viewed by several media players. The same can be said for NNNesterJ. In a FCEU recording, if you need to stop recording in the middle of a movie but wish to record it later, you can pause the emulation and create a savestate at the end of recording and then play the movie up to that point and load the state in order to continue. If you lost your savestate, then you can play the movie up to the point where you want to start recording again, and then pause the emulation and create a savestate which you will immediately load so that you can record.

 

It should also be noted that while FCEUXD is an edited version of FCEU, it does not support video recording like many other versions of the emulator.

 

NETPLAY/MULTIPLAYER

Netplay works on all versions of FCEU for Windows that are higher than 0.98.10. In order to play online, you will need the FCEU netplay server:

 

FCEU Netplay Server 0.0.5

 

This server never left the very early beta stages, but it can still support gameplay fine, although it cannot do it well for a large number of people. It can serve its purpose though, although it cannot seem to do this on Mac because of the lack of certain dll files.

 

To compile the server under Windows, it is recommended by the developers that players use Cygwin:

 

Cygwin Main Site

 

The file can be downloaded from that site. There does not appear to be sufficient netplay support for other emulators currently, but if that changes, so will this segment of the document.

VIDEO RECORDING

SNES9x seems to be the most common emulator used for video recording for speed runs on Windows, although many people use ZSNES for various videos as well. It is very simple to record with either. For SNES9x, you merely need to go to the Option menu and select ï¿½Record movieï¿½. For ZSNES, you must go to the Misc. menu and select ï¿½Video Optionsï¿½.A typical question regards converting the specific video files for these emulators to AVI files so that they can be viewed in multiple media players. Some people have explained how to do this with great detail in other sites.

 

Phil of TASvideos explains how to convert SMV files to AVI files in SNES9x on this page:

 

http://tasvideos.org/ConvertingSMVToAVIInWindows.html

 

There is a thread which was started by the ZSNES development staff on the ZSNES forums that explains how to convert ZMV to AVI files with the emulator:

someone wrote:

To record a video you need one of the latest work in progress builds of ZSNES. Get them here: http://zsnes.ipherswipsite.com/ You will need a copy of mencoder. For Windows users, I recommend getting mencoder here: http://oss.netfarm.it/mplayer-win32.php Place mencoder.exe in the same location as zsnesw.exe, you do not need any codecs or other movie programs installed. Linux users, having mencoder in your path is fine.

 

If you want to compress the outputted audio, or compress it before it goes into the video as opposed to during, you will need a copy of LAME. If you use Windows, you must get LAME from here: http://nsrt.edgeemu.com/lame.zip Any other copy of LAME for Windows will not work due to a bug in LAME. Before you are able to dump an AVI, you must have recorded a movie first, it converts movies, it does not just dump video on the fly.

 

To play back movies, you'll either need the proper codecs or a video player with built in decoding of the video mode you selected. I recommend getting mplayer which decodes anything created with mencoder. For Windows, you can get mplayer here: http://oss.netfarm.it/mplayer-win32.php You can download the GUI version. Advanced users can edit zmovie.cfg and tweak the settings if they want, and even use something other than mencoder and LAME as long as it supports encoding via stdin and you set it up properly.

The thread can be found here for further questions:

 

http://board.zsnes.com/phpBB2/viewtopic.php?t=3103

 

NETPLAY/MULTIPLAYER

ZSNES is use much more often than SNES9x for netplay. In fact, there is a program specifically made for running netplay on ZSNES. This program sets up a server for players to find other gamers that will play with have netplay sessions on the emulator. Here is the link:

 

http://www.zbattle.net/files/zb.net-1.09-SR-1-beta.exe

 

That file works for Windows. For versions that work on Linux, as well as additional information about the program, visit http://www.zbattle.net and check out the site.

 

To run netplay on ZSNES otherwise, go to the Netplay menu, then Connect, and determine who will be the server and who will be the client. Using Zbattle, this will not be necessary. Enter your IP into the appropriate box. Disregard the ï¿½your IPï¿½ part of the box, for this is usually incorrect. Instead, you can do something as simple as visit http://www.whatismyip.com to find out your real IP. Click either ï¿½Start as Serverï¿½ or ï¿½Connect to Serverï¿½ depending on what you have decided to do, and then it should connect.

 

In SNES9x, you need to go to the Netplay menu and select either ï¿½Serverï¿½ or ï¿½Clientï¿½ and follow the same method described above for ZSNES.

 

If the connection fails, the most likely problem is that someone who is attempting to make the connection has a firewall. To ensure a successful connection, turn off any firewalls that may be on. If there are still connection problems, you can try different versions of the emulator, because certain versions work better with certain computers. If you still have problems, then ask for help in this forum or go to zsnes.com and ask.

IPS Patching/Translations

Needless to say, these two areas are very closely related. They both generally revolve around ips files, which are patches that can be applied to ROM files. The easiest program to use for patching, in my opinion, is Lunar IPS, which can be downloaded here:

 

Lunar IPS:

<pre class="_prettyXprint _lang-auto _linenums:0"> http://www.zophar.net/utilities/download/lips100.zip</pre>

It also has a Dutch version:

 

Lunar IPS in Dutch:

<pre class="_prettyXprint _lang-auto _linenums:0"> http://www.zophar.net/utilities/download/LunarIPSNEv100.zip</pre>

This program is extremely easy to use. As long as you have the ips patch and the appropriate ROM file, then you can simply open LIPS, or even just open the ips patch directly using LIPS, and then select the ROM that you want to patch it to. It is seriously THAT simple. Most other programs take a little more explaining, but LIPS can fortunately be summed up to that.

 

Another good alternative is of course IPSWin:

<pre class="_prettyXprint _lang-auto _linenums:0"> http://zerosoft.zophar.net/ipswin.htm</pre>

It is also easy to use.

 

Most rom hacks and translations are put into ips format. A huge database of translations can be found at:

 

http://www.romhacking.net

 

Please check that site for translations and rom hacks before looking anywhere else. They are likely to have something either in development or already available for download, for they have a lot of groups that work specifically on translation hacks, including Aeon Genesis, which is led by Gideon Zhi.

 

If there is a translation that cannot be found there, and you would like to see one made, you can go to romhacking.netï¿½s forums and request a translation in this thread:

 

http://www.romhacking.net/forum/index.php/topic,1387.0.html

 

That is your best bet for having something translated if it is not in development already. The site in general is also your best bet for learning how to rom hack or finding rom hacks to play. Please do not ask questions about translations or patching, because all of it can be solved here now.
