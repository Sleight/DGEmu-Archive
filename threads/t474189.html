Hm... not all flashcarts (the term for special ds cartridges that play ds games illegaly) work with the DSi so you have to be certain it works with it, or else you have to return it to the shop you bought it from ASAP. Also note that you should never, EVER update your DSi's firmware. Those updates give you little to no extra functionality and it always blocks out the majority of the flashcarts. You can easily block firmware updates in the parental controls. On to the questions: 1. You do have to install a few files before you can use the flashcart. Usually you will get a cd with software on it along with the flashcart, just search for a folder that is called along the lines of "firmware" and copy all its contents to the micro SD. You need to put that on the micro SD directly (do not put it in any subfolders). After that you need to update. Go to the R4i's website, which can be found here: http://www.r4i-sdhc.com/ (note, if the box says that you have to go to a different website, then do that, the procedure is always the same though). What you need to do is download the zip file, and extract the files from it. In there there is a folder with an update. OVERWRITE all duplicate files on the micro SD with the files from the zip file. Note: you have to do this regularly to play the newest ds games2. DS games up here have the extension *.nds. You will always download a *.zip file first and you need to extract it with windows. You cannot directly play ds games from a zip file.3. If you configured the R4 correctly, then adding games is a pinch. Just copy *.nds files to the micro SD and they can played on the flashcart, unless they have anti-piracy, in which case you need to either patch the game, or wait for a new firmware update.
