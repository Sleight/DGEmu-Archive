Overview:
nullDC is the most popular Dreamcast emulator at the current time to writing.
This guide will help you setup the basics in order to play games.
Notice that this guide will not cover any of the advanced options.

What you will need:
- nullDC: http://code.google.c...lDC_104_r136.7z
- Dreamcast Bios: http://www.filefacto...amcast_Bios.rar
- Microsoft DirectX Runtime: http://www.microsoft...ails.aspx?id=35
- Microsoft Visual C++ Redistributable: http://www.microsoft...ls.aspx?id=5555
- 7-Zip: http://www.7-zip.org/

Game formats:
On this latest version of nullDC, you can only run disc images off your computer. You will not be able to run discs from an optical drive.
nullDC only supports self-bootable disc images. The CUE sheet accompanied by BIN format is usually a non self-bootable Dreamcast game. NullDC does not support CloneCD's CCD, IMG and SUB format.
The currently supported image formats are the following:
- CDI: Padus DiscJuggler image
- MDS: Alcohol 120% Media Descriptor image (must be accompanied by a MDF file)
- NRG: Nero Burning ROM image
- GDI: Raw GDI dump
- CHD: MAME's Compressed Hunk of Data

Before starting:
Make sure all the requirements are met. That said, you must have Microsoft's DirectX Runtime and Microsoft Visual C++ Redistributable packages installed. You can download them from the links above.
You will also need 7-zip installed in order to open the compressed archive to extract the emulator. The download link is also available above.

Preparing the emulator files:
1. Once your downloaded the emulator from the author's website, use 7-zip to extract the content to any location on your computer.
2. Once you downloaded the Bios pack, extract the content into the "data" folder where you extracted nullDC.
3. That's it, we're now ready to configure the emulator.

Configuring the emulator:
1. The first setting to change is to check Options > nullDC Settings > Broadcast Format > NTSC. This will allow the emulator to run at 60 frames per second instead of 50 on PAL games.
2. Next, we can setup the controls by going in Options > Maple > Port A > Config Keys for Player 1
3. All the other settings can be left at their default parameters.

Loading a game:
1. Click on File > Normal Boot.
2. Click on the [...] button, look for your game in one of the supported formats, select it and click Open.
3. That's it, your game should now be loaded and you can now start playing!

Multi disc games:
Some games will have more than one disc. The perfect example is Shenmue, which has 3 discs.
Once you complete the first disc, the game console will ask you to change discs to continue your game.
To do so, simply go to Options > GDRom > Swap Disc.
You will then be prompted for a disc image, click on [...], find and select the next disc, and then click Open.

Conclusion:
That's pretty much the basic you need to know in order to start playing Dreamcast games.
If you have any other questions, please do ask away in our forums. We'll gladly try to help.
