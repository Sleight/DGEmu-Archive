I've really only played House of the dead 4 (arcade), but I think I get the question. You're wondering if the game would be better as a regular shooter, rather than a rail shooter.I'm not so sure that it would be a good idea, there are a few games that try and put shooter/first person view and horror together (Juon: the grudge, Fear 2, and the visions after the inciting incident in half-life) The problem with those games is that it's only scary if you can actually see what's going on. I don't mean to belittle half-life in any way, but the first time I saw those visions after pushing the crystal into that thing I thought the game was broken, and after a little while I kept turning around until I found those aliens and thought it was the game still being broken.However, if the game has a fixed camera, like Dead Space and HotD, then there is no way of turning away from the scariness of the game. Not to mention that when you can only stand still the zombies seem scarier than if you can run away.
