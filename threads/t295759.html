This guide is design so that you can migrate pokemon from pokemon Ruby, Sapphire, Emerald Fire Red and Leaf Green. I've have tested this with my M3 Simply and gotten it to workWhat do you need:
A Slot 1 Flashcart
EzFlash 3 in 1 Expansion Pack
A pokemon Diamond/Pearl rom that has unlocked Pal Park
A pokemon Ruby, Sapphire, Emerald Fire Red or Leaf Green rom
A pokemon Ruby, Sapphire, Emerald Fire Red or Leaf Green save file
PokePatch 3in1 V2 Download here
Rudolph's GBAExp Loader [Download here]

What you need to do:
1. Patch your Pokemon Diamond or Pearl Rom with PokePatch by dragging the rom onto the .exe file
2. Create a folder called "GBA" in your root folder of your slot 1 flashcart(micro SD for M3 Simply/R4)
3. Create a Saver folder called "SAVE" in the GBA folder that you have created.
4. Place pokemon Ruby, Sapphire, Emerald Fire Red or Leaf Green rom in the GBA folder
5. Put the GBAExp Loader rom into your slot 1 Flashcart
6. Boot up your NDS with the slot 1 flashcart and Ezflash 3in1 Expansion Pack plugged into your DS
7. Run the GBAExp Loader
8. Press "L" or "R" until NOR Mode is displayed
9. Select your pokemon Ruby, Sapphire, Emerald Fire Red or Leaf Green rom and copy it into NOR Flash by pressing "A"
10. After copying your Pokemon Rom into NOR Flash Start it by pressing "X"
11. Start your new pokemon game and save it, then restart your DS
12. Run the GBAExp Loader again
13. In NOR mode press "B" to backup save into a .sav file then turn off your DS
14. On the Computer go into the SAVE folder and find the pokemon save
15. Rename your GBA pokemon save to the exact same name as the file in the SAVE folder
16. Move the renamed save into your SAVE folder and overwrite the file
17. Turn on your DS and run the GBAExp Loader again
18. This time in NOR mode press "Y" to write the save file into your 3in1 Expansion pack
19. Press start and start your pokemon Diamond/Pearl rom
20. In the Main menu the "Migrate" should be available
21. Migrate your pokemon over then go to Pal Park to catch them.

This may not work for everyone. If you are unsure if the save transfer worked or if pokemon Diamond/Pearl can't read the save file then start pokemon on GBA and load the save file, if there is a corrupted file. Load your game and save the again.
