PpolopbobJul 24 2012, 10:16 PM
Most of the stuff about CFW and HEN has already be mentioned or can be found in the guides.
It is indeed more recommendable to switch to or use Pro, since the TN-HEN project has stopped, and the more practical usage of PRO. Version 6.20 PRO has indeed a permanent patch, but you can also install it without patch, so basically it would be like when using TN-HEN (restart when power off or empty), but you won't be needing a ISO-loader since it is already integrated, one that allows the user to play games which normally would require higher versions.

The biggest difference between the two would be the way it is stored on the psp. TN-HEN is saved onto the RAM, making it perfectly save to use, so there are no chances of bricks. Whereas PRO (normal not permanent) is saved onto the Flash0 of the PSP, making it possible to get a brick. But since it is adding data, rather then modifying (which the permanent patch does), the chances of it actually bricking is neglectable.

I hope this clears it up a bit.
