While on the topic of controllers, what's the difference between direct input and xinput? my controller has both and I've never managed to understand why it matters which option it's flipped to

PPenga PequeñaMay 31 2014, 03:59 PM

Only actual difference for the end user is that xinput is standardized so that both controllers and games use the 360 button layout as reference (so, when the game says press A it really means press A). Direct input was a little all over the place with no standard layout for controllers so button "2" could be either, "X" on a Dualshock controller or "Y" in an Xbox (original) controller.

 

basically you should just use xinput mode for recent games and directinput for old (pre-360) games, it's just there for compatibility and won't do anything exciting.

This is a bit confusing at first...

 

There are three types of combos in SF4, cancels, links and chains.
Cancels: Normal attack cancels into special attack.
Links: Normal/special attack that can be comboed into normal/special attack after the animation of the first attack ends.
Chains: Normal attack cancels into normal attack.

 

Now if you're doing a chain, you can't cancel it with a special move(cancels don't work after chains). The problem you're having with Fei is that his crouching LK can both be linked and chained into itself(and some other attacks I think), so if you linked it, you'll be able to cancel into rekkas easily, while if you chain it, it won't cancel into rekka. 

 

Sagat seems easier because he doesn't have chains to miss up his confirms, mostly just links.
