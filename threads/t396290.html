Captain Bat' post='4078710 wrote on Apr 19 2008, 06:00 PM:
Wait... thats what was causing the database crashes? Searching? Why?
Because continuously searching through millions of posts tends to use up a lot of CPU time that then adds up until the database can't handle the load. Unfortunately for us, the database structure prevents full text indexing, so we're looking at very intensive operations whenever someone searches for something.
Ish' post='4078761 wrote on Apr 19 2008, 06:15 PM:
What's the difference between Lucene and Spider?
Lucene is supposed to be an alternative to the normal full-text indexing/search functionality provided by the database. Since we're using an engine that doesn't support full-text indexing natively, Lucene would essentially be a real-time search replacement for that functionality, as opposed to a delayed system like spidering. Of course, I haven't actually used Lucene before, so I have no idea how well it works.
