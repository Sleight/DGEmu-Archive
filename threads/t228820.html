DDJ Night Force 9ORIGINAL POSTApr 19 2007, 03:11 AM
It would seem that it IS possible to use at least the flashget download manager with dgemu without getting charged 2x Dps and without an Html file being sent instead (unless you don't have enough dps which makes perfect sense).Anyway, this is a Firefox only deal (sorry you IE fans out there :shifty: ) because you need an extension called "Flashgot" so firefox can send links (and cookies) to Flashget. Now if you left click the download link and select "FlashGot", you will still be charged 2x Dps because first your browser makes a connection with the server (first deduction) and the Flashget also does so when initiating the download (second deduction). However, what you CAN do is right click the download link and select "FlashGot Link". The link (and the respective browser cookies) will be sent to Flashget while bypassing the browser altogether. Only one connection is made allowing you two recieve your file with the RIGHT amount of Dps deducted. I believe this trick will work with any download manager supported by FlashGot like GetRight providing that the download manager also supports cookies (which they probably do).Anyhow, give it a try if you like. Worked well for me. Remember that you will need the FlashGot firefox extension or otherwise, how else will you be able to click "FlashGot Link" :shifty: ?This will certainly impact the dgemu FAQ and perhaps reduce at least one type of question support staff receives on a daily basis.EDIT:If you wish to test it out, here's some useful links:Download FlashGetDownload FlashGot
