Since February 26th, Microsoft released their latest operating system to Windows 7, Internet Explorer 10.

 

To get the update, you must have Windows 7 Service Pack 1 installed.

To download IE10: http://windows.microsoft.com/en-CA/internet-explorer/downloads/ie-10/worldwide-languages

To download Windows 7 SP1: http://www.microsoft.com/en-us/download/details.aspx?id=5842

 

For 64-bit users, you'll notice that Internet Explorer 64-bit shortcut will not appear anymore. Natively, IE10 will run as 32-bit for plug-in compatibility reasons.

If you want to enable 64-bit mode, you'll need to launch your browser, click on the cogwheel icon at the top right, and click on Internet Options.

Move to the advanced tab, and under the Security section, check "Enable Enhanced Protected Mode" and restart your browser.

 

From now on, if you actually check the processes of iexplore in task manager, it won't be identified as a 32-bit application anymore (there is no *32 next to the process name).

This also means to compatibility to 32-bit add-ins.

 

Vista users won't be getting this update, and Windows 8 users already have this browser by default.

 

 

On the Mozilla side, Firefox is at version 19.0.2.

For 64-bit variants, Waterfox is still stuck at 18.0.1. I've long dropped this browser as their update schedule is too slow. Instead, I now use Cyberfox, an even more optimized 64-bit version that is blazing fast at loading stuff. People interested, download is here: http://sourceforge.net/projects/cyberfox/

As usual, all add-ins that Firefox uses can be used in Cyberfox (AdBlock Plus, Download Statusbar, etc.)

 

Update your Adobe Flash and Shockwave to the latest versions. Both has had security holes that were fixed.

Java 7 is now at Update 17. Either you upgrade to the latest version and make sure to enable it only if you need it on sites (if some of you actually use the DG Arcade, you'll have no choice), or uninstall it completely for security measures for now. http://thenextweb.com/insider/2013/03/04/oracle-ships-emergency-java-7-update-17-to-patch-two-vulnerabilities-after-one-is-exploited-in-the-wild/
