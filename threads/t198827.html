1. Getting VisualBoyAdvance [GVBA]
VisualBoyAdvance (VBA)
The official VBA website is located at http://vba.ngemu.com/. Download links are provided below (left-click these links; do not right-click and choose "Save As...").
Version 1.7.2 (Windows): http://prdownloads.s...vance-1.7.2.zip
Version 1.8.0b3 (Windows): http://vba.ngemu.com...1.8.0-beta3.zip
Version 1.7 (Mac OS X - official release): http://prdownloads.s...2-MacOSX.dmg.gz
Version 1.7.4 (Mac OS X - unofficial release): http://www.macupdate...fo.php/id/10123
Version 1.7.1 (Linux): http://prdownloads.s...tar.gz?download

For most games, you should use version 1.7.2 (1.7 or 1.7.4 for Mac OS X, or 1.7.1 for Linux). However, certain games require version 1.8.0b3 (Windows only). See this list for more details: (link to be added).

VisualBoyAdvanceLink (VBALink)
VBALink is a modified version of VBA that supports emulation of the GBA link cable and wireless adapter on the same computer and across a network. More information is available on the official VBALink website:
http://vbalink.wz.cz/. Download links are provided below (Windows only).
Version 1.7.3: http://vbalink.wz.cz/vbalink173.zip
Version 1.8.0b0: http://vbalink.wz.cz/vbalink180b0.zip
Version 1.7.3 should be used for emulating the GBA link cable and for emulating 2-player wireless linking on the same computer. Version 1.8.0b0 should not be used except in very specific cases (e.g. the Crossover battle between MegaMan Battle Network 5 and Boktai 2, wireless linking across a network).

3. Advanced Usage [ADVU]
Once you've learned how to use the emulator to play games, you can play around with some of the emulator's other features. This section will cover a select few of them.

---

Save States
Save states allow you to save at any point in the game, regardless of whether the game itself allows saves at that particular moment. To create a save state, go to File -> Save...:

To load the save state, go to File -> Load... and select the save state file that you created.Power users may want to use the pre-named save states that come standard with VBA. To use these, go to File -> Save Game -> # (where # is any one of the numbered options). Note that each of the pre-named save states has a shortcut key (e.g. Shift+F1):

To load these saves, either go to File -> Load Game -> # or use the appropriate shorcut key (e.g. F1).

---

Audio Options
To turn the sound on or off, go to Options -> Sound -> Mute. Do not use On and Off because that will desynchronize the audio and video.

Other audio options are also available in the same menu.

---

Video Options
You can change the size of the emulator screen by going to Options -> Video -> * (where * is any of the size options) and selecting the size you want. Note that the quality of the video will invariably decrease if you use a size larger than x1. To counteract this, you can enable certain video filters by going to Options -> Filter -> * (where * is the name of any filter).

---

Cheats
VBA comes with built-in supports for a number of different types of cheats. To enter them, go to Cheats -> Cheat list... There are four types of cheats. Use Code and Cheat if you have hexadecimal cheats that set given memory addresses to supplied values (you don't usually use these options). Use GameShark for GameShark codes using the old GameShark encryption and for Pro Action Replay codes. Use Codebreaker for Codebreaker and GameShark SP. Note that websites do not always label their cheats properly, and so you may need to try a few options before figuring out which type of input to use. See the official VBA FAQ for more information: http://vba.ngemu.com/faq.shtml#cat3_3.

VBA also has a built-in search engine that allows you to create your own cheats for quantitative game values (e.g. number of lives). Please consult the official VBA FAQ for instructions: http://vba.ngemu.com/faq.shtml#cat3_0

---

Loading GameFAQs Saves
You can load SAV, SPS, and some XPS saves in VBA. To load a downloaded SAV file, go to File -> Import -> Battery file... and choose the file you downloaded. To load an SPS or XPS file, go to File -> Import -> Gameshark Snapshot... Note that not all XPS files are compatible. Other types of saves cannot be loaded directly.

---

Recording gameplay videos
VBA also comes with a video recording option. To record VBA-only videos, go to Tools -> Record -> Start movie recording... Enter a filename and the recording will start as soon as you click the Save button. When the video segment you want to record is finished, go to Tools -> Record -> Stop movie recording to stop the recording. If you want to record videos that can be played using typical media players, use Tools -> Record -> Start AVI recording... and Tools -> Record -> Stop AVI recording. For these videos, you can change the video compression. Recording uncompressed video typically does not slow down gameplay in the process, but produces very large files. Recording compressed videos create more manageable files, but tend to slow down gameplay during the recording process (the resulting video should be unaffected).

And that's all for now. If a very popular feature is not covered here, send me a PM and I'll see if it belongs here.

4. Using the Link Feature
If you want to use the link feature, you need to use VBALink, not VBA. See the first section for download links.

Single-computer linking
Follow these instructions to link two or more emulators on the same computer.
1) Open one instance of VBALink for each player (this example uses two players).
2) Load the appropriate rom in each instance of the emulator. Load any saves you may have available.
3) If the linking uses the wireless adapter, go to Options -> Link -> Wireless Adapter. If not, just go to the next step.
4) Go to the link location within the game on each instance of the emulator and choose to connect.

---

Network linking
Follow these instructions to link two or more emulators across a network
1) Open one instance of VBALink on each computer
2) Load the appropriate rom in each instance of the emulator. Load any saves you may have available.
3) If you are using version 1.8.0b0 and want to wireless adapter emulation, go to Options -> Link -> Wireless Adapter on each instance of the emulator. If not, then go to the next step.
4) On each instance, go to Options -> Link -> Options... and choose "Network."
5) On one computer, click the "Server" tab and select the number of players. Then press "Start!"
6) On the other computers, click the "Client" tab and enter the IP address of the host computer. Then press "Connect."
7) Once all the links have been established, go to the link location within the game on each instance of the emulator and choose to connect.

Basic troubleshooting
Most linking questions are very specific, and so solutions will vary from case to case. This section will address some very basic issues.

Why does [GAME TITLE] not link? Not all link types are supported at the moment. To see a partial list of compatible games, please consult this topic: http://www.dgemu.com...showtopic=66686. If the game you are trying to play is listed as compatible, go to Options -> Link -> Options... and increase the link timeout to 9999. Also, please note that while a few games support wireless adapter emulation (e.g. Pokemon Fire Red/Leaf Green, Pokemon Emerald), most do not (e.g. Pokemon Ruby/Sapphire, MegaMan Battle Network). Do not enable wireless adapter emulation for games that do not support wireless linking!

How do I find my IP address (for network linking)? Go to Start -> Run... and type in cmd /k ipconfig. Your IP address will show up in a new command prompt window.
