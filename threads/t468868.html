To be more exact:DVD-R = 4.7GB recordable once, direct write. 100% compatible with all DVD players.DVD+R = 4.7GB recordable once, format before use, better data protection when having multi-session discs. Although compatibility should be 100%, some rare cases they don't read properly on DVD players, especially on the really really old ones.DVD-RW = Same as DVD-R counterpart, except you can erase it and reuse it for a certain amount of times. Not 100% supported by DVD players on TV.DVD+RW = Same as DVD+R counterpart, except you can erase it and reuse it for a certain amount of times. Not 100% supported by DVD players on TV.DVD+R DL = 8.5GB recordable once. Very expensive discs, just use these to pirate 360 games :drool:
