SshadowmanwkpNov 22 2011, 08:11 AM
That seems like an original R4 you're talking about. If you've got your firmware updates from this site: http://www.r4ds.com then you have an R4 that can install a very popular alternative firmware. This alternative firmware is called Wood R4, it gets regular updates for ds games that act up. You can download it from here: http://filetrip.net/...od-R4-1-40.html You can also keep an eye on that page as well, because it will inform you if a new version has been released. Setup instructions:1. Back up all files on your R4 in case the firmware is not compatible with your R4 (you only need to do this the first time you try to put this firmware on your flashcart)2. Unzip the file3. Navigate to the folder Wood R4 <version number>4. Put the contents of the folder onto the root of the Micro SD, overwriting all existing files (note: the root means the very first place you get in when you go to your Micro SD, so do not put them into sub-folders)5. Start up your ds with the R4 and you're ready to go You can also update the firmware with this very same method, it ain't too hard really.
