EEricChizAug 01 2006, 06:32 AM
Certain emulators, instead of making a program that can mimic the BIOS, simply use a dump of the BIOS to operate. Some have code that mimics the BIOS, but not very well. And then there are some that have code that mimics the BIOS fairly well, but have locked it to public domain and homebrew roms to prevent piracy.The BIOS pack contains a bunch of different BIOS dumps for various system that you can use to get roms that don't work to work, or don't work well to work better. You probably wouldn't see anything better for certain systems, but if there's a lot of error messages coming up everytime you try to start a certain rom, a BIOS dump might be a good way of solving the problem (and subsequently making the emulator shut up and run).A good example is the FamiCom Disk System, which most-to-all NES emulators require a BIOS dump (from an FDS drive) for the disk images to run.Another good example is most PSX emulators - most PSX emulators don't bundle the PSX BIOS because Sony is more than willing to sue the pants off of Sony PSX emulator creators. (See Bleem and CVGS. The former closed due to legal battles with Sony, the latter bought out by Sony after Connectix won a suit.)
