Ripping sprites really depends on the program you use. For ripping from an arcade game, the easiest thing to do would be to get the latest version of WinKawaks, which would be 1.58.[center]~RIP THOSE SPRITES~[/center]Get the ROM you want the sprites from and open it in Kawaks. (I'll rip from Garou: Mark Of The Wolves (set 1) )Open the rom and change the NeoGeo settings to a familiar dipswitch, so that you can rip the sprites without being attacking:Choose the practice mode from in game:Once you have chosen the character you want to rip, you go into the Tools menu and choose the Shots Factory option, when its open, you will see a bunch of checkboxes, click the blink selected box near the bottom. And disable the layers, one by one until you're left with just the sprite layer you want to rip, make sure to uncheck Blink Selected before you click OK:You now have only your sprite layer showing:Go back into Shots factory, make sure the 8x8 button is clicked, that will disable the lifebars and powerbars as well as menu text. Click the Step frame button and then the Screenshot (unfiltered) buttonKeep doing that until his animation has scrolled through.[center]~Animate Those Sprites~[/center]The next step, requires you to have some sort of Animation program, I did the tutorial with Jasc Animation Shop 3, you get it free when you purchase (or pirate :shifty: ) Paint Shop Pro. Open up Paint Shop and start the animation wizard, go through the wizard and make sure that you select the "Opaque" option for background color. Make sure its either bright magenta or bright green. (R:255 G:0 B:255 or R:0 G:255 B:0 )Open up all the captured screens you have taken and make sure that they are in order. You'll get a screen like this:Next, choose the crop tool and place it around the sprite. Press the right arrow and go through each invidividual frame and adjust the crop box accordingly.Now crop.Once you have the sprite cropped. Select all the frames (ctrl + a) and click the Animation option at the top and then Replace color and use the settings below:Once you have the green background, you should be good if you want to use them in MUGEN, as you have the green set as transparent :P Select all frames and Save them as PCX files and they're ready to be added to your SFF :D STOP HERE IF YOU ONLY WANTED MUGEN RELATED RIPPING!!!If you want to take the animation and make it transparent, however, Select all frames again and go into Animation > Replace Color and use the following settings:Basically, you are replacing the green with Transparent opacity.Next, go into Animation > Animation Properties and use these settings:When you're ready to be finished, Click File > Save As and save as a GIF. And theres your animation :)This is what I ended up getting, I could get a better outcome, if I spent a little more time with it :P Happy ripping!
