[center]WARNING[/center]The use of these codes may possibly mess up your save data and may also cause freezing. Also, be aware that there's a limit of how many codes you can put at a time.If you haven't installed the homebrew channel via Twilight princess hack, please review this topic first:http://www.dgemu.com/forums/index.php?showtopic=425930[center]Getting Started:[/center]If you haven't done so already, create a new folder in the root of your SD Card named "apps". Put the folders needed inside that folder.For this you need the app "Wad Manager" and the Ocarina app.You can download the ocarina app here:http://wiird.l0nk.org/ocarina.zipIn case you get an error stating that the app is not a valid application, you can download the WAD for the Ocarina Channel here:http://www.mediafire.com/?dmwk04mtzwyDownload the Wad manager app here (there's also the channel which has the WAD itself, but it's optional):http://www.dgemu.com/forums/index.php?showtopic=425953Once downloaded, do the following for each app:Ocarina: Open the "ocarina folder". There will be two files: "hbc" (meaning homebrew channel) and "pc". Open the "hbc" folder and place the folder that's inside (you should see "ocarina") into the apps folder in your SD Card.Wad Manager: when you open the file, you will see two folders: "apps" and "WAD". Open the "apps" folder and copy the "Wad Manager 1.3" folder to the apps folder in your SD Card.NOTE: Use the Wad Manager in the Homebrew Channel to install the Ocarina WAD just in case. Make sure that the WAD is in the "wad" folder, which you should have in the root of your SD Card.[center]Adding & Applying Cheats:[/center]After you have those apps in your SD Card, go back to the ocarina folder. Now, instead of going in "hbc", you now go in "pc"There will be a file named "codemgr.exe". That is what you'll be using to edit and apply your cheats.Before we start with the cheat manager, you can use this website for cheat codes:http://usbgecko.com/codes/Here's how the codes are sorted:NTSC-US: United StatesPAL-EU: EuropeNTSC-JP: JapanJust go to the first letter of the name of the game and from there, you can manually add the cheats or download the cheat list as a .txt file.Here's how you add cheats:In the cheat manager, you must first put the Game ID and game name:To add cheats, click the "Add a code/comment/category" button. Then add the name of the cheat and enter the code accordingly. Then click "Store modifications"If you want do load from a .txt file, go to File > Open TXT file.Once you're done with the cheat list, you can now export it to your SD Card. In order to do this, click the "Export to GCT" button at the bottom. Now, select the drive of your SD card and click "Store". It will automatically create a folder called "codes" in the root of the SD Card.Now, all that's left is to insert your SD card into the Wii, and enter the Ocarina Channel, or the ocarina app located in the homebrew channel. From there, follow the instructions listed on your screen. If it says that the cheat list is too large, try using less cheats. I recommend using 9 or 10.Enjoy your cheats!
