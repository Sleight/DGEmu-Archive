PpenisburgORIGINAL POSTOct 19 2008, 06:00 AM
Credits to psp-vault :http://www.psp-vault.com/Dark_Alex and Team M33 are at it again, this time with custom firmware 5.00 M33! The new firmware recently showed up on Dark_Alex's website via their forum.The only change from the last custom firmware was a bug fix that fixed a problem when you went to chang the brightness of your PSP the CPU speed of the XMB would always change to 222 MHZ. The good thing is that now you can access the PlayStation Store and use homebrew at the same time!To install this new custom firmware, copy the UPDATE folder to the /PSP/GAME/UPDATE/ folder on your memory stick. Than download the firmware 5.00, renamed to 500.PBP, to the /PSP/GAME/UPDATE/ folder on your memory stick. Finally run the update via the Game menu of your PSP. You must have a homebrew compatible PSP with 3.52 M33-4 or higher to run this update.There is a bug in this firmware that outputs error 0xFFFFFFFF to your PSP when you run some PS1 games. You will have to patch the firmware manually, however.Thanks to member tetuko for the tip!Update:Rayman123 reports that the PSX2PSP emulator will not work on the new 5.00 M33 firmware, which supports 24 bit depth. You will need Popstation, which supports a 32 bit depth, in order for it to work on 5.00 M33. Thanks rayman123!Update 2:If you have a PSP-1000 you will be interested to know that a 1.50 addon has been released for firmware 5.00 M33. Make sure you download the 1.50 firmware update to install this addon.Thanks to dj_3sixty for the tip!
