I hope it will be useful.How to dump your save files from your original cartridge onto your R4 DS / M3 Simply in 10 steps(source : http://frodo.dyn.gno.org/~brettk/savsender )What you need in addition to WiFi access point, Computer, NDS with network access configured and R4 DS / M3 Simply :- savsender (d/l it here http://frodo.dyn.gno.org/~brettk/savsender )- netcat (d/l it here http://www.vulnwatch.org/netcat/ )- dd (d/l it here http://www.chrysocome.net/dd )1/ Patch savsender.nds with the correct DLDI patch2/ On the root of your media card, create "/DATA/SETTINGS" folders, and create a new text document called "savsender.conf" which contains the following lines : 192.168.1.123 5000 (where 192.168.1.123 is your computer's IP address and 5000 is the port number used for the transfert).3/ On your router, forward the port 5000 to your PC (192.168.1.123).4/ On your computer, copy nc.exe and dd.exe in a new folder.5/ In a command prompt, run the following command : nc.exe -l -p 5000 > savefile.sav6/ On your DS, run savsender.nds7/ When it tells you to press A to dump the save file or B to restore, swap to the official DS cartridge and then press A. It will automatically detect the save file and send it over WiFi to your computer. 8/ Once it says "Done!", turn off your DS. Then, go to the command prompt window that has netcat running and press CTRL+C to kill it. 9/ In the same command window, run the following commands to fill the save files with blanks up to 512 Ko : dd if=/dev/zero bs=1k count=512 > "newsave.sav" dd if="savefile.sav" of="newsave.sav" 10/ Just copy newsave.sav alongside your backup rom, and rename it (if your backup is my_rom.nds, rename your save file in my_rom.sav).Tested and approved with European version of Zookeeper, Bomberman, Trauma Center, Brain age and NSMB. :whistling:
