I don't see this mentioned anywhere in the official no$gba thread (or anywhere else in that forum for that matter) so I wonder if it's worth mentioning and giving a mini-HOWTO setup guide for it.The utility is called NDS2XGL2 and what it essentially does is (taken from the official site):
Mysoft wrote:
1) 1.5x zoom fixed (to fit in 1024x768) (fullscreen is TODO)2) Allow NO$GBA to rotate the screen3) Can Speed NO$GBA emulator a bit (2%-10%)4) It uses/requires OpenGL (a faster card more speed-up)5) It will remeber the last select files for the roms you open using the normal open method (rom list not supported in this version)6) It add 2 filter for the Graphics HQ2X and Scale2X7) Add Right Click in the Touchscreen area (simulates mouse-look like those new games (CS/quake/etc..)
In the next release (whenever that comes), there will be a profiler and maybe auto-detection of game save type (THAT will be useful) as well as 2x, 3x, and as you saw, full screen screen support....and plus I've noticed that it fixes the display in certain games (e.g. the pokedex description shown just after you capture a pokemon which is mostly invisible in regular no$gba)The official thread is here:http://forums.ngemu.com/no-gba-discussion/...ew-version.htmlIf someone wants to write up a quick mini-guide or just append to the no$gba one (as this is pretty much essential), then great. Otherwise, post your feedback here.
