Introduction The following is a guide to a fantastic tool for use in PlayStation emulation called the PlayStation Emulation Cheater, or PEC for short. This guide is written under the assumption that its readers understand the basics of PlayStation emulation, including such functions as plug-ins and running the games. If you do not, it is recommened that you read the following thread PlayStation Emulation Information The guide does contain - where relevant - pictures to aid with the explanations. If you use Bleem!, VGS, or any other emulator, PEC will still run, however, this guide will not cover the specific abilities dealing with those emulators.II. What is it and where can I get a copy? PEC is a program, very much like any other, that simulates the effects and actions of a GameSharks for use with any of the PlayStation emulators. PEC supports PlayStation games from all three major regaion: NTSC (North America), PAL (Europe), and Japan. The current build of PEC was last updated on the 8th of August 2002 and contains more than 71,000 pre-registered codes for over 1,800 games. To obtain a copy of PEC go to the offical website of the Playstation Emulation Cheater (Link) where the latest build is available in the download section (The official website domain is dead. Use the link in section IV for an available download).III. How does it work? / Requirements The concept behind the GameShark is relatively simple: within each game are lines of code that represent an item or action within the game. The GameShark, acting on the code inserted into it, will overwrite certain lines of this code to gain or modify whatever aspect the user desires (life, ammunition, weapons, time, etc.). This is where that wonderful PEC database comes in handy! The authors pre-programmed numerous codes into the database that are available immediately. The process is simple as the program itself, just load the game, select the codes desired, send them to the plug-in, and continue playing. The requirements are simple as well. PEC is fully compatible with any modern PlayStation emulator (PSEmu Pro, ePSXe, AdriPSX, PSCX, FPSE, SPinex, Bleem!, and VGS). PEC will also run on any Windows-based Operating System (95, 98, ME, 2000, and XP); however, PEC will not run on MacOS or Linux-based systems. Again, PEC will not run on MacOS or Linux! A Pentium II, 300 Mhz or comparable computer is required, as are a minimum or 32 Mb of RAM, and 10 Mb of free hard-drive space. Essentially if you can run the emulator, you should be able to run PEC as well.IV. Setting up PEC NOTE: Recent Operating Systems include the "account" feature. Begin by downloading the setup file: Setup File. If you have a large hard drive, or easily lose track of files, we recommend saving the file to your desktop for quick and easy access. Double click on the download file to begin the setup process: this will bring up the screen pictured in(Setup1). It is recommened to install the files in a subfolder of your PlayStation emulator folder. Once you have selected the location click Next>. The following screen will inqure as to the location in which to install the PEC plug-in. To run PEC, the plug-in must be in the same folder your emulator's plug-ins are in. Click Next>. The subsequent screen will ask one last time about your choices so click Next>. This screen(Setup2) will summarize your selections. Double check and click Install. Congratulations, PEC is now installed. You can now run PEC. Select the Finish button to close the setup file.V. Finding Cheat Values in Games In the event that you want to alter a part of the game but can not find a code for it PEC still provides a solution: the PEC Cheat Hacking Engine (CHE). While playin, you may pull up the engine to modify the in-game memory, thus creating new cheat codes on the fly. The example used is NTSC Final Fantasy VII to find the memory address for Irvine's health in battle Load the game into the emulator, make sure the plugins are set correctly. Get into a battle (CHE1). Open the Cheat Hacking Engine by pressing Ctrl+H. Everything is self-explanatory so begin searching. Because we know that Irvine's health is 7002 the search is narrowed down from the beginning. Search for 'equal value', data type 'short',value '7002', search range 'complete memory', and data base 'decimal'. Clicking Search will bring up the results which are 11 values matching that description (CHE2). Resume Emulation and letting Irvine get attacked will bring his health down to 6839 (CHE3). Return to CHE and do another search. Since the exact value is still known an 'equal value' search can be done for '6839' resulting in 4 matches (CHE4). Now that there are only 4 matches modifying the individual values is practical. Highlight the values one at a time and click Modify. Modify them to different values and click Ok (CHE5). Return to the game and see which value it changed to (CHE6). This tells you which of the addresses was the correct one. Returning again to CHE there are two options, freeze the value or copy it. By freezing the address at a certain value (CHE7) it acts as a gameshark code until cheats are deactivated from the PEC program. So regardless of how many times Irvine gets attacked now his health will never change (CHE8) The other option, copy will use clipboard to copy the memory address until it is stored in either the codelist.inf or the User Database.VII. Adding Cheats to the User Database The User Database feature allows you to add custom codes to PEC without having to edit the actual codelist. To access the User Database, click on File, then select such (UD1). Click Add Cheat and supply an appropriate name for the code you wish to insert in the title box. This title is purely for reference purposes and will not affect how the cheat functions. Under the Codes box there are two other boxes, the first being a little longer than the former. This is where you insert the code. In the first box, type the eight alphanumeric symbols that make up the memory location, and in the second goes the four symbols that specify the value that will be altered. Click Add to submit the cheat. In the event that a cheat contains more than one line of code, simply continue to insert them until all are submitted. Once the full cheat has been typed in and submitted, hit Ok. Now that all the codes are entered, simply check the box alongside those cheats you wish to activate. Click OK in the bottom right-hand corner and a box will pop-up asking if you wish to save changes (UD2). Select Yes and you will be returned to the primary PEC window. Send the cheats to the plug-in, by hitting the Cheats to plugin button, and enjoy!If you wish to deactivate any of the cheats in the User Database, simply uncheck those codes, save the changes, and resend the codes.VIII. Editing the Cheat List or Creating Your Own The cheat list is the huge database where all the pre-programmed codes are and in order to make your own or edit the orignal you must know the syntax of the file. This section attempts for explain the syntax of the codelist.inf (the real file name of the cheat list) so that you may add your own games to it. If for any reason that you miscode a part of the codelist.inf PEC will not start. Again, if you type something wrong in the codelist PEC will not function!.1. The Game The first line of code is the identifier (known as a TI), without it the codes are useless and PEC will not run. It is presented like so: {#game title#gameID}. The title is a given, but what, you ask, is a gameID? Each game created is given a unique ID; for PlayStation games, this ID is made up of two distinct parts: the region and the serial number. The game CD itself has the ID on it, but if you do not possess the actual CD there is another way to obtain it. Run ePSXe with the game and create a save state. Go into the save state folder and look for the most recent modified file. The region will be the four letters followed by 7 numbers, the 1st 5 are the serial number. For example, using a NTSC version of Crash Warped a save state would be named as SCUS_942.44.00 therefore the game ID would be SCUS-94244. So the TI for the game would be written as #Crash Warped#SCUS-94244. For games that are on multiple discs you will need to list each disc in order. For example, NTSC Chrono Cross which is 2 discs will have a TI of #Chrono Cross#SLUS-01041#SLUS-01080. More discs may be added as needed.2. Basic Codes, Folders, and Notes Basic codes are those which do not require a variable or list to choose from. On the line after the TI you must insert a straight quotation mark (") followed by the name of the code, then on the following line the actual code.For instance, once more using NTSC Crash Warped.#Crash Warped#SCUS-94244 "99 lives D005BEEC F64C 800B5D4C 6300 D005BEEC F64C 80068F58 6300 There does exist one catch; you have a limit to the number of codes that can be shown at once for any game. To counteract this we introduce another feature, creating folders. This allows you to group the cheats that are similar to each other. When creating folders, rather than inserting {"cheatname} you will insert {"foldername\cheatname} instead. You must use a backslash for this purpose and no other or else it will think there is a folder there and that can mess things up. For example, NTSC Final Fantasy VII using folders would appear as such.#Final Fantasy VII#SCUS-94163#SCUS-94164#SCUS-94165 "Battle\Invicible 300F83E3 0001 300F844B 0001 300F84B3 0001 "Battle\no battles 8011627C 0000 8007173C 0000 "Battle\mega battles 8011627E FFFF 8007173E FFFFAs you can see, the folder name is Battle and the cheats that affect the battle are listed inside. While folders do allow you to sort your cheat codes, they do not allow you to add notes to them, such as how to use them in the game and when not to activate a code. The note feature allows you to place as much information as you wish concerning any code with any game. To create a note you must use a period "." at the end of a cheat then write the note. Again, using NTSC Final Fantasy VII as an example, a note would appear like so:#Final Fantasy VII#SCUS-94163#SCUS-94164#SCUS-94165 "Battle\Ulti D0062D78 0085 800F5E6A 00FF D0062D78 0085 800F5E9E 00FF D0062D78 0085 800F5ED2 00FF .Press L1+L2+Square to fill up your limit break. "Battle\Invicible 300F83E3 0001 300F844B 0001 300F84B3 0001The note "Press L1+L2+Square to fill up your limit break." will now appear in the notes box (see "Notes" in Section V for further information) when the Ulti cheat is selected.3. Modifier Codes As many codes affect totals within a game (such as the amount of lives, money, or items your character possesses) making use of a question marks (?) will allow you to choose a variable value for codes. You must first use the question mark in place of the code area, then end the code with a question mark, noting the values that may be submitted for such.For instance, a valued code for money might appear like so:"Gold amount01020304 ?????0000-FFFF PEC interprets that the value of ???? is between 0000 and FFFF; upon selecting the code, you will be prompted to choose a value. This same rule applies to codes where the last 1-4 digit(s) are variables; however, attempting to recall what each represents is a painstaking and difficult task, thus, the list feature. Lists are denoted by the dollar sign ($) that is placed in front of each value. A listed and valued code for an item in slot one might appear as follows:"Item Modifier\18009CBE0 C???$602 X-Potion$603 Ether$604 Turbo EtherIn cases such as this, PEC will not prompt you for a value, but rather, ask you to select the item you desire from the supplied list.If you are going to be using a particular list a lot you can put it in after the TI using the and (&) sign. Then instead of listing the options every time after a cheat, use the percent (%) sign plus the list name. Then when the cheats are selected they will bring up the list, the same principle can be used for notes as well.-this is an example using NTSC FFVII, in the cheat window there will be a folder called Item Modifier with the options of 1, 2, and 3 within and the list of five items will appear for each as well as a note#Final Fantasy VII#SCUS-94163#SCUS-94164#SCUS-94165&ITEM$602 X-Potion$603 Ether$604 Turbo Ether$605 Elixir$606 Megaelixir&Note1.warning! this will replace the current item in the slot"Item Modifier\18009CBE0 C???%ITEM%Note1"Item Modifier\28009CBE2 C???%ITEM%Note1"Item Modifier\38009CBE4 C???%ITEM%Note1 This is a real warning! If you do not type the names exactly the same they will not work, they are case sensitive! Now that you have a basic grasp of the syntax of the file, you may begin to edit such. Begin by opening the PEC folder you created when first you set-up the program; within that folder will be a file named codelist or codelist.inf. This is the database where all the games, codes, and values are stored. Before you attempt to edit this file, open a new and empty Notepad file. Attempt to create your own game codes within this file using the syntax that was just reviewed. Save the file as codelist.inf, making sure that the tab "All Files" is selected. Rename the current codelist.inf as original for backup purposes and replace with the one you made, and attempt to run PEC. See Section IX for troubleshooting with the codelist.inf file. For some reason I keep getting an error or it crashes when I run PEC, why?A. PEC, just like any other program, is not perfect. Users are urged to consult the notes provided for any code (see "Note" in Section V for further information), as many will occasion errors if used at improper times. Unfortunately, in the event of an error or crash, the only solution is to reload the emulator and begin your game from your latest save.Q. When I attempt to load PEC it says "there was an error loading the codelist.inf file", what happened?A. This error occurs whenever the codelist.inf file is improperly edited, or has been corrupted. If you have been editing such in an attempt to create a custom cheat list, note that a blank line or improperly placed space will result in an error of this sort. Check the document to ensure if any such mistakes exist. If you have not edited the file, the error is most likely a result of file integrity corruption. In this case, the only solution is to revert back to the original or download a new copy of PEC. Q. I don't understand how to add codes to the codelist.inf file, what should I do?A. The code that I selected is not working, why?A. Unfortunately codes do not always work the same way twice, nor do they always work in the manner they are supposed to. Occasionally you will be required to modify your game settings for the code to activate; this usually entails moving to a new area or switching to a new character. Q. Nonetheless, bear in mind that each cheat you choose to activate will similarly increase the chance of an emulator or program crash, as each makes further demands on your processor and memory. Generally, it is best to not activate more than five codes at any one time, save it be they will shortly be removed.Q.
