I got a few questions.How do I make borders?How do I add effects to my text?How do I make mine look so cool?Does anyone like my sig?
To make borders in photoshop,1. Create a new Layer, rename it to "borders" if need be,2. Select your new layer, Press CTRL-A or Select > Select All3. go Edit > Stroke > Set Width to 3px, Set Color to Black for example (its up to you), Location: Inside and leave everything else default and Hit OK.5. Do not Deselect, if you do, just repeat step 2.6. Repeat step 4, Set Width to 2px, Set color to White and leave everything else the same and hit OK.7. Repeat step 4, Set Width to 1px, Set Color to Black again and levae everything else the same and hit OK.To add some simple effects to your font,1. Type something with your text tool2. Double click on the (text) layer or right click on the layer and Select Blending options3. Tick the Drop Shadow box to add shadow4. Tick Stroke, select Color to Black and set Width to 1px to add an outline.These are just some standard stuff. just experiment around till you get the effects you like :blink:
