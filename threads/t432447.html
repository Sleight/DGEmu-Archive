Mad Monk Rasputin' post='4521545 wrote on Feb 23 2009, 12:10 AM:
But isnt that the same reason why Macs have no viruses? ie: no on bothers?Or is there some actual protection?
People do try on occasion. It is a combination of factors. One is the fact that unlike windows security updates are put out daily instead of on a release schedule. No matter how minor or major the update. Another is the fact that you have a LOT more people to review the code and fix problems that could let viruses into the system. Another is the fact that nothing can be installed or set to run without the user explicitly giving it permission to do so. For installing stuff that means typing in a password so even if you let someone else sit down to use your computer they can't install a virus either. Also file extensions can't hide a virus on linux. By default in windows file extensions are now hidden and windows (in a completely retarded manner) treats the file as the first extension it fins but shows the file type icon of the last extension it finds. This is one of the most common reasons people get viruses on windows. You download a file you think is porn and it looks like it is (just an arbitrary example) hotbabe.jpg when in reality windows is being retarded and the file is really named hotbabe.exe.jpg and the exe part which indicates that it is in fact a program and not an image is hidden. So you only see the icon for a jpg. Yet when you double click on it instead of loading an image for you to spend some special alone time with windows runs the exe and tada you now have a virus. Meanwhile Linux will allow file association based on the file extension but you can't just double click on a file and have it run unless you manually modify the properties and set it to be executable regardless of how it was set on another system before you downloaded it. And hopefully NOBODY is stupid enough to believe they need to set an image as executable to view it.The entire OS is designed around permissions systems and security so yes, there is a LOT of protection against viruses inherit to the design.
