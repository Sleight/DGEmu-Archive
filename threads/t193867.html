AatomicknightFeb 15 2007, 10:38 PM
So while randomly perusing through the InvisionPower bug tracker, I discovered the reason why these members are being deleted. Apparently the manual validation script completely disregarded the fact that there's a table called "validating," which contains all the validation requests (registration, e-mail, password, etc.). Now when a user is able to validate normally, his/her entry is deleted from the table and everything is okay. However, manual validation didn't do that and so as far as the forums were concerned, the member still did not validate. Now IPB has a task that deletes old validation requests, meaning that any users who still had entries in that table were deleted when all the validation requests were pruned.So yeah, I've fixed that now. As for some of those previously validated members......well, let's just say that some of them don't exist anymore >.< But that shouldn't happen anymore.
