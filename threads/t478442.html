KKirie MotobaDec 14 2012, 05:27 PM
Usually, when you get a temporary user profile like that, 1 of the following scenarios is possible:
1. Windows partition completely ran out of space (0 bytes available)
2. Corrupted Windows profile

In the case of #1, clean out temp files and such, and once done, restart the computer. Everything should be good.
In the case of #2, this can be multiple factors at work:
- Failing hard disk. Backup your stuff, and have your system serviced for hard disk replacement. If you're on an HP or Dell laptop, they all have self health check tools available at the bios screen. You should try to run a extended SMART test. If your laptop is of any other brand, you'll need to go get yourself a copy of Hiren's Boot CD or something to run the SMART test with a third party tool.
- Virus infection. Can potentially be fixed by cleaning out said virus.
- Bad shut down that corrupted profile files. Can potentially be fixed by running a checkdisk or a system restore to a earlier point.

A very easy way to get around this is to do this:
- Accessing this temporary profile, go into Control Panel, create a new administrator user account. Once done, restart your laptop and login to your new account. You should be able to get in now, minus all your personal files and customisations, but it will be in normal mode. From there, you can troubleshoot more easily, do your backups, etc.
