DG Games
This site was created by a forum user here at DGEmu. They legitimately collect up flash games from around the internet and post them to be played for free. You can even create an account to add comments to games, create a favorites list, etc.

Tardis Remakes
This guy likes to create remakes of obscure and great old games.

DigiPen Student Games
Vancouver Film School Student Games
These are lists of freeware games created and released by students of DigiPen Institute of Technology and Vancouver Film School.

Game Giveaway of the Day
Originally posted by Sir VG
A game is offered nearly every day. Once it's posted, you have 24 hours to download it. If you do, it's yours! They're not the uber elite games, but you might find something fun there. Check it out!

Humble Indie Bundle
Not exactly free, but it still bears mentioning (not at all because I love it lol). They post bundles of independently created games for whatever price you want to pay from a penny and up. We do post most of the games here, but if you purchase it yourself you get keys to unlock the games on Steam, OnLive, Desura etc.

The Indie Game Database (TIGdb)
A project that compiles a database of indie games. This section of the site is freeware only.

The Interactive Fiction Database
It's a game catalog and recommendation engine. IFDB is a Wiki-style community project: members can add new game listings, write reviews, exchange game recommendations, and download text-based games.

Play by Email
Though the site looks simple, it is considered by many to be the resource for games that are played via e-mail communication.

Retrospec
Retrospec offers quite a few old-school games on Windows, Linux, and Mac.

Pixel Prospector
This section of Pixel Prospector includes a number of free to play indie games. Some are browser games and some are downloadable. The main site itself is a great gaming resource as well.

Liberated Games
Liberated Games is dedicated to cataloging all full commercial games that have been liberated and made free in playable form to the public. Some of the games are simply the source code and are not playable on their own though.

Pica Pic
This is an amazing ongoing project that posts old LCD games to be played in your browser.

Free PC Gamers
It's pretty self explanatory. A site dedicated to listing well made free PC games.

Game Jolt
This site has an array of independent open source, freeware, and flash games.

Freeware Database - Retro Remakes
These games all seem to be remakes and rehashes of other commercially released games. There are currently more than 2000 games.

Experimental Gameplay Project
They're a group of indie game developers, running a friendly competition every month. The rules: Make a game based on the month's theme, and don't spend more than 7 days. New games posted at the end of every month.

There are other Indie Bundles that offer groupings of games and/or game music for low prices, though not quite free. They often offer Steam codes and/or DRM-free downloads.

Indie Royale
Indie Gala
Indie Facekick by GATT
Indie Game Music Bundle
