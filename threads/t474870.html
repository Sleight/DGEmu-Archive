Well, "latest release" isn't very informative to begin with.. Alas, I've checked the site of this flashcart and it seems that they have fixed all ds roms up to X-men destiny (5822 on our list) in their latest firmware, version 3.7. Atsumete! kirby seems to be release 5786, so giong from that it should work. However, there are different ways of numbering roms, which might mean that your game isn't fixed yet. because we're not certain up to which game they have fixed, we can't tell for certain whether or not your game should be fixed.However, there is an easier way. It took me a while to find, but it seems that this flashcart is actually an R4 clone, meaning that you can use alternative firmware on this flashcart that supports more games! The most compatible one in most cases is YSmenu. Usually it takes a while to set up, so I recommend using this program to install it: http://filetrip.net/f9452-YSMenu-Generator-for-R4M3SimplyClones-1-5-3.html After that you're not done yet however, you also need to update certain files, here's a good link to regularly updated http://filetrip.net/f26890-RetroGameFan-DAT-Update-6-72-5930.html
