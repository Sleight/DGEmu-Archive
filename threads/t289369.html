Mods you are free to do with this what you wish.

As many of you are aware, the newest version of VBALink supports networked wireless multiplayer. Head over to http://vbalink.wz.cz/#download to get it.

Well many of you were having troubles connecting over the internet with friends, as you were both behind a router, so when you start the Server you are given a generic internal IP such as 192.168.0.3 etc.

Note - for this guide to work, I am assuming you have admin access to your router. If you aren't sure, a good place to start is this default password list. If you don't have admin access to your router, you can consider using LogMeIn Hamachi for zero-configuration VPN (LAN over the Internet).

Firstly, set up a static IP address for your computer, something in the internal range the router allows - such as 192.168.0.3. For most routers you will have to know your MAC address for this, if you don't know how to find this out refer to the end of this post.

If you don't know how to set up static IP addresses from your router control panel, then you can do it locally by following this guide. Beware though, as routers run a DHCP Server - if you have multiple computers in your local network, and another connects before you and is assigned the IP address you have set up as the static IP for your computer, the computers will conflict and the Port Forwarding rule you are about to set up will not work. For this reason, it is best to learn how to set up static IP addresses on your router, rather than trying to manage them locally on each computer.

Set up a new Port Forwarding rule whereby port 5738 has TCP forwarded to the Static IP Address you set up for yourself (our example being 192.168.0.3).

If you don't know how to set up Port Forwarding for your router, please refer to: PortForward.com.

Go to www.whatismyip.com to find out the external IP of your router.

Open VBALink, go to the Link settings and start the Server. It will still say that the server IP is 192.168.0.3, but if you give your router external IP address to your friend / opponent and they put that into the Client, in the Server-address entry box, (assuming the Port Forwarding rule has been set up correctly) all the traffic will be forwarded to your computer. The result is voila, you are connected.

To find out your MAC address in Windows, hold down the Windows key (between the Ctrl and Alt) and press 'R' or you can go to the Start Menu and press Run. Type:
cmd /k ipconfig /all
Your MAC address is the one that says "Physical address", it will be in the form ##-##-##-##-##-## where # denotes any alphanumeric character.

If anybody wants more information on how to do this, then post here stating what router you have.

Please note - if you have dialup or a direct broadband connection (i.e. through a modem) you do not need to do all this. The IP VBALink tells you should indeed be the correct external address to give to your friend.
