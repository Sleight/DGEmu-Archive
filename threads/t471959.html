Yes, you should be able to trade from one pokemon GBA game/ROM to another, even when using flashcarts.See this for more info: http://gbatemp.net/t274701-questions-about...t&p=3394952As for trading with pokemon blue, you will need 2 actual games, since goomba color supports no multiplayer/trading at all.Also take note that you will need a GBC link cable for pokemon blue, not a GBA link cable (there's a difference).Since you are already using emulators you might like to note that trading between ROMs on PCs is also possible.Use VBALink for trading with GBA ROMs, and TGB Dual for GB/C ROMs. :D (there is a rather boring-looking but simple TGB Dual guide here)
