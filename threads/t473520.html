GGBATESTAug 07 2011, 06:36 PM
It might be that you loaded your save state and it erase your in game save.For example,A - First save in game.B - Than you save using save state.C - Than you use save in game.If you loaded B, than C is erase since the save state happen before you saved C. The save state can only see what happen at that time.Is that what might have happen?You can test your save file in another folder and see if that is case.Create a new folder and extract VBA emulator into the folder. Copy your ROM and battery file (name of game.sav) to the new folder. Do not copy the save state file.Than open the ROM.If it loads your save before the save state than your third save was erase by loading the save state.You can play from the save state. After you do a in game save, you can rename the save state file to a different name so that you do not accidentally erase your in-game save.

If your emulator writes to the SAV file ONLY when you exit (VBA does), There is a chance you can save your SAV file by just copying it BEFORE closing the emulator or loading a different save state.ieYou open VBALoad up your ROMOH NO, THE SAVE STATE HAS BEEN LOADED! I AM GOING TO LOSE MY DATA!Don't panic, Go and copy your SAV file or rename it. Disable autoload and close the emulatorNow go delete the new SAV file (The one from a few hours back, That VBA created just now) and rename the one you copied/renamed to what it originally was. (Eg: Pokemon Emerald (U).sav)Reopen VBA and load the ingame save. WIN!From what I remember (Yes, I had the same problem as you) VBA writes the SAV files only when you exit. I tried it out just now and it seems to be the case so if you have this in future, Try out what i said(If what i said isn't clear, I'll rephrase it for you)
