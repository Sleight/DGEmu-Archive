Before opening a thread that asks anything about GBA emulation and emulators, please read the following and see if your question is answered. Any member making a thread whose content is covered here will receive a WARN.

GBA emulation is currently at a very advanced stage and most commercial roms are perfectly emulated. However, certain ROMs require that you adjust the settings of your emulator in order to run them. Here is a compilation of the most frequently asked questions. Read them carefully.

Q: Which is the best emulator?
A: We strongly recommend that you use VisualBoyAdvance Link (VBA Link in short). It is currently the best emulator in terms of game compatibility and features (including linking). The recommended version for most roms is 1.7.3, although you may need to use version 1.8.0b0 for certain roms.

Q: Where can I download VBA Link?
Official VBALink HomePage

Q: Where can I download GBA roms?
A: On DGEmu of course. Either browse the GBA rom pages or use the rom search function.

Q: Can a game from Europe play on a US/Japanese GBA (or vice versa)?
A: Yes. All Nintendo handhelds (GB, GBC, GBA, NDS) are region free. You can play any game on any region of handheld.

Q: What is the difference between VBA and VBA Link?
A: They are almost the same, except that VBA Link provides the capability of linking two games whereas VBA doesn't support the link feature. That is why we recommend VBA Link. However, the different tutorials are valid for both emulators (except for the link part of course).

Q: I don't know how to use emulators. Could anyone help?
A: Read this topic for a complete tutorial of the different features in VBA Link.

Q: My emulator is too slow. Do you have any suggestions?
A: Read this page.

Q: Help, when I open a rom, all what I get is a white screen.
A: Follow EXACTLY the instructions in the first post of this topic.

Q: How come all Pokemon games don't work?
A: Same as above.

Q: I have the following error message: "The 1M sub-circuit board is not installed".
A: Same as above.

Q: The Dragon Ball games don't work. The error message "This game cannot be played on this hardware" is displayed.
A: Same as above.

Q: Pokemon Mysterious Dungeon Red doesn't work/save.
A: Same as above. If you set the wrong save file type, you'll be able to play the game (it works) but won't be able to continue the adventure (it does not save, thus you can't continue it after you beat the game).

Q: The Classic NES games don't work. What can I do?
A: You'll have to download the patched versions here: http://www.dgemu.com...pic=130120#romi

Q: The Sims 2 - Pets has major graphics problems. Is this a bad ROM?
A: No, the issue is that VisualBoyAdvance 1.7.2 can't emulate it properly. Use 1.8.0 Beta 3.

Q: The Game Boy Advance videos don't play. How do I make them play?
A: Use VisualBoyAdvance 1.8.0 Beta 3. Prior versions don't play the video.

Q: How can I play e-Reader cards?
A: You need to use a special modified version of VisualBoyAdvance. You can download it from this site.

Q: Can I link e-Reader cards with a game (such as Super Mario Advance 4)?
A: Not at this time. You can only play stand-alone cards.

Q: I keep getting the following error message: "The internal battery has run dry"
A: Go to Options -> Emulator and check Real Time Clock.

Q: I have already spent many hours on my Pokemon game and it cannot save. Is there any way to fix it?
A: Yes, there is a solution. Please read this topic.

Q: How do I use cheats?
A: Read this topic.

Q: When I delete cheat codes, they are still activated.
A: Make an in-game save and soft reset your game (CTRL+R).

Q: I have problems with Pokemon cheat codes.
A: Read this topic.

Q: How do I patch a rom?
A: First, download GBATA from http://gbadat.altervista.org/tools.htm. Run the program (gbata.exe) and then click the "..." button to load your rom (zipped or unzipped). Then click the "IPS Patcher" tab, click the top "Select" button to choose the patch, change the Output File path if you want, and hit "Patch." This will generate a new patched rom.

Q: Why do I get this error message "Error creating file Battery Saves/...." on the Mac Emulator?
A: You need to extract the Save and Battery folder that came with your Mac Emulator.

Q: How can I get my VBA save file to VBALink save file or vice versa?
A: There are two options that you can do. Either...
1) You can use the import and export function to transfer the file over to the other emulator. In VBA, you would export the battery file. In VBALink, you would import the the battery file. If you want it the other way, than do export in VBALink and import in VBA.Or...
2) You can make a copy of your VBA save file (nameofgame.sav) and rename the save file to nameofgame.sa1 (first opened VBALink will see this save file), nameofgame.sa2 (second opened VBALink will see this save file), etc... To get it from VBALink to VBA, you rename the save file from nameofgame.sa1 or nameofgame.sa2 to nameofgame.sav.
