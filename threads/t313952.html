Name: Game Boy Advance (Shorten to GBA) [Left Image]Release Dates: Japan- March 21, 2001North America- June 11, 2001Europe- June 22, 2001Australia/New Zealand- June 22, 2001China- June 8, 2004Name: Game Boy Advance SP (Shorten to GBA SP)[Middle Image]Release Dates: Japan- February 14, 2003North America- March 23, 2003Europe- March 28, 2003Australia/New Zealand- March 28, 2003China- November 18, 2004Name: Game Boy Micro [Right Image]Release Dates: Japan- September 13, 2005North America- September 19, 2005Europe- November 4, 2005Australia/New Zealand- November 3, 2005China- October 1, 2005General SummaryThe Game Boy Advance (GBA) is a handheld gaming console that is a successor to the Game Boy Color. The GBA was made by Nintendo and is part of the sixth generation. The GBA was backward compatible with Game Boy and Game Boy Color titles. A few years later, GBA SP was release that addresses some issue that people had with the original GBA. Also GBA SP had added new and much brighter LCD screen, which improved playability.In 2005, Nintendo released the Game Boy Micro and GBA SP+. The Game Boy Micro is a smaller and sleeker design than the GBA. It is unable to support Game Boy and Game Boy Color titles.
