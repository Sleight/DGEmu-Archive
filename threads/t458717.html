Metal Slimononon' post='4842873 wrote on Jul 18 2010, 12:33 AM:
Torrents seem like the best solution to that, but that would obviously completely negate the point of the forums.
I feel that anything that reduces the need to post to earn more download credits (or that makes posting a less important source of download credits) would make everyone's experience better. Presumably we would end up with less spam and perhaps a bit more quality content (focusing on emulation, configuring emulators, etc.) rather than discussion topics filled with inane content.Regarding the whole discussion on compression: generally, the compression ratio for 7z isn't significantly better than that for RAR for single files ("significantly better" defined arbitrarily as approximately 10% and above). The 7z format's main compression advantages show up when you archive multiple copies of approximately the same data - you can sometimes get huge improvements in compression ratio in such cases. From a programming perspective, 7z would be a better choice simply because it's an open standard, which increases the chances of finding APIs compatible with whatever system is being used. I would personally prefer using 7z, but there is of course the issue of educating users so that they'd be able to use it properly.
