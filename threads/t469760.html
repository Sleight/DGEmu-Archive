CD Keys/CracksTopics such as: "Any1 has a good cd key for HL2 please reply?"These topics never get a decent answer and only lead to spam. So please stop posting about them in here. Do not ask for CD Keys or Cracks and do NOT post CD Keys or Cracks, we do not provide them.Support QuestionsEach time you make a new topic to ask support/help for a problem, make sure to give enough information for other people to be able to help you. That is, give a detailed explanation of the problem, tell any possible changes you made for it to occur, etc. Topics like "my computer is crashing, plz help" are unacceptable and the user may be warned. Also we recommend you try a forum that deals with the situation, for example if it is a problem with a game we suggest you look for a forum dedicated to the game and post there, they will instantly now what is the problem rather then as just guessing.Building PCs topicsIf you want to make a topic to get recommendations on hardware you should use to build a PC, then make it in the hardware and software section. Specify how much you are capable of spending (and currency you use), and what is the use you want to give to the pc (gaming, school, graphics etc).Prices postingIf you want to post the price of anything, please state the country that it refers. $20 is not the same in the US that it is in Canada or France, etc.Asking for cheatsDo NOT start topics asking for cheats, use a search engine to find them, or go to a cheat site (eg GameFAQs).Asking for game recommendations Do NOT make posts to ask recommendations on a certain type of game. ex: "can you guys recommend me a good shooting game?"All these topics lead to spam because everyone has a different opinion. So you can just look at topics concerning the type of game you want, and read what people think.
