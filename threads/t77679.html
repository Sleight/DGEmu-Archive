DDaft PunkOct 12 2005, 10:02 PM
yeah, make sure you have the pen tool selected on paths mode (the middle overlapping squares in the top bar) draw the path you want the text to follow (dont need to connect the ends if you dont want) then select the text tool, hold it near the path and click it, should be able to see that its all lined up the the path now so just type whatever you want and it follows it.
