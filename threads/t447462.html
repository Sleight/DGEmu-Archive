[MH] Touhou Project - Collection 2009

My 4th release to the Internet community. A big collection of many Touhou games spanned onto 2 DVDs. The release date was due for September 8th 2009, but I decided to release it a few days in advance! ^^

The release contains the following:
- Anex86 (to run Touhou 1 to 5)
- Endless Alice
- Endless Marisa
- Koumajou Densetsu Scarlet Symphony
- Marisa to Alice - MariAri
- MegaMari
- Marisa no Yabou
- Mystical Chain
- PatchCon! Defend the Library!
- Super Marisa Land
- Super Marisa World
- Touhou 6 - Embodiment of Scarlet Devil
- Touhou 7 - Perfect Cherry Blossom
- Touhou 7.5 - Immaterial and Missing Power
- Touhou 8 - Imperishable Night
- Touhou 9 - Phantasmagoria of Flower View
- Touhou 9.5 - Shoot the Bullet
- Touhou 10 - Mountain of Faith
- Touhou 10.5 - Scarlet Weather Rhapsody
- Touhou 11 - Subterranean Animism
- Touhou 12 - Undefined Fantastic Object
- Touhou 12.3 - Unthinkable Natural Law
- Touhou Battle Gaiden
- Touhou Defense Force
- Touhou Dreamer's Party
- Touhou Eastern Spirit of God Medicine
- Touhou Gensokyo Rensa
- Touhou Hiya Tai Ki
- Touhou Huhiki
- Touhou Soccer Moushuuden
- Touhou Splinter Cell Code-R
- Touhou Tower Defense

Due to some changes for compability reasons, some games cannot be updated with future official patches. Please make sure to read the documentation that comes with the install as some games will not function without a proper setup of the system's regional settings.
The rar file contains the DVD images for the 2 discs in iso format of the release, along with custom labels for the disc and case.
Special thanks goes to Sezuki from animepaper.net for allowing me to use some of his work for my release, so I also added a bonus of 3 wonderful wallpapers he created into this release.
