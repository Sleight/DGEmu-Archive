HOW TO SET UP YOUR DSTT(Adapted from GBATemp's guide)1. Backup all your files on your microSD card, then format it with the official SD card formatter.Then put the data back.2. Download the unofficial TTMenu (the "firmware") here: http://gbatemp.net/index.php?showtopic=267243Do read the txt files, they are pretty useful.3. Go to "DSTT_DSTTi TTMEnu" folder. Copy the "TTMENU" folder and "TTMENU.DAT" file to the root (not inside any folder) of your microSD card.4. Make a folder named "ROMs" on your microSD card. Download ROMs from DGEmu, extract the .nds files with 7-Zip or another archiver, and copy them to that folder.5. "Eject" the microSD card from your computer.6. Insert your DSTT into the NDS. Insert your microSD card into the DSTT. Turn on the NDS.7. You should see a menu with your games, and you should be able to run your games now. Always keep the following in mind: * Always leave some free space on your microSD card for save files and system files. * Always put ROMs into your "ROMs" folder. Leave as few files as possible on the root of your microSD card. * Always use "eject" to remove your microSD card from your PC. * Use the official formatter if you ever have to reformat. * Keep a backup of all the files that are on your microSD card. Backup your .sav files often. * Make sure you don't use the official "TTMENU.DAT" (particularly if you have a fake) because it contains fake-killer code.After you're done, be sure to update the "firmware" regularly, so that you still can play the latest ROMs. In fact every time you can't play new ROMs you should get the latest ones.Old stuff:

---------------------------------------------------------------------------------------------------------------------------------------------I noticed that there was no specific place for everyone to ask questions or to view info on the DSTT/TTDS like most of the other flashcarts seem to have, so I'll start this one.WHAT IS IT: A budget flashcart that is supported by two separate groups, neither of which is probably the real manufacturer of the product. Team neoFLASH and NDSTT are the two groups. NDSTT has released the most recent firmware for the product that has taken care of the issues that all the other flashcarts seemed to experience at the same time. V1.10 is the newest kernel as of this posting. YSMENU version is now 080520, which enables txt viewing if you press select twice to show all files.www.ndstt.com/english for kernel updates (site goes up and down)WHERE TO BUY: OZmodchips.com modchipstore.com dealextreme.com gameyeeeah.comSYSTEM PROS:1. So far as noted on this site and as played by myself, COMPATIBILITY with all games available atm.2. The cheat system is simple and files are compatible with the r4/m3 cheats, just use the r4cce prog to decrypt and save as USRCHEAT.DAT3. Simple file system with no superficial frills or extras. (With either YSMENU (http://home.usay.jp) or the DSTT OS)4. Compatible with eWin rumble and 2n1 packs out of the box. (YSMENU required to boot gba games or GBAexploader from the DSTT MENU{required for 3n1 from ezflash})5. Auto-DLDI and high access speeds for the SD slot making loading pretty quick unless you have fat32 formatting(not a huge speed loss).6. Changeable skins.7. Cheap and functional.SYSTEM CONS:1. File system does not list alphabetically/numerically on the original DSTT MENU. (Use Drivesort, Fatsort, or the copy/paste method) (YSMENU works too)2. The original OS is wanting in the User interface for most. No frills only works for some people.3. Original OS doesn't support GBA loading to the flashcarts or native support for the 3n1 pack.4. Contact problem issue for older carts, the newer batches are not having the same issue that I have seen in postings.5. Homebrew support is not yet at 100% for games. Most apps appear to work with no issue. 6. Requires self-install of Moonshell and DSOrganize.7. Does not support interchangeable skins on the fly.CHEATS: For cheat files ready made, visit GBAtemp.com and the download section. Uses AR/Codebreaker style cheatcodes, and even most homebrew codes will work with no issue as long as the game ID is correct.SKINS:Skins can also be found on GBAtemp.com as well as NDSthemes.com. Just copy all the files over the existing skin info in the DEFAULT folder (x:\ttds\skins\default).FAQ:Q. I get a face that says no card. What's going on?A. Make sure your card is clicked in and seated properly.Q. There's a face that says "Menu?". A. You either forgot to put the kernel on the SD or you improperly installed the YSMENU setup. COPY all the files from the DSTT OS d/l directly to your SD card(except the readme) for the original OS. If you opt for YSMENU, Make sure you followed all the instructions carefully on getting the core files from the TTDS.DAT file and put them in the system folder and have the YSMENU.nds changed to TTDS.DAT when put on the flash for direct boot. To switch between them, you can leave YSMENU.nds as is and click on that to load it, or vice versa to load TTDS menu as an .nds file.Q. My games will not load and either come up with an error that tells me to restart or it stops in the middle of loading and doesn't go any further.A. There are a few different issues that can cause these errors. Here are a few tips that can solve these 1. Don't use the reader that comes with the TTDS, it can corrupt files and make this a not so fun experience. Buy a trusted TF reader from a brand or get a multi-card reader that can read SDHC cards. Kingston makes a cheap one. 2. Use Rominator to put the roms on the SD. Drag and drop is a nice thought, but Rominator takes the extra step of validating your files and dropping them in there one by one, may take longer, but it could stop a potential headache. 3. Store all your extra files in a folder. DSTT OS will find them naturally. YSMENU uses a folder system, so no worries. Only put required files on the root, like Moonshell, DSOrganize, or BEUP. The FAT file system only likes so many files on the root of the drive, that's why Windows uses folders for system files. 4. Leave room on the card for save files. The cart creates one every time you open a game. It's 512 kb per file. Also some homebrews create user files such as BEUP.Q. My cheats aren't showing up as available and I know I added it to the list or downloaded a file with the game available.A. Make sure the file is in USRCHEAT.DAT mode and has been decrypted from the r4/m3 versions if it was intended for those systems. Also check the game ID, the added code could be for another region than the one you're using. Q. Wifi or d/l play isn't working correctly. A. Make sure you have it setup for your home network correctly if you're using a WFC compatible game. If you're going ADHOC, make sure your signal is good. Some trimmed and all overtrimmed roms will not work correctly with either option. A commerical dump rom without trimming will work with no issues.Q. Can I softreset back to the main menu from GBA Mode?A. Simply, no. Software and hardware limitations do no allow to softreset from the slot 2 back to slot 1. Save your game and then reset the system. The SRAM on the slot 2 carts needs this step to save files to the SD card. No software has been created to use everything from the slot 1 cart or interaction between the 2 slots to allow immediate save or access.Q. Slot 1 card is not being read and just boots to the DS firmware.A. The DSTT/TTDS were having a contact issue with earlier batches, and a few of the newer ones may be produced with the same problem. You have the option of shimming it into Slot 1 and forcing it down, which causes extra wear-and-tear to contacts of the slot and the cart. Some have opened the cart and shimmed it internally just enough to fix the issue and make it close to the same tolerance as commercial carts, not recommended if you could send it back and get a replacement. Last but not least, warping the cart with a little bending can solve it, but never do that. The best, easiest, and most worry free fix is to get a replacement cart.

DMA is an access type for hardware on comps and other things running processors/ram. It allows the processor to be freed of running some processes because they go directly between memory and the SD in this case.
