Any comment and suggestion is welcome.__________________________________________________No$gba (No Cash GBA) belongs to a series of well known Gameboy (No$GB), Gameboy Color (No$gbc) and Gameboy Advance (No$gba) emulators. They are among the best ones and provides many interesting features.Since the version 2.2 of No$gba, the emulator was implemented with NDS rom support and the current version 2.3 has a decent compatibility list. But the most interesting feature is probably the possibility to increase speed when we all know that other emulators most of the time runs slowly the roms they can load.However, unlike other emulators, No$gba requires some specific instructions to run, so this guide is here to address these issues.1. How to Use No$gba?STEP 1: Download the emulatorThe latest version of No$gba can be found here. Create a new folder and extract the emulator therein.STEP 2: Download the BIOSNo$gba requires BIOS files to run. These files are highly illegal so use them at your own risk. The BIOS files (BIOSNDS7.ROM and BIOSNDS9.ROM) can be found here. Download, extract and place them in the SAME folder as your emulator.STEP 3 (optional): Download the firmwareSome roms (mainly starting from #500) requires an additional file to work called firmware.bin. Currently I don't have a link to download it. If you find one, put it in the SAME folder as the emulator. Withtout this firmware, some roms don't load at all.Anyone who has a link to download it is welcome to PM me. Thanks.STEP 4: Download the romsAll NDS roms can be found on DGEmu.STEP 5: re-encrypt the romsDownload the re-encryption tool (eNDryptS Advanced) here and extract it in any folder you want (no need to put it in the same folder as the emulator).Extract the roms and put them in the SAME folder as . Otherwise, it won't find the roms.Open the eNDryptS Advanced.exe and type '1'. The program aotomatically detect all roms in the same folder and re-encrypts them.Once it is done, press any key and close eNDryptS Advanced. You can place your roms in any location you want.STEP 6: running the romsJust open No$gba emulator. A window will pop up asking you which file to load. Chose one of the roms you encrypted and click on 'Ok'. Depending on the compatibility of the rom, it can run or not. Just pray for it to work.2. Preliminary Compatibility ListI have made some tests with a few roms. Since I decided to go in the details, it can take some time before the list is complete. Some games that don't load may be due to the fact that I don't have the firmware.bin file. However Pokémon Diamond and Pearl DON'T WORK.If you your game is not in the list, don't make another thread to ask whether it works, instead PM me directly, I'l test it for you.
