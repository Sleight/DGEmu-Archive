With my recent acquisition of Installshield Admin Studio 9, I am now able to undertake repackaging projects of classic games. So with this, I've decided to redo a classic game I loved back when I was young. The installer from the original disc does not work on 64-bit systems, and workarounds proposed on the Internet were a burden to follow.
Instead, I have decided to created this new installer that will install Star Wars Rogue Squadron 3D v1.3 without any hassle on computers running Windows XP. Vista, 7, or 8, 32-bit and 64-bit editions.

This release contains the scans of the original jewel case covers and disc so that you can print them.

Hope you enjoy this latest release!
