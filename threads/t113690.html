If problems persist, try these steps:1. Restart your PC with your HDD still plugged in2. Check if Windows has found it as new hardware3. If it did, ignore these steps, if not, follow on4. Try your HDD in another computer and if it's recognised, you probably have an error with your USB/Firewire/1394 connection5. If that did not happen, your HDD is faulty or broken, take it to a computer shop to have it checked over professionallyQ: I inserted my HDD, it got a blue screen, I had to restart my PC, the error still happened when i restarted itA: You have an error on your computer hardware most likely, check for driver updates for your: motherboard, memory, computer HDDIf problems persist, your computer has another error, try repairing your windows setup or take your PC to a computer shopQ: My HDD is working, but it won't let me access my filesA: Try unplugging, then re-plugging in the USB, if that doesn't work, restart your computer and try againModem, TV ect... side cardsQ: I inserted my card, it was recognised but it cannot identify what type it isA: You will probably need a setup CD if Windows doesn't recognise it, if you don't have one, try to download the setupCamerasQ: Yay i have a new cam! :D , but it won't workA: 1. The more RAM a PC has the more of a program or multiple programs can be loaded into it at once without having to use the paging file, which is located on the (Relatively) much slower hard drive. This means the CPU can access the data much faster and also means that more programs can be run at once with less performance loss.If you have very little RAM, or are running too many programs at once your computer may suffer from any of the following: 1. Very slow performance (Most likely, assuming the PC is built from reasonable quality hardware) 2. Crashing 3. Spontaneous restarts (This is more commonly caused by using an inadequate power supply)To see available Physical Memory (RAM), go to Ctrl+Alt+Del -> Performance -> Physical Memory (K). This gives you your RAM usage statistics in Kilobytes.To cut down on RAM usage, multitask as little as possible by running as few programs at once as you can manage. This also frees up many other resources for the programs that are still running.Average specifications for basic PC usage are to have 256 or 512 MB of RAM and at least a 1.6Ghz processor. A gaming PC will be much more powerful, using 1 or 2 GB of RAM coupled with a processor operating at around 2.8 Ghz (Effective numbers, this corresponds to an AMD64 2800+, or a 2.8Ghz Pentium 4.)To see avalible Physical Memory (RAM) vacant or not currently being used, go to Ctrl+Alt+Del -> Performance -> Physical Memory (K)Approximate RAM usage for programs (some inaccurate):Adobe Photoshop: 3 - 9 MBInternet Explorer: 9 - 36 MBMSN Messenger: 14 MBWindows Media Player: 8 MBAIM: 1 MBReal Player: 2 MBWindows Explorer (My Computer ect.): 8 MBModems:Dial-Up only, DSL belowMost external dial-up modems are normally connected via the external port method (the extra port for Interactive boards ect...).
