TheFlameAlchemist' post='4287978 wrote on Aug 3 2008, 07:21 PM:
Ok well I have the disc2 eboot but how do I change that stuff?
If you downloaded it already in eboot style, it should be fine. You change the Game ID and Save ID when you are converting them yourself.
someone wrote:
The save files are embedded into the eboot?
So, it is a save file just like for PSP games, and is in the saves folder. Which is why you need to change the Save ID and Game ID when coverting, so that the save file on your memory stick from the earlier disc, with match up.
someone wrote:
And if it says runs of 3.02 popsloader for example, will it work for all after 3.02?
Not necessarily. Sony keeps updating their firmwares, but each POPs is different. They're coding it for the games they release at the PSN. So we have to make do. For example, Chrono Cross runs perfectly on 3.03, but not on 3.71.
someone wrote:
Also what is the document.dat that comes when you convert PSX iso's?
The document.dat is the manual. When you press home, you can access the manual for the game. You put it in the folder where you put the PSX eboot.*note: One thing about PSX saves, is once you use 3.10+, they cannot be loaded on anything lower. If you saved a game on 3.03, for example, then want to load the save with 3.30, it will ask you if you want to convert the save, and that it won't be able to load on 3.03 anymore. Just back up your saves before doing anything like that.
