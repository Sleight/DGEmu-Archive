KKirie MotobaMay 03 2014, 06:43 PM

Very far.

 

The Java thing is simple:

Since Java 7 Update 25, for security precaution, we need to sign the full Applet to not get a security warning.

 

To sign an applet for the Internet, you need to pay someone like Verisign to create a Root CA for you that is valid for a few years, and pay again to renew. Not cheap.

 

You can also sign your own applet, but then that's wonderful and dandy within an Enterprise, but online, since the Root CA is not recognized by computer, you'll still get a warning.

That and when you manage your own certificate, you need a server to host the Root CA, and if that gets hacked, people can go ahead and generate tons of fake certificates under your name.
