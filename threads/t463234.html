NirvanaFanx2' timestamp='1308973589' post='4960995 wrote:
Thanks for the advice.One last thing though. Does the Acekard 2i have any advantages over the DSTWO other than the price? I am thinking all the extra stuff the DSTWO can do would be worth the extra cost, unless it has some drawbacks besides its price.
Besides the price, there is one thing that the DSTWO has as a drawback: it drains the battery faster. The DSTWO has a CPU built into the cartridge, thus it can run much heavier homebrew, but it does drain the battery quicker. Luckily, you can change the cpu speeds (I think there were 4 settings or so) to increase your battery life. However, if you decrease the cpu speed it will impact the performance of course.Do note that the cpu is mainly used with specialized homebrew, like the gba emulator. I have seen a test run by somebody in which a ds running a rom on the DSTWO got the same battery life out of a dslite with a retail cartridge.
