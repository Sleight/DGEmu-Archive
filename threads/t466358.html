22bigpigsFeb 02 2011, 08:51 AM
There should be a 6.30 HEN but I haven't heard much about it. I've heard more about 6.31 HEN.So I'd rather go with things I know.First step: Upgrade to 6.31. Since you're using a GO, This should be it: http://www.mediafire.com/?6w43lxp2k6o5gj6 That's a pspslimhacks.com file.Step 2:Put 6.31 HEN on your PSP: http://www.megaupload.com/?d=B9GQ8BKLThat's from a site I don't use much but its the only one I found. It says its signed. There should be an EBOOT.PBP in a folder. Copy the whole folder into your X:\PSP\GAME folder. (X:\ Is the drive letter of your PSP. Mine is H:\ )Then exit USB mode, Go to game>memory stick. The HEN should be there. Just press X to run it and hope it works.Pressing select should get you a VSH menu (I'm not too sure 6.31 has one though.)Once you're there, You can decide whether you want to downgrade or not.Remember, there are always risks when you're installing new firmware. Though, I'm pretty sure this should be safe since it's using the normal method of updating to downgrade. ( :laugh: )Here is a link to a guide. Link: http://pspslimhacks.com/downgrader-for-fw-...-6-20-released/Feel free to ask if you have any doubts. This can be very confusing if you've never done it before.
