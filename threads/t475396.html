A reference guide on how to link to Meru's radio application.Use the following code as an example. Make sure the width and size stay the number designated.<center> <iframe src="http://mhhq.x10.mx/radio/?album=TalesBattArr2&type=gst&noclose=true" height="400px" width="600px"></iframe>

<a href="" target="_blank">Click here to download the soundtrack</center>Options to change in the iframe:album: The short name of the album.type: The type of album. Current available choices are: ast (Anime Soundtrack), dge (DGEmu Collections), gst (Game Soundtracks), gmr (Game Music Rips), jap (Music of Japan), thp (Touhou Project Music)noclose: Always set to true on DGEmu for forums. If the player was to be loaded in a separate window, then this entry should be set to false or removed from the URL.Options to change in the anchor:href: The link to the download in the Download Center.When posting, make sure to have the "HTML On - Auto Linebreak Mode" set.
