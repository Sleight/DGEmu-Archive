No, this is no April Fools Joke, this is the real thing. You can play Wii Games with no modchip! A very simple process will allow you to play Wii ISOs from a USB drive on your Wii.

On the Wii:
Step 1: Install Homebrew Channel (see the pinned topics for this).
Step 2: Install cIOS rev10
cIOS36_rev10-Installer.zip :: http://www.crocko.com/4A00B01ABDB44C19AD352060CDC33761/cIOS36_rev10-Installer.zip
cIOS36_rev10-Installer.zip :: http://www.filefactory.com/file/1r4c114ldcfp/n/cIOS36_rev10-Installer.zip
IOS36-64-v1042.wad :: http://www.crocko.com/FF2429DCC1314868B8F77375EF52B800/IOS36-64-v1042.wad
IOS36-64-v1042.wad :: http://freakshare.com/files/vip3ifrm/IOS36-64-v1042.wad.html
IOS36-64-v1042.wad :: http://www.filefactory.com/file/1pv7f4knvk13/n/IOS36-64-v1042.wad
Step 3: Install Ultimate USB Loader to your SD card:
http://gbatemp.net/index.php?showtopic=147085
Step 4 (optional): Install the USB Forwarder Channel to the Wii via WAD Manager. Download:
http://sharebee.com/9ce107ee
Step 5: In the root of your SD card, create a folder called Images
Step 6: Put the background PNG in the Images folder. Name the file bg.png
Background PNG: http://i44.tinypic.com/6hnknk.png
Step 7 (Optional): Download titles.txt, and put it in /apps/usbloader/ on the SD card.
http://www.mediafire.com/?5zlm2z3tyt2

How to copy games onto a USB drive using Windows.
Step 1: Download WBFS File Manager.
(Step 1.5: Install .NET 3.5 SP1 if you haven't already installed it. Download Link)
Step 2: Run WBFS Manager 3.0.
You'll need a dedicated USB drive to this, since Windows can't read WBFS format and will always show it as Local Disk. Note the drive letter.

In WBFS Manager, select the drive letter up top, then click Format to format the drive in WBFS format, to be read on the Wii. Or if you have a drive that already has games on it, press Load to bring up the listing of games.
