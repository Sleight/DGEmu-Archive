DDragons MasterJun 04 2012, 05:32 PM
This has nothing to do with caching - we're just using nginx instead of apache - u see apache opened a new process for each visitor - having many concurrent users pretty much raped the server - this doesn't happen in nginx - there are just a few threads handling all requests using select ("select" is a function name) - this is gazillion times more efficient if u have many users - and we do.

The exec time is even slower as this server does things (php, mysql) slower (it's way weaker) but the exec time is just how much time took to generate the page - sending it over and handling the requests (each image is a different request! it's crazy) is what hopefully became faster.

Oh man just *hopefully* fixed the staff utils - was a small problem using $_SERVER['PHP_SELF'] which goes crazy - should always use $_SERVER['DOCUMENT_URI'] instead - it works great now.
