The fonts you've downloaded need to be copied in the "Fonts" folder (if you're using Windows XP, the fonts folder should be on your main local disk, where you've got installed your OS in the WINDOWS directory - in most cases that would be "C:\WINDOWS\Fonts"). After you've copied the font files there, you'll be able to use them in any program that uses text tools - and. of course, in the GIMP too.
