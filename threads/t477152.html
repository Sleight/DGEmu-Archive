Anti-Piracy Patch only applies to NDS games really ....

For GBA there are some games that require a standard patch though, from looking I see that Mario vs DK (E) requires a patch:
1777 - Mario vs. Donkey Kong (E) - A4DAF243 to CA030D61.zip
I can't see anything about the (U) edition that you have though ..... if you want to download the Europe version and see if it works (if not apply the patch and it should then work).

For details on how to patch and the program/s to use see these:
http://www.dgemu.com/forums/index.php/topic/186228-gba-emulation-faq/ (just do a search for 'patch')
http://www.dgemu.com/forums/index.php/topic/130120-gba-emulation-guide-updated-november-24-2009/#ipsp

The only other possibly if you REALLY wanted the US version is to try VBA-M instead:
http://vba-m.ngemu.com/

That is the DGEmu ROM number, official ROM ID or just another website is VERY likely to have a different number than ours, so instead look for 'Mario vs'.
