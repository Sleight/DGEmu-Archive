What is the difference between the desmume and the desmume_sse2?
SSE2 just has a more advanced CPU instruction than the regular desmune. In plain English, it should give a performance boost (assuming your CPU supports it). However, if your computer is already running desmune at full-speed, you probably won't notice any difference between the two. Anyways, if your CPU don't support SSE2, it will probably give some kind of error message when you try to run the SSE2 version.
