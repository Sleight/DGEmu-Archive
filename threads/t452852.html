Another problem might be the region of your rom. Some games you can only play multi-player with games from the same region (bleach for example), while other games that are somewhat different per region can play multi-player with different regions (like advance wars days of ruin/dark conflict). The best thing is to sort this out first before jumping to the conclusion that it is your flashcart, because this is the easiest thing to sort out.In most cases you can swap the saves from the same game from different regions (do note that it WON'T work with different games, for example you can't use a pokémon diamond save with pokémon pearl). To do so, simply replace your rom with the same game from a different region and rename the save file exactly the same as the rom.
