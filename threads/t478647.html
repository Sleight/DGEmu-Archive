Hmm, I think I might start a new blog about computer support, seeing how many issues I've encountered, I should start documenting it properly.

 

Just today, an issue I wanted to resolve since a month now was fixed up.

Basically, my McAfee firewall refused to turn on no matter what. My homegroup was screwed also.

 

Did a clean reinstall of McAfee (removal tool used, reinstalled from source from my company), and it seemed to work. It updated, restarted computer, then went back to screwy mode.

Homegroup still refused to work, so I started looking into that: Homegroup services were down. Trying to start them, dependency service is corrupted. Look at dependencies: Windows Firewall was one of them, correlating with McAfee firewall issue.

 

Looked into it, behold: Windows Firewall was missing from system, probably due to corruption (I had a virus attack about 2 months ago, and my system suffered a power loss also during the course).

Restored registry keys, restored permissions, restarted computer, double check services, check McAfee, everything is back in working order. YEAH!!
