NightWinggl' post='2280416 wrote on Mar 19 2007, 10:37 AM:

DLDI cannot be used to patch real games, but it is far from what dbgtdob says it is.DLDI is used with homebrew that use libfat, ie. homebrew that need to access your SD or CF card. Because the internal workings of each flash cart is different, several versions will have to be released for each flash cart, or one large file will need to be released to support all versions. But what if a new flash cart came out? The homebrew would need to be recompiled again. This becomes a very large bother, so Chishm released the DLDI patches.What happens is that a homebrew using libfat sets aside 32kB (bytes) of space in the homebrew. Then, the user patches the homebrew according to their flash cart. Thus, newer flash carts that are released can still be supported, as long as the patch is available.And homebrew are not programs "hacked" by "normal people"... the term 'homebrew' is most commonly used to describe "home-developed programs written for systems that are not typically user-programmable".
