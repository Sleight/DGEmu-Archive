Start by choosing your CPU. I recommend the AMD Phenom series, AMD products run cooler than Intel and use less power, both musts in the PC world. Once you choose your CPU, find a matching mother board with an adequate number of RAM slots/media ports/etc. I would recommend a 500GB hard drive at minimum, and 6GB of RAM if you plan on using this computer for as long as possible, although you can do fine on 4GB. Choose an ATI graphics card, 5000 or 6000 series should be just fine. I run on 4570 I believe, and comfortably run Borderlands, Portal, Magicka, UT, Age of Empires, Google Earth(newest version), Google Sketchup and can reasonably run BFBC2. Choose your case to fit the motherboard. Oh and make sure you install good fans and keep track of your cpu and gpu temperatures. My system(laptop) runs 6GB RAM, AMD II N930 Quad Core 2.0Ghz processor, 500GB 5000rpm HD, ATI 512mB model 4570 graphics card. Cost was about $950. Desktop components are usually cheaper.

this is pretty old but if you're still looking to buy a new pc, i'd wait until intel releases the fixed motherboards for their sandy bridge processors in spring. then i'd go for a sand bridge proc (dual or quad-core 2.8ghz+), a compatible motherboard, at least 4gb of ram (it is dirt cheap right now), a 7.2k rpm hard drive (also very cheap), a msi 560gtx ti (very excellent graphics card card for the money. approx $250), a 600 watt or more modular power supply (it doesn't have to be modular but it makes cleaning up cables so much easier), any dvd burner (cheap), the coolermaster hyper 212 cooler (if you want to run the cpu cooler than stock or overclock), any case you want, and a copy of windows 7 if you don't already have one. i'm not 100% sure but i think you can get all of that for around $1000
