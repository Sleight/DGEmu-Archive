This is the official slot-1 flashcarts comparison topic. All discussions and questions about the best slot-1 flashcarts or the ones you have go there. Don't open other threads about X vs Y flashcarts.This is a brief overview of slot 1 storage devices currently available. I have only included devices with reasonably good NDS rom compatability but feel free to PM me if I have missed your favourite, if there are any mistakes, or if any new carts come out.Slot 1 storage devices generally have the following characteristics: Uses MicroSD card. They can be picky about which brands of MicroSD cards are used. The MicroSD card is inserted from the top. You don't need to patch your roms; just copy them to your card. Some also supports optionally patching roms. This can be used to add features like soft reset and cheats. No booting devices needed. You don't need NoPass, FlashMe or the like. You need to manually select the save type for every rom. You also need to select the speed to read the MicroSD cards. For these two settings, you may need to try a few times before you get it right.Homebrew support is not as good as slot 2 storage devices. Manufacturers that release a libFAT for a device will increase the number of working homebrew on that device. None of these can run GBA programs. Get a slot 2 storage device instead if you wish to play GBA games or run GBA homebrew.Special characteristics of each card:M3 DS (aka R4)No need to set save type or card speed. Has libFAT. Supercard DS(ONE) Optional patching. Has libFAT. Can use Supercard rumble series as a rumble pak DSLink Requires booting tool. Only works with FlashMe or a MK4-Mini brand NoPass. Requires patching. No need to set save type or card speed. Has libFAT. EZFlash V Optional patching. MicroSD card inserted from the side instead from the top. Acekard Uses a special AKFS filesystem on the MicroSD card. You need to use a special software to copy your roms. MicroNinja No need to set save type or card speed. Has libFAT. DS-XtremeInternal 512MB storage. No need to set save type. Intergrated USB port. Very expensive. Around the price of a new DS lite. No libFAT but some homebrew still work. Ninjapass X9 Typical slot 1 storage device. N-CARD aka DSLinker Internal storage: 128MB, 512MB or 1GB Uses a special USB to slot-2 cable to write to slot-1 card.No need to set save type.Full details are in the following post by dbgtdob: http://www.dgemu.com/forums/index.php?s=&a...t&p=2024849

The nice thing about the DS-Xtreme is it is an all in one solution. It comes with a USB cable which you use to hook it up to your computer. You drag and drop your files onto it, and your good to go. The downside is that it is pricey at $125 and has a relatively small capacity at 512MB.The R4 uses MicroSD cards, so the memory is expandable. It is also much cheaper at $45. But you have to get a MicroSD card and probably a reader too since the one that comes with it seems to break after awhile. Updating is a little more complicated since you have to add files to the MicroSD card then run the updater on the DS, but nothing that difficult.Hope that helps.
