..luchaduceOct 19 2004, 10:25 PM
scan lines are simple#1 - open a picture you want to apply various scanlines to. i chose ak1200, one of the best drum n bass dj's out there. hit image - image size and note the image's size. this one is 200x251 pixels. #2 - now create a new transparent psd file that is the same width as the original pic (200 in this case), but only 2 pixels in height. once created, use the zoom tool to zoom in so yous can see it betta. then use the line tool to draw a straight black 1-pixel-thick line (on the upper pixel) all the way across the canvas to the other end. before using it, make sure anti-aliased (on line options tab) is deselected. then do select - all (or ctrl-a) and edit - define pattern. #3 - now go to the original picture, and create a new layer, name it scanlines if you want. choose the paint bucket and go to the paint bucket options tab on the navigator window. change the contents from foreground to pattern. now use the paint bucket anywhere on the picture, and voila, scanlines. there ya go thats the method i usedthanks to http://www.somethingleet.com/forum/article...rticle&artid=56 for this
