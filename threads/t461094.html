[center][font=Arial Narrow]DGEmu RPG[/font][/center]
[center]This is just a preview of the RPG Maker VX based DGEmu RPG I started working on a month or two ago. Shows from start to the first 2 boss battles. I know,it's very primitive and needs a lot more work, but in time it'll be very official.I never really finished the story, but the gist of it is that BR has grown tired of deleting the Spam Center over and over again, so now he's found a new, much bigger target, the site itself!Join the main character (in this case, KHRS, but when the project is finished, you'll be able to change the main character to whomever you want using RPG Maker VX) as he forms a ragtag group to stop BR's evil plans!However, BR isn't alone in this, he too has a group of flunkies that will try to stop the protagonists.[/center]
[center]Updates:[/center]
[center]Playable Demo: http://www.mediafire.com/?0j14cw7eczmp119[/center]
[center]My Assistant Preview[/center]
[center]So yeah, this is just what I managed to create in the short time I worked on it. Basically:- The Spam Center is the main area, a sort of pub/social area where the "regulars" relax and do what they do best.- I tried to make a lot of things like the actual site itself, for example: Level = Posting Rank, Gold = GPs, etc.- The first "level" was based on the general discussion forum.- The main draw of the game is the in-game characters who's personalities I tried my best to mimic based on their DG personalities.- For the sake of showing things off, I made both characters lvl 99. The actual game is a lot more challenging and some parts will require some leveling up.- As shown in the video, there are a lot of incomplete things, item shop having no items, unfinished piano room area, etc.- It seems laggy, but that was just due to the recording software, the game itself is very fluid.I don't want to go into too great detail, so I'll leave it at that. Like I said, I like the way it's coming a long, so I WILL finish it at some point. But yeah, this was just to show how the game is. I have a lot more unused characters, so don't get your panties in a bunch if you weren't in the video, there's a lot more game to be made.[/center]
