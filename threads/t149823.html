OOpulent MaelstromAug 07 2006, 03:07 PM
So far I noted that the pages load faster and the loading feels "cleaner" (you never see any "broken image" icons and other crap). Everything else is faster, like when you middle-click a link to open a new tab (it opens instantly) and when you launch the browser. I compared the mousewheel scrolling in both browsers and Opera's feels nicer (autoscroll redirects the cursor to the middle though, which bothers me). Better password management, better security (according th the Secunia site) and better website compatibility.Other than that, it's more light-weight than Firefox when it already includes features (mouse gestures, anti-phishing, BT support, session saver, etc.) that you would need to install specific extensions in order for FF to include, and which would render it even heavier to use. It's also got an awesome sidebar that appears only if you click the left edge drawer and thus doesn't bother you if you don't use it (unlike the different FF sidebars I used).I still miss extensions like Adblock and StumbleUpon though. No "I'm feeling lucky" address bar search. And Firefox remains a tad more intuitive.

Opera does not work very well with Gmail (G-Chat is not avaiable).Opera's javascript behaviour is a little strange as well (if you hit enter in one of those "check box"es, it will "enable"/"disable" it - in IE & ffx, hitting SpaceBar will "enable"/"disable", while hitting Enter will "submit"; in Opera, both Enter & SpaceBar will act the same way - so, if you want to submit a JS form, you'll have to go to the bottom of the page and hit the "Submit" buttom). Also, once you hit that bottom one time, it will be disabled (so, if you're for example using "Fast Reply", it will not enable you to "double-post"); this can be considered a "good feature" by some people, but if you really want to submit the same form two or more times, you'll need to reload the whole page.Opera is highly customisable; but there are no "extensions" like firefox (so, if you want to tweak your browser, you'll need to manually edit the .ini files).Opera 9beta & Opera 9 have a built-in "image blocker" (similar to Firefox's "AdBlock" extension). You can easily block any unwanted image (like Ads & Signatures) by shift + right-clicking and choosing Block Content or using the ShortCut Ctrl+K. But it does not lists Iframes, like AdBlock does (though, you can manually enter the URL of the Iframe and you'll be able to block it).Opera's HotKeys seems to not be "universal":I can't remember exactly which version I was using last (I've installed both Opera 8.x -later upgraded to 9- and Opera 9 beta) and while one of them will recognize a Ctrl + click as "Open in new 'tab'", the other will reconize that as "Save Link"; Opera 9's Open new 'tab' hotkey is Ctrl+T, while Opera 9 Beta's is Ctrl+N (by the way, they're not 'tab's; they're 'window's, which means Opera does not work well in Multiple windows sessions).The above are the reasons why I prefer Firefox over Opera.But I have to admit Opera has its good points.Opera is portable to almost any machine (I've heard there will be an Opera avaiable to nintendo WiiBoth Opera 9 beta & Opera 9 have "Widgets", which allows you to install some nice (yet useless) add-ons, like Calculator, Games, text editors, etc.(again, most of them are pretty useless, but that's not my point)Opera has built-in Mouse Gesture support (Righ-Click + MouseWhell = change 'tab's; Right-Click + Left-Click = 'back one page'; and so on).Like Teck said, everything you try to do on Opera requires less click.But it's a little annoying when you try to do things that only requires one or two Click, since you'll have to "undo" some of the "extra tihngs" Opera will do "for you": for example, if, for any reason, you want to just "select a word/phrase", if you Double-Click it, a context menu will pop-up automatically.Opera enables users to completely remove page's "skin"s (err.. CSS).So you can overwrite any site's defaul theme to something that fits your taste.Opera has built-in save session facilities, so, whenever your browser crashes (or you just close it while there are several 'tab's open, you can resume you navigation from the point you were).Well, there are many other features on Opera (some good, some bad).You have to use it to know it better.(BTW, Opera's Status bar is disabled by default, so you might want to enable it to be able to see where "links" are pointing to).On a side note, Sir VG once suggested me a browser called MaxThon.Basically it's an enhanced Internet Explorer.
