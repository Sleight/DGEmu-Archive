A PS3 or a 360.

 

PS3 firmware hack = play tons of games, need to download humongus games.

 

360, either a jtag, dvd-drive hard mod, or xk3y does the job, depending on what you want to do:

- jtag for homebrew, basically emus and such (requires soldering skills depending on systems. Some exploits can be used if you run the correct system version)

- dvd mod: running games off DVD+R DL discs (cheaper solution, uses discs)

- xk3y: running your games off external hard disk (most expensive solution, but easiest by far to setup)
