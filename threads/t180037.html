I talk about this suggestion before leaving the staff with DJ but since I am back, I guess I can carry it myself now. After receiving a PM from a member named Natzor proposing a game recommendation feature on DGEmu, I suddenly remembered an excellent model that AnimeDB (the largest anime database site) for recommending. Ok, that was for the introduction, now the discussion: there are 4 points that seem important to me.1. Do we need a game recommendation feature?2. Which model to implement?3. Under which form?4. Possible limitations and issues.My opinion to these three points are:1. Yes we need. True, there are in each forum a topic named “favourite game on X console” or “Recommended X console games”. However, for all people who looked at them, it’s more a collection of different sort of opinions that vary much with the personality and preferences of each of us. In short these threads are useless for recommending personalized good games. The rating method put on the main site has the same sort of shortcoming: many people may like a game and give it a good rating but if one specific member has a different taste than the majority, then this feature is useless for him.2. To this question, as I said in the introduction, the method proposed by AnimeDB seems really revolutionary. Instead of analyzing the determinants and common factors of games to provide a recommendation (aka microstructure), this method rather adopts a macro view on this issue.Let me illustrate with a very simplistic example (the real model is much more complex):Suppose we can only vote for either Yes (I like) or No (I don’t like) to a game. Suppose that a member A voted yes to Pokemon, yes to Golden Sun and No to Boktai. The model try to find other members that voted the same as him. For example there is a member B who voted the same for these 3 games and voted also for a 4th game, say Yes for Harvest Moon. Then the recommendation feature display Harvest Moon to member A for him to play next.In short, this model just skips complicated analysis based on genre and subgenre and just finds people with the same taste as yours, which overcome the problem mentioned in the first question. Of course the real model is based on gradual rating given instead of a binary answer. Of course, we can modify the model so as to adapt it to specific issues we encounter.All the details are provided on the Wiki of AnimeDB:http://wiki.anidb.info/w/How_does_Anime_Hint_work3. The form I would see for this is a recommendation for each category of ROM we have: GBA, NDS, GBC/GB… and a button besides the Help/Search… buttons on the top of the forum.4. There are mainly three limitations I can think of:- Will this impose much strain on the server?- Since it is based on the rating each member gave to games he already played, are the rating recorded for the existing votes?- Will this be difficult to implement?So what do you guys think?
