Let's think about this for a moment. A GameCube ISO is easily over a gigabyte in size, meaning that anyone daring enough to host them on a web server will burn his or her bandwidth in a matter of hours.Therefore, there are no GameCube ISO websites. If you want to download GameCube ISOs, search on some of the bigger torrent sites. You'll find them there.Anyone who makes a topic asking for GameCube ISOs or where to get them will receive a warning.---On the topic of emulators, there do exist a number of them. You can download them here: http://www.ngemu.com/gcNote that none of these emulators can fully emulate all games! The GameCube is simply much too powerful for a typical consumer computer to emulate successfully. The latest Dolphin beta is able to run a few games at full speed (no sound implementation though) given a sufficiently powerful computer (with a multi-core processor and running an x64 OS), but even so, emulation on the whole is primitive at best.
