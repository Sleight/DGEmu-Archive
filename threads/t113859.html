Earlier Sir VG expressed some disappointment in FCEU's screenshot naming system, as it names the screens "1.png, 2.png...". I found a simple way to have it instead name the screenshots to match the roms they came from. Assuming you are using Bisqwit's rerecording version (Available here) follow these steps.1. Once FCEU has loaded click on "Config" in the menu.2. In the drop-down menu click on "Directories".3. Down at the bottom of the window there is a lone checkbox marked "Save screenshots as '<filebase>-.png'".4. Once you click on the checkbox any screenshots you take with FCEU's internal screenshot function (F12 by default) will go to the appropriate folder as "gamename-#.png" with gamename being whatever the ROM file is titled and # being the number snapshot of the game it is.Easy, eh?
