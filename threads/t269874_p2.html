FDS ROMs procedure:Step 1) Download the bios file <a href="http://rapidshare.com/files/40005815/bios.zip.html" target="_blank">hereStep 2) Ok, once you download the bios, you extract it all into the same folder you keep the emulator.Step 3) The bios itself contains some other zipped files. For the FDS, extract the stuff out of the Famicom Disk System BIOS folder.Step 4) You should now have the Famicom Disk System BIOS.pas file out. Rename it into disksys.rom and place it in the same folder your emulator is in.Step 5) Restart FCEUltra and load the FDS game. It should work now.Also: Some FDS games require you to load "Side B" of the game when you play it.In order to fix this, press Ctrl+F8, then Ctrl+F6, and Ctrl+F8 again.
