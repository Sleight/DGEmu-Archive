"Download Problem" MessageType: /dl]
someone wrote:
Read this segment of the Support & Suggestions FAQ: QUOTE(Support & Suggestions FAQ @ Nov. 15, 2007) style_images/1/post_snapback.gifQ: I clicked the download button but I didn't get my Rom. What happened? A: 1. If you have a pop-up blocker/ anti script/firewall/proxy that doesn't have DGEmu allowed then add DGEmu to it. 2. If you are using a download manager or internet accelerator then disable or uninstall it. 3. If you are using Internet Explorer, a yellow bar or message may appear. Just click the link to start your download. 4. If you are using Firefox, make sure you are not using extensions like Downthemall, Flash Got, and Fasterfox. 5. Make sure that you have admin rights on your computer. 6. Try right clicking the download button and select "Save Target As" ("Save Link As" for Firefox) 7. Make sure that you have at least twice as much free space as the ROM that you are downloading. You need more than that if you are browsing or downloading other things.
