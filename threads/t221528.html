Anyone creating a thread asking for Pokemon Diamond and Pearl compatibility on emulators will be warned.*NEWS*11/26/2007: Complete overhaul of the topic. Since No$gba v2.5c, there isn't much to expect in the future except wifi implementation so that the guide below will stick for a while.11/18/2007: No$gba 2.5c is released and emulates almost perfectly these games.[center]_____________________________________________________[/center]FOLLOW EXACTLY THE INSTRUCTIONS BELOW TO MAKE THE ROMS WORK.STEP 1: Download the emulatorThe latest version of No$gba can be found here. Create a new folder and extract the emulator therein.STEP 2: Download the additional filesDownload the BIOS and the firmware and extract the contents in the same folder as the emulator. They are optional but better have them than not.STEP 3: Download the romsDiamond (U), Pearl (U) or here (external link).Extract the roms after you download them!STEP 4: Run the emulatorOpen the emulator and choose your rom. Then press F11 and make sure you have the following settings:- Emulation Speed: "Unlimited MHz Disaster, 10%" (fast) or "Realtime, Auto" (normal)- NDS Backup Media: Flash 512 KB- Sound Output Mode: "Digital Mono" or "Digital Stereo"- Sound Desired Sample Rate: Low (10kHz)Click on "OK" and then go to File->Reset.Note: you can go to Options->Save options so that you won't have to do this step the next time.You can now play the game. Read the FAQ below for any questions you may have.[center]_____________________________________________________[/center]Frequently Asked QuestionsFrom now on, anyone asking the same questions listed below will have points deducted.Q: Do Pokémon Diamond and Pearl work on emulator?A: Yes, on No$gba.Q: Can you post step by step instructions to make the games run?A: Read the instructions above.Q: Where to download the roms?A: Diamond (U), Pearl (U) or here (external link).Q: When I try to load the game, I get a black screen, can it be fixed?A: You are probably using an old version of No$gba. Download the latest version and follow the instructions above.Q: When I try to load the game, I get a "Communication error..." message, what should I do?A: This is only a v2.4a problem. Download the latest version and follow the instructions above.Q: I have "The data could not be read. Please turn off the power, then remove and reinsert the DS Game Card" error message, huh?A: Press F11 and in NDS Cartridge Backup Media, choose Flash 512KB. Then RESET (go to File->Reset).Q: The game freezes at the end of a battle, what can I do?A: Turn on the sound (F11 and in sound output, choose either "Mono" or "Stereo").Q: Okay, I'm on Route 210 and passed the Psyducks then I got a little ahead and the screen turns white? Why is that?A: Use the HM DeFog to clear away the fog. Then, change the screen, such as go into your bag, then come back out again. The screen needs to be "updated" after you use DeFog.Q: I have a microwave failure error message, what can I do?A: Turn off the sound most of the time and turn it on only to pass battles (since the game freezes at the end of battles if the sound is off).Q: The speed is very low, how can I increase it?A: With the latest release of No$gba, speed should be absolutely correct. If your computer has less than 1.5GHz/512MB RAM, upgrade it. Otherwise, close all unnecessary programs and use the settings indicated in the guide.Q: I can't open the menu! / Pressing 'Start' doesn't open the menu! / I've registered an item in my key items slot but nothing happens when I press Select!A: To open the menu, press the button mapped to 'X'. To use the registered item, press the button mapped to 'Y'. In older versions of Pokemon, it was 'Start' and 'Select', but it's changed now.Q: How do I save?A: In the game, press the button mapped to 'X' to make the start menu appear and then choose save.Q: Can I use save state (save/load snapshot)?A: No, it doesn't work for NDS roms.Q: When I save (press F8 or File->Save snapshot) and then load the save (Load snapshot), I get "The rom-image has crashed...A: Read the two questions above.Q: When I try to deposit, the game freezes.A: You are probably using an old version of No$gba. Download the latest version and follow the instructions above.Q: Can I trade?A: No. The Wi-Fi feature is not emulated.Q: Can I use cheats?A: Yes.Q: Are there other emulators that run these roms?A: iDeaS can run the game but not as well as No$gba. DeSmuME cannot run the game.[center]_____________________________________________________[/center]- Post here only if you have followed EXACTLY the instructions but still have problems not covered by the FAQ above.- When answering other's questions, make sure you know the answer and quote the question as well.- Don't post comments not related to emulation.- Any useless posts (complaints, etc.) will cause the poster to be fined GPs.Failure to any of the three conditions above WILL lead to warn.
