[center]FAQ: What is inside our zip files?[/center]Several members have been asking about What is inside our zip files? This faq has been made to explain the other files besides the rom file, which can be any type from NDS ROMs, GBA ROMs, N64 ROMs, SNES, NES, GameGear, Atari and more...A group dumps a rom and includes some of these files with the zip file. The files are a way for the group to claim credit that it is one of their roms that people are using. These files are there for collectors and anyone else that is interested in them.Before you ask, NO these files will not be deleted. These files are smaller than the rom and do not cost a lot of DPs. Plus we do not want to take away credit from the group that dumped the rom.Some of these files might be in the zip file, depending what group dumps the rom: A file with extension .nfo = (also written .NFO or NFO, a contraction of "info", or "information")The file is a plain text file that contains information. The type of information it can contain is all the ROM dump details, CRC number, language, size, etc.If you open this file with the default program, which is System Information on a PC, you will get an error. This is not the program to open this file since this is not a System Information file. The file can be open with NotePad or Wordpad, but there are some limitation with this. There are special characters in the text file, which every OS interprets them differently. The special characters are carriage returns, which are "characters" created by pressing the "Return" (Enter) key, and newlines, which are characters delimiting the start of a new line. The best way to open this file is with dedicated NFO viewer. This is a link for a dedicated NFO viewer:http://www.softpedia.com/get/Office-tools/...FO-Viewer.shtmlfile_id.diz = (FILE_ID stands for "file identification". DIZ stands for Description In Zipfile.)The file is similar to a .nfo file. It is a plain text file containing a brief content description of the archive in which it is included. The best way to open this file is as nfo files.eAt.RiZe = The file is similar to a .nfo file. It is a plain text file containing a description of the archive in which it is included. The best way to open this file is as nfo files.A link to the website = This is a link to the website of the group that dump the rom or the site that has the rom, which in our case will be DGEmu. Click on it to open the website.jpg or similar files = These are just images of the game in action, the Box Art, the In-Game screenshot, etc.[center]For additional information on Wiki:NFO filesFILE_ID.DIZ[/center]If any mods have any suggestions, please let me know.CREDIT:Channel28 (original idea for the FAQ), Sir VG, phoenix121, atomicknight, DJ Night Force 9, and GBATEST(putting the faq together)
