[OFFICIAL] GUIDE: How to recover bad Pokemon saves

Saves made using the wrong settings may be fix-able

AatomicknightORIGINAL POSTAug 21 2006, 07:07 PM
This is a guide on how to recover Pokemon saves made using the wrong save settings (i.e. Flash 64K instead of Flash 128K). At this moment, I cannot fully guarantee that it will work under all circumstances, but chances are that the following procedure will produce viable results.

Required files
A save state that was made using the Flash 64K save type
An unpatched version of the rom of the game used to create the save state above (note that you may need to re-download a version from DGEmu if you patched your existing rom)
A copy of VisualBoyAdvance


Instructions
1) Create a new folder somewhere on your hard drive
2) Copy the save state, the rom, and the emulator into the new folder you created in step 1. NO OTHER FILES SHOULD BE IN THAT FOLDER
3) Open the emulator, but do not load the rom. DO NOT CHANGE ANY SAVE SETTINGS
3a) If you are playing Ruby, Sapphire, or Emerald, you should turn on the Real Time Clock by going to Options -> Emulator -> Real Time Clock
4) Load the rom. You may get a white screen - that is normal behavior, so proceed to the next step
5) Load the save state by going to File -> Load... and selecting the save state (it should show up on the screen without requiring you to change directories)
6) Your saved game should be loaded. Then change the save type by going to Options -> Emulator -> Save Type -> Flash 128K
7) Use the in-game save (i.e. press Enter to open the in-game menu and choose Save)
8) After going through the entire saving process, close the emulator. If you look in the new folder you created in step 1, you should see a 128KB save file corresponding to your rom.
9) Create another new folder within the folder you made in step 1
10) Copy the emulator and the rom into the folder you created in step 9. DO NOT COPY ANY OF THE OTHER FILES
11) Open the copy of the emulator you copied in the last step (i.e. in the newest folder). Do not load the rom
12) Change the save type to Flash 128K by going to Options -> Emulator -> Save Type -> Flash 128K
12a) If you are playing Ruby, Sapphire, or Emerald, you should turn on the Real Time Clock by going to Options -> Emulator -> Real Time Clock
13) Load the copy of the rom found in the newest folder you made - it should be the one that shows up automatically on the screen
14) There should be NO white screen. Now go to File -> Import -> Battery File... Click on the icon with the folder and an upward-pointing arrow (i.e. go to the folder you created in step 1). Load the 128KB save that was created in step 8. At the confirmation screen, click "Yes"
15) After the initial intro screen, you should get an error message like "The save file is corrupted. The previous save file will be load." That is correct behavior, so proceed to the next step
16) Choose to continue with the existing save file
17) Now use the in-game save again (i.e. press Enter to open the in-game menu and choose Save)
18) Reset the emulator (File -> Reset)
19) When the rom loads again, there should be no error message pertaining to the save. If you close the emulator, you will find a 128KB save file corresponding to the rom in the newest folder you made (in step 9). Delete all the files in the folder you made in step 1 so that you don't confuse them with the good saves (don't delete the folder you made in step 9 of course).
20) Continue playing using the in-game save that was generated in steps 17-19. You may want to make a save state immediately just in case.

So there you go. Hopefully this will work for everyone, but I cannot be sure due to lack of sufficient test cases. Just as background, I used VisualBoyAdvance version 1.7.2, a Pokemon Emerald rom (unpatched of course), and a save state provided by Keiz (original topic is deleted). After running this procedure, I beat the Elite 4 and was able to continue playing without any problems.

If you are in such a situation, please try this procedure out and let me know if it works by posting or by PM. If you cannot get it to work, please upload your save state to a site such as SendSpace and deliver the link to me by posting or by PM. I will personally run through the procedure myself to see if I can get it to work.
