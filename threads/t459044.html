DG Announcements' post='4329825 wrote on Sep 3 2008, 02:58 AM:
Q: I clicked the download button but I didn’t get my Rom/got a corrupt file. What happened? A: 1. If you have a pop-up blocker/anti script/firewall/proxy that doesn’t have DGEmu allowed then add DGEmu to it. 2. If you are using a download manager or internet accelerator then disable or uninstall it. 3. If you are using Internet Explorer, a yellow bar or message may appear. Just click the link to start your download. 4. If you are using Firefox, make sure you are not using extensions like Downthemall, Flash Got, and Fasterfox. 5. Make sure that you have admin rights on your computer. 6. Try right clicking the download button and select "Save Target As" ("Save Link As" for Firefox) 7. Make sure that you have at least twice as much free space as the ROM that you are downloading. You need more than that if you are browsing or downloading other things. 8. If you get an HTML file (if you click your file and it takes you to an internet page) simply change the .html to .zip.
If the above does not work, than it might be the random connections problem that some people have reported that we are looking into.The search has been offline for sometime now to minimize IPS Driver errors.
