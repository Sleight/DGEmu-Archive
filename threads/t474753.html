To set this straight: we host some 3ds roms, but it isn't known whether or not the roms in this state will work with future emulators or flashcarts, or are even proper roms at all. We have some bad roms on the site (mostly nes roms) these were some of the first roms that were for the system. The roms were used for some emulators and flashcarts, but only after more roms came out, it was revealed that the first roms were bad roms. These bad roms had to be either patched, or converted in order to make them work properly without major problems. The same might happen for 3ds games, so that's why it is going to take a while before DG is going to catch up. If you add up the facts that a lot of unverified 3ds roms on the net are infested with virusses, which add up to a false total. Most of them are too large to download in a feasible time with the current DP system. And that not a single 3ds rom or flashcart can play the games, you can count on it that we won't be uploading 3ds roms for a while.
