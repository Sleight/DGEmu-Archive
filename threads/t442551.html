Basically, what I'm trying to do is copy my Pokémon Platinum save file (from no$gba) and transfer it to the AceKard 2.1 to continue where I left off.

I did this:
1) Save the game via the emulator and close it. It updates the SAV file.
2) Play a different game with the AceKard; Platinum's SAV is in SRAM. Once the other game is loaded, it's dumped.
3) Copy the SAV to the Rom's folder in the SD card (for AceKard).
4) Rename the file's extension to .nds.sav.
5) Reload the AceKard and ROM.

The save file is corrupt? It prompts me to start a new game.
