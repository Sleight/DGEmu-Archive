How to use the forums' search functions

Finding topics in the forums
1 posts · page 1 of 1 · 5157 views
HHadelORIGINAL POSTApr 16 2007, 05:50 AM
The search function is an essential tool for the DGEmu forums that almost all members will probably need to use at some time or another. It is not only important for new members to know how to make proper use of this function, but even DGEmu veterans should effectively use it for finding duplicate or starting new topics. Most importantly, members should know how to find and use the search function before attempting to create new threads.How to find the search functionAs you can see, it's pretty easy to find. On the top right corner of every forum page, you can see the "search button" and the "quick search". Another option is to click the "My Assistant" link on the page and then go to the "Search" tab, but that is the same as using the quick search and leaving the "Search this forum only?" box unchecked. Using the "Search Forum" box at the bottom left hand side of every topic list in a forum is the same as using the quick search with the "Search this forum only?" box checked. The search button goes to the main search page, which is identical to clicking on "More Search Options" in the quick search box. From the main search page, you can click the "More Options" button to go to the Advanced Search page, which allows you to conduct searches in much greater detail, if necessary. Here is the link to the search page, in case you wish to save them or bookmark them for reference:DGEmu Forum Search: http://www.dgemu.com/forums/index.php?act=SearchHow to use the search functionSo now that you know where it is, you should learn how to use it! First of all, always remember to do a search in the appropriate forum before creating a thread so that you can check to see if it has been done already. Even if you think no one else on Earth besides you could possibly think about the thing you want to make a topic for, you should check just in case so that you can avoid making moderators close your topic. The other obvious reason to use the search function is if you are looking for specific information that you know exists somewhere on the forum already, or you are trying to find the original version of a duplicate topic.Searching before creating a threadSuppose you are thinking of making a topic about Pokemon Ruby. Of course, you are not going to immediately go to the GBA forum and create a topic called "Pokemon Ruby, do you like it?" because you know that you should make use of the wonderful search function first! While you could use the quick search for GBA forum and look for anything with Pokemon Ruby in it, it is recommended in cases like this to make use of the Advanced Search function.When thinking of a topic, searching topic titles is usually the best option, because otherwise there will probably be too many results to sort through. Also keep in mind that all of your search terms must have 4 or more characters in them or else the search cannot be completed. So, back to the Pokemon Ruby example. Here's some things to keep in mind:1. Search topic titles first: As stated above, there are less results to go through when you do this, and otherwise you would be looking for the use of the search terms in all the posts in a given forum.2. Use as few terms as necessary or use quotes: When you ask the search function to find multiple search terms, and you don't use quotes, then it will look for all instances of every single term in the search. Therefore, in the search of Pokemon Ruby, it would be advisable to not include "Pokemon" in the search because there are going to be a lot of other various Pokemon topics that are thrown into the search along with the ones you might be looking for. Therefore, you should either only search for the term Ruby or use quotes and search for "Pokemon Ruby", because this will turn that title into one search term. Here is an example of doing that:As you can see, "pokemon ruby" needs the quotes around it in order to be searched as one term. Here are some results of the various ways to search for Pokemon Ruby as a topic title to show that quotes and small terms, as well as title searches, are the most effective:pokemon ruby [GBA forum, entire post search]: 457 resultspokemon ruby [GBA forum, topic title search]: 378 resultsruby [GBA forum, topic title search]: 12 results"pokemon ruby" [GBA forum, topic title search]: 7 results(Note that the results shown here were the number taken at the time the guide was written)As you can see, ruby and "pokemon ruby" give the least results to sort through, which is usually better. Of course, when you are just trying to see if a topic has been done before, it might be better to go with using ruby as the search term. It's helpful to know that the quote marks are always a viable option though.3. Use some common sense: There are some topics that you shouldn't even consider making a topic for, but should go straight to the search function for instead if you can't find them on the first page of a topic list already. The DG boards have been around for quite a while; there are some things that would obviously have topics at this point. Examples of such topics include:Favorite GameFavorite ConsoleBest RPG [for any console forum]Best Shooter [for any console forum]Favorite MovieFavorite BandTopics about famous games that have been out for a whileThere are plenty of other examples, but those ones are some of the most common. Usually these threads are on the first page of a given forum anyway, but if not, then don't even consider making one until you do a very THOROUGH search.4. Always check pinned topics: Even if you can't find any topics in the search related to what you want to make one for, you should consider the possibility that the type of topic you want to make is against the rules of a certain forum. You should ALWAYS make sure to check the pinned topics of a given forum or subforum before posting in it. Such topics as "Pokemon Emerald cheats please?" are not allowed to be made in the GBA forum, for instance, and there is a pinned thread that tells you this. There is no asking for in-game help or cheats in the GBA forum, and that is why you can't make that topic without a point deduction. So that is yet another thing to consider before searching.Searching for duplicate threadsMany of the same ideas described in the previous section apply here as well, although there are some things that are slightly different. So make sure you know everything said before, but also consider this when you are searching for a duplicate thread:1. Using the quick search is better sometimes: If the thread that has a dupe is an extremely common one that winds up on the first page a lot, it might be easiest to either use the quick search and plug in the appropriate term(s) or just scan the first page of the topic list in the right forum. Using the advanced search options is not necessary when the topic at hand is usually very active. Examples of such a topic is the "Favorite GBA game" thread (in the GBA forum) or the "Favorite Band" thread (in the Music section of the Multimedia forum).2. Use everything you remember about the original topic in the search: The advanced search options have a lot of tools you can use if you find that the quick search is not sufficient. If you happen to know who started the original thread, make use of the "Filter by Member Name" feature. For example, it is well known that Bish started both the "Favorite NDS Game" thread (in NDS forum) and the "Naruto Discussion" thread (Anime and Manga section of Multimedia forum). If you happen to remember a certain range of dates that the original topic may have been created in, then make use of the advanced function that lets you search for topics made only during a certain time period. The advanced search options have all those features for a reason. Use them!3. If you can't search for it, have a staff member do so: There are a handful of threads that have terms which are nearly impossible for a regular member to find without having to sort through a ton of results. Some examples are topics like "DS vs. PSP", "Wii vs. PS3", and a few others that simply lack any 4+ character terms that can be used effectively in a search. Keep in mind that all staff members are capable of searching for terms that are less than 4 characters, and only regular members have this restriction. Therefore, if there are any threads that fit this scenario that you know for certain you have seen before, feel free to let a staff member know and they will probably be able to find it for you and have a moderator close it themselves.Final Words:That essentially wraps up how to effectively use the search function. Remember that even if you use the search function correctly and you still accidentally make a dupe topic, then the only points you will lose at most are the 10 points you would have earned from creating the topic. Basically, you have no net loss in points from this. Using the search function to its full capacity before creating topics will mostly allow you to avoid situations like that, though, so make sure you take the advice in this guide seriously. There are a couple of other, less commonly used methods for search terms that are used around the forums, and those can be viewed by clicking the link for "Advanced Usage Help" on the Advanced Search page.
