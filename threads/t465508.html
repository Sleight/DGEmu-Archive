Pandora is essentially an underpowered Linux netbook with a gamepad grafted on. The specs and price were pretty good for when it was announced but then it got delayed for years. Not a year, but something more like 3+ years.The link you listed even mentions that that software is SDL based. SDL was developed with portability in mind, hence the version of EasyRPG for Pandora.Grab the right compiler and library files and you can essentially make a copy for any platform you want. They have instructions for building it for Windows and Linux, and they mention builds for OSX. I don't know if anybody has tried it but there are SDL libraries available for the Wii and PSP so you should even be able to make versions for those.http://easy-rpg.org/blog/http://easy-rpg.org/wiki/My point being this, you could probablly get a decent gamepad and a netbook and run the exact same stuff as a pandora for the same money but with better specs and a bigger screen.
