p2p Kaillera playThis guide will teach you how to utilize kaillera's latest online feature, person2person online play.The advantages of p2p play are obvious, no longer will the set up be:Player => Server <= PlayerBut instead:Player <=> PlayerMaking the delay issues a second thought.1: First, you need an emulator. You can find one from this list of MAME emulators: http://www.dgemu.com/forums/index.php?showtopic=2266492: Next, you need to download the p2p kaillera.dll, you can get that here: http://www.mediafire.com/?3tg32ynijxoPlace it in the same folder as the emulator executable file, replace the existing one if it applies.3: Next, you will need to configure your connection to forward port 27886. Make sure that your modem/router and whatever you might have forwards all UDP packets of port 27886 to your pc. Its the same as if you were configuring your bittorrent client or other any other p2p systems for usage behind your router. If you've never forwarded a port before, go to http://portforward.com and look up your router's brand and model. Read the default guide for the router and forward that port as it entails.4: Now that your emulator and connection are both prepared for p2p play, lets enter File > Network Play. When you enter, you'll notice that the interface is slightly different, you'll see something like this:Select the P2P mode from the Change mode Drop down list as shown. Select the "host" tab if not already selected and you should see the P2P mode screen5: To host a game, activate the host tab, select a game and press host, you should see this: If you want your game to show up in the Public Waiting Games list then click the S: Public box.Also note the "whatismyip" button. Use it to determine your external IP as well as to see if the waiting games list server is up.6: If you are the one connecting then on the p2p mode screen, switch to the "connect" tab and click on the "waiting games" button. It should open up the waiting games window and automatically download and ping waiting games. You can just double click to connect if you find the game you are after. If you want to connect directly with IP, all you need to do is put his ip in the PeerIP box and click connect.The game will start when both players are marked as ready. Enjoy!October 26th: The DLL was updated so the interface may have changed a bitSIDE NOTE: This P2P kaillera client will work with any emulator that supports kaillera play. Just replace the kailleraclient.dll with the one in this topic and you're good to go!!!
