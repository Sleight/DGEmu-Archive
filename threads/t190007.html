Last updated: 29 March 2007
Current emulators:
Easiest NES emulator: NesterDS - A DS port of Nester (NES) [Link]

Instructions:
Follow the link, scroll down to NesterDS, click the title and choose the first mirror to download.
Unzip the zip file.
Run rom_inserter.exe
Click the first 'Browse' button and select the nesterds.nds or nesterds.nds.gba (patched for GBA flash carts). If you don't know which one to use, try both of them.
Click the second 'Browse' button and select your NES rom.
Click 'Insert' and name the new file. Remember to add a '.nds' extension to the end.
Copy the newly created file to your flash cart and play.

NesDS - A NES emulator for the DS. [Link]
NesDS WIP1 - Work in progress, but supports saves. [Link]
PocketNES - NES Emulator for GBA.

[hr]
Recommended SNES emulator: Snezzi DS - SNES for DS [Link (v0.25a) / Pocketheaven (latest - v0.28(a))]

Instructions:
Just drag and drop onto snezzi.exe within the 'sound' or 'no sound' directory (self-explanatory) and copy the created file to your flash cart. There is no need to patch it. (PM me if I'm wrong)

SnezziDS Compatibility List
SnesDS - A SNES emulator for the DS. [Link]
SNEmulDS - SNES for DS [Link]

[hr]
Tested GB emulator: Goomba - Game Boy emulator - runs in GBA mode. [Link]

Instructions:
Click here for instructions to insert games into goomba.
If you're using SuperCard, you have to patch it. This does not work with SC-Rumble (no support for GBA). [can someone please confirm if this works for other flash carts]

Goomba Color - GBC emulator - runs in GBA mode. [Link]
Lameboy - GB/C emulator which runs in DS mode, so it is compatible with all flashcarts. [Link]
DSBoy - Game Boy & Gameboy Colour emulator for the DS.

[hr]
TI-8X Emu - An emulator to run TI-85.
ScummVM DS - ScummVM interpreter/emulator for the DS.
Stella DS - Atari 2600 Emulator.
PicoDrive DS - Sega Mega Drive / Sega Genesis Emulator [Link]

Instructions:
Click the link and download picodrive.ds.gba if you're using a slot-2 flash cart, otherwise get picodrive.nds
If you're using a slot-2 flash cart, rename picodrive.ds.gba to picodrive.nds
Patch it with DLDI
Put picodrive.nds and your Sega Mega Drive games onto your flashcart, start up picodrive, browse to your game and play!

For information on emulating different systems on the DS, please go to the following sites:
Download links and information for the M3
Wikipedia article with lots more emulators
General (and brief) information on some emulators
If the system you want to emulate isn't on one of those lists, then chances are, there is no emulator on the DS for the system. If I have missed any, please PM me about it with a link to it.

If you use this, put all the files in the root directory of your MMD or memory card (ie. straight onto it, not within a folder), making sure all the games have .gbc extensions. You may have to rename the .ds.gba file into .nds and run that instead.

As of now, it is impossible to play GBA games from a slot-1 flashcart.If you want to play GB/GBC/GBA games on your DS, you'll need to use a slot-2 flashcart (and the appropritate emulator for GB/GBC), eg. using your son's Supercard. Goomba was originally made as just a hobby for the developer, but since the DS can't play GB games (but can play GBA), suddenly it's found a reason to exist.You can also play DS games from a slot-2 flashcart, but you'll either need a nopass (eg. Passcard) or you need to flash your DS. I suggest you play your DS games from your R4 and play your GBA/GB games using your Supercard (in GBA mode - just turn on your DS and choose 'Start GBA game').Also, note that having two accounts from the same IP address may result in a ban, so maybe you should just stick to one account for both you and your son.
