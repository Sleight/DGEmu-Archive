Using the R4.This is only for the original R4. Stuff from here onwards might or might not be outdated. Follow at your own risk:

GAME:
The first icon is the game icon, this icon takes you to a directory/file listing of the contents on your micro SD card. You can go back to the main menu from here by pressing 'Start'. On the top screen is a list of the folders on your card, and below them, a list of all the .NDS files and their sizes.
When you launch a ROM file for the first time, the R4 will tell you that it can't find a .SAV file (save game data, and this is, assuming you haven't already copied across a .SAV file with the same filename as the .NDS) for the game and asks you if you would like it to auto-create the file for you before launching. You are given three options - 'OK, Cancel and Ignore'.

MULTIMEDIA:
The second icon is multimedia.
This starts moonshell a multimedia player.
Moonshell supports a wide variety of media files such as OGG, XMA, MP3, WAV and DGP.
To play Music files simply click on them, Moonshell can also play video files, but you will need to convert your existing videos files such as avi into DGP which the moonshell media player supports.
here is a guide on how to convert avi and other media files into dgp to play on your R4.

Press the 'Up/Down' key can process the Row Up/ Row Down; Press the 'Left/Right' key can process the Page Up/Page Down.

Press 'B' key to change the font (large, Medium, Small in rotation).
Press 'X' key to change the font color (27 color in rotation).
Press 'Y' key to change the row spacing (From 1-8 point space in rotation).
