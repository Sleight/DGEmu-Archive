KKirie MotobaFeb 24 2012, 04:09 PM
Considering it's an external hard disk, you got the following scenarios to consider:- File system corruption.- Hard disk failure.- Bad sectors on drive.- Bad USB cable or loose connector on either the end to the computer or the end to the hard disk- Bad hard disk controller board inside the case.Things you can try:- Try with another USB cable (I doubt it will help much)- Try another USB port- Try another plugging it to another computerIf none of the above helps and gives you the same result (A generic drive), then I remember some dood in the SC posting about something similar before regarding his USB stick. Just run Active@ Partition Recovery in the hopes that it can restore your partition. If that doesn't work, then move on to Active@ File Recovery and backup your stuff from there.Also, when you plug your drive, listen if it does some weird clicking noise. That's always a bad sign if it does.Last resort would be to "carefully" destroy your hard drive casing and put it into a new case. I've seen instances of perfectly healthy hard disks having issues due to a faulty controller board, and just swapping it out with another hard drive case fixes the issue.
