When it comes down to IT, most generic things people think of are:
- Computer technician at a store
- Programmer (for games or applications)
- Database administrator
- Web developper
- Network administrator

But in reality, IT branches off in so many directions it's nearly infinite.
- Security analyst (firewall, anti-virus)
- Server administrator (delivery of Windows or Linux server machines, active directory management)
- System analyst (proposal of IT projects to client, analyze all costs, resources, materials needed, etc)
- Project manager (coordinates all communications and resources involved in a project that the system analyst provides)
- Project coordinator (coordinates how resources are assigned to each project depending on priority and provides delays, pre-requirements, etc)
- Virtualization specialist (VMware, ESX server, vSphere, Terminal Server administrator)
- Software packager (Windows Installer, software installation automation) (Also my main role where I work)
- Microsoft System Center administrator (Administer SCCM, SCOM, OSD, etc) (My secondary role where I work, soon to become my primary hopefully)
- Backup administrator (schedules, monitors backups of servers, etc)
- Oracle analyst (Specializes in many Oracle products)
- etc.

Job level positions that I know here:
- Tier 1 IT support (call center bs): ranges between $15 to $20 per hour.
- Tier 2 IT support: ranges between $18 to $22 per hour.
- Tier 3 IT analyst (many of the jobs listed above): junior positions ranging between $22 to $26, senior positions ranging between $25 and $40 per hour. It also depends on how rare the specialties you have.
