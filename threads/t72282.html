All the separate pinned topics containing rules, were merged into a single one to make life easier. All new rules for this section will be added here.CD KEYStopics like: "Any1 has a good cd key for HL2 please reply".This topics never get a decent answer and only lead to spam. So please stop posting about them in here. If you really HAVE to post about it, do it in the spam section. Posting other topics about CD keys for any game might lead you to a warning. Support questionsEach time you make a new topic to ask support/help for a problem, make sure to give enough information for other people to be able to help you. This is: give a detailed explanation of the problem, tell any posible changes you made for it to occur etc. topics like "my computer is crashing, plz help" are unacceptable and the user will be warned".Building PCs topicsIf you want to make a topic to get recommendations on hardware you should use to build a pc, make it in the hardware and software section. Specify how much you are capable of spending, and what is the use you want to give to the pc (gaming, school, graphics etc). Prices postingif you want to post the prize of anything, please state the country that it refers. $20 is not the same in the US that in Canada.Asking for cheatsDont start topics asking for cheats, use a search engine to find them, or go to a cheat site. Members giving you cheats will do that, so there is no need to have topics for this in here.Asking for game recommendations do not make posts to ask recommendations on a certain type of game. ex: "can you guys recommend me a good shooting game?"all this topics lead to spam because everyone has a different opinion. So you can just look at topics concerning the type of game you want, and read what people think.Posting LinksSometimes it may be necessary to link to software for other members to download if they request it (especially in the "Hardware/Software" subforum). However, please note that the rule in the Warez Links thread about "Posting Direct Clickable Links" applies to the entire PC section so please be sure read and follow it. All violating links will be removed.Pinned and closed
