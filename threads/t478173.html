KKirie MotobaNov 01 2012, 10:10 PM
I just got back home and saw all of this...
Hmm, it gets into safe mode, but in normal mode, it just hangs? As in, you don't even see the animation of the windows appear?

Once you get into safe mode, try one of the following:
command prompt "sfc /scannow" just to try to see if there's any Windows file corruption (you need a Win7 disc on hand)
schedule a "chkdsk /r C:" at next boot up, and then restart your computer. If your system hangs before it even gets to the check disk... go next paragraph.

If you got access to a Windows 7 DVD, boot on it. This should bring you to the welcome screen, choose your language, and then instead of an installation, start the utilities for troubleshooting.

The classic window scanning for hard disks and attempting repair should come up (and probably fail at what it's doing). Your choice of:
- System restore to an earlier point (that won't delete personal files, but applications and updates installed between will be lost)
- Launch the command prompt and for the "chkdsk /r C:" from there, it should work.

- Launch the command prompt and go for "diskpart"
The prompt will change to DISKPART> instead of the directory you're in.
Type "list disk", look at your available hds, and then type "select disk 0" where 0 is the disk number of your primary hard drive that has Windows.
Type in "detail disk" and it should now show you all the info about your hard disks, and the volumes on your drive and their drive assignments.
2 things you want to make sure:
1. Your drive letters aren't messed up (As in your Windows partition is suddenly assigned D and your system restore partition is C
2. Your partition for Windows is set to active (a little * in front of your drive tells you it's active)

If #1:
Select the volume that currently got wrongly assigned C by typing "select volume 1" where 1 is the volume number of wtf messed up.
type in "remove letter C", that will reassign it. If you want to be sure, you can type "list volume" and you should see it has no more drives.
Now repeat "select volume" to your windows partition that has the wrong drive. type "assign letter c"
"list volume" again, everything should be good.

If #2:
while you have your windows volume selected, type "active". Then do "list volume" and you should see a *.

When you're all done, type "exit", close your command prompt, restart, and cross your fingers for it to boot.

Also, another thing that might help under safe mode to help investigate:

Windows key + R
type eventvwr

In the Windows Logs section, try to look up if there's any critical errors in certain sections pointing to the times where you booted your system until the hang.
That might give you a little clue.


You can also open up msconfig, choose "Diagnostic startup" in general.
If that doesn't help, go into "Boot" tab and checkmark "Safe boot" in boot options and choose minimal or alternate shell.
