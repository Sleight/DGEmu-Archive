[center]Screenshotting Guide - Guide Chapter 1: Downloading[/center]
Alright, it’s the beginning of a new screenshotting phase, and you’ve been assigned a list of games. The first thing to do is to go over to the assignments thread in the screenshotting sub-forums.

(Click to Enlarge)

Here is the standard look of the assignments thread. The system being worked on in this image is the NES. Note that the suggested screenshot resolution is beside the system’s name, along with our recommended choice of emulator. In the first column are the URL links to the various assignment pages; in the second column is the number of ROMs in your set, and the third column is the display name and ID# of the DGEmu member. The reason the number is given as well as the screen name is because display names can be changed, whereas one’s ID number cannot be.Once you find the URL link to your assigned games in the list, click on it, and you'll be sent to a long list of games.

(Click to Enlarge)

Here is the standard look of an assignment. The first column has the region the game came from – in this case, the first 3 are Japanese, and the rest have an unidentified region (in this case, because they're regionless ROM multipacks). The second column is the name of the game, the following 5 columns (the columns with black dots/checkmarks) sign various flags used by the Good Tools naming system (The number of columns this take up varies from system to system); The next column is the number of times the ROM has been downloaded. The next column after that is the game's price in DPs.

(Click to Enlarge)

In the picture above, you can see the name “10-Yard Fight” has been highlighted. The full filename of the game, “10-Yard Fight (J).zip” has been shown in a small tooltip, and the game’s containing its ID number, is shown in the lower left of your browser (assuming the status bar is turned on). In this case, the ID number is 4.

(Click to Enlarge)

Upon clicking on the game, you'll enter the game's details screen, like the one pictured above. The details screen lists all sorts of information that you really don't need to know about the game in order to screenshot it. All you need to be concerned with is hitting the Download link at the top to download the file. When downloading, consider naming the ZIP file the ID number, instead of the standard name. This will make screenshotting and keeping track of how much you’ve done infinitely easier. So, if you had this game, you would rename the file from “10-Yard Fight (J).zip” to “4.zip”. Repeat this process until you out of download points, in which case you can return tomorrow at reset time.Please note that assignments are generally random and we have not much control over what games you get. If you end up with an undesirable lot, ex: a lot of weird Japanese gambling games, we’re sorry, but you’re still expected to do them.

[center]Screenshotting Guide - Guide Chapter 2: Emulators[/center]
You've finished downloading your assigned games. Now it's time to pick an emulator to run them with. Hopefully you, being at an emulation site, already know the basic workings of an emulator.

The most important thing is to use an emulator you're comfortable with. While we might recommend various emulators at the beginning of each phase, if you wish to choose an emulator for yourself, you're welcome to do so.

Emulators can be found by doing a Google search or by heading over to Zophar's Domain, as they have a large selection of emulators and other game tools. Typically, we will provide links to the emulators on the assignment page, however if an external link to the emulator is down, please let us know so we can provide an alternate link.Something you should look for in an emulator is a one-key screenshot function. Examples of emulators that have this are Dega (SEGA Master System/GameGear) and FCE Ultra (NES). Please use our recommended choice in emulators, as we've check to see if it can do the task at hand. We look over the emulators to see if it supports opening ROMs in ZIPs, as well as the ability to screenshot (the easier to do such, the better), as well as if it has a good compatibility with the system's ROMs.

[center]Screenshooting with Project64[/center]
This section is for Nintendo 64.

First, Download and setup the emulator.Take some time to configure it to work the way you want it to.If you have graphics glitches when emulating certain games or have really slow emulation, Try using a different graphics plugin. (recommended: mudlord's rice video plugin)

Note:
As PJ64 outputs screenshots with dimensions equal to the window's resolution AND Jabo's Direct 3D automatically outputs the files in the JPG format, You may be able to skip the converting provided the filesize is less than 30 KB.

32X 68000 Bios: 32X_G_BIOS.BIN
32X Master SH2 Bios: 32X_M_BIOS.BIN
32X Slave SH2 Bios: 32X_S_BIOS.BIN

If you don't have all 3 loaded in Gens, it will return an error whenever you try to play a 32X game (such as Knuckles Chaotix).

[center]Screenshooting with NeoPop[/center]
This section is for NeoGeo Pocket Color.

NeoPop is the best emulator out there for this system, but unfortunately does NOT have screenshotting capabilities in the program (it's on their to-do list, but the emulator hasn't been updated in about 6 years). So working with this system will be a bit complicated.

First, let's cover configuring the emulator for our usage...just for playing.A ROMs folder is already created via the ZIP, so just dump all of your ROMs in there. They do not need to be unzipped, as NeoPop supports ZIP format.Controls can be configured via Options -> Controls.

If you get a message on any game that says "This software cartridge is available only for NeoGeo Pocket Color" it's simple to fix. Options -> System Type. Set it to Auto Detect or NeoGeo Pocket Color. This is on Auto Detect by default.Under Window Size, Zoom x# will set how big the screen is for you. But know that you WILL have to resize the ROMs based upon the resolution you choose. Don't use 3x Zoom, 2x or 4x makes it easier for you to convert later.Frameskip (Options -> Frameskip) should be set to FS0: Show All Frames.

Now that the emulator is configured, we need an external screenshotting program. For this, a good choice is Gadwin PrintScreen. Just get the Freeware Version, you don't need the pro version for this. Install it. Now we need to configure it.

Right click on the tray icon and choose properties.Under Preferences, make sure EVERYTHING is unchecked. Mostly it's to get rid of annoy factor. Set the Hot Key to whatever you want that's comfortable for you.

Under Source, set it to "Client Window". Uncheck "Capture Mouse Cursor" - we don't want your mouse to accidentally be in the screenshot. One thing to note about this, is that your mouse cursor HAS to be over the NeoPop window in order for the correct item to be screenshotted. Using "Current Window" would always get the NeoPop window, but unfortunately it does capture the title and menu bars as well. Sucks, yes...I know.

Under Destination, make sure copy to Clipboard, Printer, and E-Mail are UNCHECKED. Check "Copy captured area to file".In the file section, check "Automatic Naming" and uncheck "Ask for Filename". Everything else doesn't matter here, but note the destination location - by default it'll be in My Documents\PrintScreen FilesUnder Image, choose BMP and uncheck everything else. While this program can do JPG and resizing, leave that for IfranView - you'll get slightly better quality (and smaller file size!).

Screenshot and fulfil the requirement.

After all the games are done, you can do a batch conversion in IfranView.
File -> Batch Conversion/RenameWork as Batch Conversion.

Output Format:
JPG (Options: 100%, or as high as possible. You'll have to play with this to get as good of quality shots as you can without going over 30KB).

Check "Use Advanced Options" if you need to resize (you used 2x or 4x Zoom)Advanced: Check "Resize". Set to new size as a percentage of original - x%/x% (If 2x Zoom, 50% /50%- 4x Zoom, 25%/25%)

Check "Use Resample Function"Add All images from the PrintScreen Files folder, and convert. Redo anything over 30KB. Rename everything else to the proper naming format:
If ID number was 39, then...
Title: 39.jpg
In-Game: 39_1.jpg


[center]Once the images are properly renamed, and are converted to JPG, move on to Step 4 - Making your report[/center]

In-Game Screenshot: This is the ROM's non-title (in-game) screenshot image. If the ROM ID # is 119, then this image should be named 119_1.jpg

Emulator Used: If you use our suggested emulator choice (FCEU, VBA, Dega), then you probably won't have to do anything with this. GBC, Master System, and GameGear people, you don't have a choice, so you really don't have to worry about it (as there's nothing to change it to anyways).

After you're done, click Upload Files. After you're done, the boxes will clear and you'll get a message near the top whether it was successful or not. If it's not, please consult with us in the discussion thread and we will help you. Likely there may already be an image for the ROM you're uploading. Just give us a text copy of the message and we will investigate and assist in any way necessary.

Repeat process until you're done! (This can be tiring and confusing. Please take your time and take occasional breaks.)

[center]Screenshotting Guide - FAQ Chapter 2: Emulators[/center]

Q: The emulator needs a BIOS file! **or** (NES ONLY) The emulator can't find disksys.rom!
A: This is a common problem. Often emulators aren't preprogrammed with BIOSes for legal reasons. There is a link in the Guide Table of Contents to a BIOS package. This will contain all the BIOSes deemed necessary right now (more may be added at a later date). Place the requested BIOS dump in the same folder as the main executable in the emulator. This should allow you to run the BIOS-needed rom.

Q: The emulator doesn't open ZIP files!
A: You'll need to decompress the ZIP files with an external ZIP decompressor, such as WinZIP. Once you're done decompressing, delete the junk files (files ending in JPG, PNG, GIF, BMP, NFO, DIZ, and HTM) and you'll be left with the roms, which you should be able to open in the emulator. Typically, this shouldn't happen, unless your download is bad.

Q: The emulator doesn't open a certain rom!
A: First, ensure you're using the right emulator. It is impossible to open NES roms in Dega because Dega is a SEGA Master System/GameGear emulator. Next, make sure you have the appropriate BIOSes and plugins, and have the emulator properly set up. If this fails, try a different emulator. If the rom still doesn't work, you may have a bad rom (which is suppose to not work) or a bad download, which means you might have to redownload it.

Q: The game is definitely ok, but the emulator brings back an error!
A: Look on the screenshotters discussion thread to see if this error is fixable. If not, use the 'Emulator Error' placeholder image, which is found in the screenshot questions area.

Q: (NES ONLY) The emulator told me a certain mapper is unsupported!
A: This is common, but less now than it used to be. Since there are so many Mappers (and some, being only used once or twice) not all of them have been implemented yet. Occasionally there'll be a mapper that isn't done and the NES game cannot run without this mapper implementation. Chances are, there's another emulator that does have this mapper implemented, so if possible, find an alternative emulator (If you're using FCE Ultra, try JNes, and vice versa).

Q: (NES ONLY) The screen says "Loading" or a small bit of Japanese writing, and then hangs for a long time!
A: The disk is loading. While this isn't really necessary now, the original system had a long load time. Just be patient. While you're waiting, take note of the next question.

Q: (NES ONLY) The screen says "Please Set Side B" or "B" and a lot of Japanese writing!
A: On the original FamiCom Disk System, you had disks which you physically had to eject and flip over. To do this in FCE Ultra, hit the following key combination:[CTRL]+[F8], then [CTRL]+[F6], then [CTRL]+[F8] again. This virtually ejects the disk, flips it over, and reinserts it. The emulator should continue loading the disk at this point.

Q: A lot / Most / All of the roms on my list are the same!
A: What's your point? You have to do all of them. You have to check all of them too, not just copy and paste the screenshots from one into all the others, as some may not work, some may be in different languages, etc.
