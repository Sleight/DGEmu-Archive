Unless a new version of Ensata is released, there will be no more games compatible with this emulator than what is already on this list so that no more update will be made. However, DON't ask for Ensata compatibility with X rom since no future rom can be run on the current version of Ensata.Ensata is an emulator made by Nintendo and leaked from them. Ensata used to be a quite advanced emulator last year but its compatibility list remained limited as newer versions are not leaked.1. How to Use Ensata?STEP 1: Download the version 1.4d here. Extract the files.STEP 2: Go to Release>ensata.exe and open the executable file.STEP 3: On the emulator, click on Execute>Open Nitro file. You will normally see no file in your rom folder. To be able to select them, change the Files of type to 'All Files (*.*)'.STEP 4: Select a rom and click on 'Open'.Note: step 3 is set once for all, you don't need to repeat it each time you try to open a rom.2. Key ConfigurationYou can set the key configuration yourself. Just click on Setting>Key Configuration.3. Compatibility ListCurrent version: 1.4dRoms reviewed: ALLFULLY PLAYABLE: The game is playable entirely with no error noticed after a few minutes of playing. To my knowledge, Ensata tends to run a few roms but almost always perfectly.PARTIALLY PLAYABLE: The game can be run but with some issues like considerable slowdown.
