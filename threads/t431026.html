As of some generally recent update, you can format part or all of your flash drive memory unit to allow save files from Xbox 360 games to be stored on it. You can format up to 16GB on a single drive. To do this, go to system settings, memory, and select your un-formatted USB drive (obviously has to be plugged in). You'll be prompted to format it and select how much memory on the drive you want to commit to Xbox files.
