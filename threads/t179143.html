Not sure if this will be especially useful, but hackerx once suggested that some sort of system be put in place to alert of possible dupes upon registration. Now that would have been quite difficult to do, but here's something that more or less does the same thing: http://www.dgemu.com/forums/new_user_check.phpIt basically looks at the latest registered members and checks if their registration IP has been used before. If it has, then it will show up in the list. You can limit the number of results by doing something like this: http://www.dgemu.com/forums/new_user_check.php?max=20So yeah, it's there if you ever find a use for it.
