This thread is a tad old so it's about time it gets answered.Assuming you have a system capable of running it, use this:PCSX2: Use 0.96 and the USA bios (I believe it's scph39001.bin)Graphics: Gsdx 0.15 - DirectX10 mode (if available)Sound: Spu-X 1.2 (or pete's SPU2 if playing RE: Kingdom Hearts: Chain of Memories)Input: Lilypad (works with both directinput and xinput devices)CD-ROM: Use the ISO plugin. Always dump your discs to ISOs before playing. Reading from the disc is slowAll of the plugins can remain as is.
