Now that DGEmu has created the PS2 Emulation/Homebrew forum, I thought I'd start by creating a guide on how to boot homebrew on your PS2. While my PS2 has a modchip installed, I'll include some extra steps to allow those without modchips to use this guide. Note that since I don't have a modchip-free PS2, so I can't fully test it out, but it should work for you.Tools Needed (everybody)CD burner + 1 blank CD1 PS1 game (official, if you're a non-modchip user)1 PS2 memcard with at least 500KB freeBurning program such as Nero, Alcohol 120%, etcTools Needed (for those without modchips)SwapMagic + SlideTool (or some other way to swap discs without using the Eject Button)Software NeededIndependence CompileruLaunchElf (Latest version is 4.12)Most everything we'll do is pretty simple, via use of a tool called the Independence Compiler. This allows us to use the "Independence Exploit" in order to boot homebrew on the PS2.Welcome to the pretty inferface. If you want a more detailed introduction, look there. I'm just keeping it simple.Switch over to the Title.DB tab.Here is your time to dig out your PS1 game. If you do not have a modchip installed, it MUST BE GENUINE! The program needs the serial from the game in order to add it to the database. The list starts out blank because it doesn't know what games you own (it's also to keep the size of the file down). The fastest way to input it is to type it into the box, though the easiest (and most accurate) is to load your PS1 game into your computer, then change the drive in the program to whatever your CD drive is, then click "Get ID from CD". Either way, once you have the title inputted, click "Add to Title.DB". This adds it to the box on the right.Note, you only need one game in order for this to work, though you may feel free to add a few more games to the list. Personally, I recommend 2 or 3, as if you for some reason can't find your game, you can use something else until you do.Switching over to the Loader tab, you see a lot of text and minimal options. Simply put, this is where you will tell it you want to use uLaunchELF. 3.4 is included with the program, but since it's out of date, click other, then find your uLaunchELF 4.12 file you've downloaded from this guide.Nothing else to see here (don't try to make sense of the text It talks about other ways to boot, but we're covering the simplest way only).The next tab is the Files tab. This is created pretty much for people who don't have either a hard drive or a USB loading device (like a USB flash stick or flash card loader) and can only load ELFs from the PS2 Memory Card. Since loading onto the PS2 Memory Card only costs you extra space unnecessarily, (and it's a pain to remove ELFs you don't like this way), you can safely skip this section.Next is the IP options tab. For those of you who don't connect your computer to a network or the internet, you can skip this section...it's totally optional. The biggest reason for this is for people who want to use the FTP ELF to load stuff onto the PS2 Hard Drive (such as games, if you don't have a modchip installed).Next up is the region tab. Simply choose your region - NTSC-U/C or PAL (this is not configured for Japanese PS2s, sorry).Next up is the Extras tab. Pretty much you don't need to touch this. The main reason for this section is to create a dummy file. Since the default setting is fine, you don't need to do anything here.Last up is the most important tab, the Create Exploit tab. Again, the default options are just fine. What the default options do is to create a CD ISO that will install the exploit onto a PS2 memcard.NOTE: Since we didn't include any other ELFs, you'll get a warning saying you didn't include any. Give the program the finger and click YES.Now you've created your CD ISO. Burn it with your favorite program, such as Alcohol 120%.Ok, now we're ready to begin installing our exploit.Have your PS2 memcard plugged in Slot-1 (the left slot). Boot up either your exploit disc (if your PS2 is modded) or your Swap Magic disc and swap discs so you can run the disc.You'll get a screen saying that it was installed (usually this takes like 5 seconds from when it boots). The process is very quick and after that, you can eject the disc...you're done with it.The exploit is installed, so here's how you load up uLaunchELF. Simply have your PS2 memcard plugged in, then load up one of the PS1 games you inserted into the Title.DB page. After that, uLaunchELF will load up!The initial screen is pretty bland and simple. You start with 2 options:O: File BrowserSelect: ConfigureI won't cover everything in the Configure section at this time. I'll mainly focus on loading other ELFs.Press Circle to load up the browser. You'll get a screen with a few options. Here's what they all are:mc0:/ -> Memory Card in Slot-1mc1:/ -> Memory Card in Slot-2hdd0:/ -> PS2 Hard Drivecdfs:/ -> PS2 DVD Drivemass:/ -> USB deviceshost:/ -> (I believe via network not sure offhand)MISC/ -> Other options/programsPress down to select your device, then press circle to select it. If you select the wrong item at any time, go to ../ and press Circle to go back. Find your ELF file and press Circle to activate it.----Common Questions:Q: Can I burn the game to a DVD instead of a CD?A: I haven't tested, but since DVD Decrypter isn't screaming at me, it should work.Q: Can PS2 users with modchips use an unofficial CD?A: Yes. The only reason I state official is for unchipped PS2s.Q: Can I use an Action Replay/Gameshark/etc CD for my Title.DB?A: Anything that can produce a serial ("SLUS code" it's often referred to) will work.Q: At what point does/can the PS1 disc be inserted?A: Any point, including from the PS2 Browser.Q: Does the memcard with the exploit file have to be in Slot-1?A: No. It can be run from Slot-2. The exploit just, to my knowledge, only install on Slot-1.Q: How do I remove the exploit?A: If you don't want to use this anymore, simply delete the "Your PS2 Configuration" file on the PS2 memcard.Q: The program says an update is available...A: Ignore it. The website that this program came from originally no longer exists. Ignore it.Q: What if I want to run the PS1 game?A: Simply remove the PS2 memcard that has the exploit on it. I mean, PS1 games can't use PS2 memcards anyways...Q: What different ELFs are there?A: There are several, including (but not limited to): HD Loader, PS2 Media Player, SMS (another PS2 media player), SNES Station (an SNES emulator), and FTP program, and others. I will create another thread in regards to what's out there, and how to use it at a later date.Q: uLaunchELF looks so bland. Can it be skinned?A: Yes! There are a number of skins out there. One good place to look is at PSX-Scene. Under Config, you can install it under "Screen Settings" then "Skin Settings".Q: Since HDLoader is available as an ELF, does that mean I can play PS2 games w/o a modchip?A: Yes, for the most part. Some games don't work well on the hard drive though. You also need a way to be able to FTP games into the drive itself.Q: I have another question...A: Feel free to PM me and I'll help you as best as I'm able.
