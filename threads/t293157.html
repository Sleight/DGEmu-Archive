---COMPLETE
'CoLT' ('FireFox' Extension) - Adds an extra item to the right-click menu bar which allows you to copy a link in several ways, BBCode (this is what you will mostly use), HTML Link, etc. This extension is VERY useful for when you do the Reviews especially and other things like linking a person to a topic, etc in the forums. Instead of typing out:

'iMacros for Firefox'

you right click the link, select 'Copy Link Text and Location As' > 'BBCode'. Now go to where you want to paste it and go Ctrl+V (Paste) and it inserts the BBCode for you.If like me you don't think you need the other options and just want BBCode you can get rid of the other options, in 'FireFox' go to 'Tools' and select 'Add-Ons'. Find 'CoLT' in the list and press the 'Options' button. Select the option you want to get rid of and click the 'Remove' button, or if you still want the other options you can use the 'Move Up' and 'Move Down' buttons to change their order in the menu.

---INCOMPLETE
'iMacros for Firefox'
(FireFox Extension) - An easy Macro making tool you can use to quickly open up Fast Reply, type something in (Hello Message, DP GP Message and Failed Download Message are popular S&S topics and Hello topics that I have made macros for) and if you want you can make it post for you too.

---INCOMPLETE
'Split Browser' (FireFox Extension) - While I haven't used it myself just yet this looks like a nifty tool. Just as it says on the Add-On page, "This splits the content area of the browser window as you like. It will help you in various cases. For example, to compare multiple webpages..." so it makes it easier to compare multiple webpages instead of having to click the tab to change each one.

Another similar extension is Split Pannel

---INCOMPLETE
'AutoHotkey' ('Windows' Program) - Similar to 'iMacros for Firefox' only more complex. When answering emails a new window opens, this new window can't open up 'iMacros for Firefox', so this is the program needed in the case. 'AutoHotkey' features several tools in one actually, it has a recorder which it records your movements (both keyboard and mouse!), once that is recorded you save the actions as a folder *.ahk (short for 'AutoHotkey'), you then use another program in 'AutoHotkey' that converts that file to an *.exe (Executable Program), now it is a program you can run, to make it even easier you can paste a shortcut of that *.exe on your Desktop and in Properties you can put a 'Shortcut Key', since this is DGEmu I use 'Ctrl+Alt+D', that way you press that combo and BANG, the .exe kicks in and performs the task!

---COMPLETE
'Snap Links' (FireFox Extension)
- After installing the extension you may have to restart your browser an extra 2 times or restart you computer but this really is a great extension to have, in makes it so easy to now open up multiple links. For example in a forum there are several new topics and you want to check them all, press and hold the right mouse button (default setting) and drag, a green --- like box will appear and any links in that box will form little red boxes over the links, the number of links will be displayed at the bottom right of the browser. Let the button go and it opens up all the links in a new tab (default setting). Unfortunately if you are compulsive like me and click the right mouse button every so often as force of habit and the green --- box is very small it may get stuck, the green --- box is stuck even after letting the mouse button go, if this happens then you can no longer use this extension for the remainder of the session (until FireFox is closed or restarted).

---COMPLETE
'Update Scanner' (FireFox Extension) - A useful piece of software that allows you to track, in the background, a website that you are looking to be updated with information. If you want to know when a new ROM is released you can set this to alert you when something is posted (most likely a ROM but can be an announcement), or if you are waiting for a reply in a thread. You can adjust the time so it scans the page every 5 mins, 15 mins, 30 mins, 1 hour, 6 hours, per day or only when you choose Manual Scan. You can also choose the amount of text that has been added to update you on, if you don't want to be updated on short stuff that is say 10 letters long then you can set it so it doesn't.
