Chris_J_Pook: If your looking for a simple game to make I would go into one of these categories...1. A map game: Basically with bmps in a windows app or just an ASCII map in a console app, you can make a game register your location, whether your trying to move into a blocked spot, and display all this on the screen. You should design your character stats to be held within a class so when you enter the battle function you pass it two character objects. This is one of the longer "simple" games to make. It takes about 30-50 hours for a very basic game. Most of this time is spent coding the interface.2. A puzzle game: Something like memory, see-then-do, or tic-tac-toe. I would strongly recommend only implementing the ability to go vs. another human to begin with, be it a 2 player game. Then later implement a computer. This isn't quite as interesting as the map game but can be created in 10-20 hours. Most of this time is spent coding the check valid move function.3. A text adventure game: Just make your own data stored on the individual and a loop that displays status, gets input, performs action, and repeats. The text based adventure topic contains some sample code for such a game. The great thing about this game type is you can make a small game in about 2-6 hours. Most of the time spent is verifying your if/else/while statements.
