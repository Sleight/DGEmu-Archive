if you want to color a specific area of a sig, then Ctrl + Click the layer then and a color balance layer. the selecting of the area will automatically create a mask on the color balance layer.Another way is to use the render. duplicate the render and more it all over the sig untill it is covered, the highlight all the duplicated render layers ( in the layer panel) then right click and select merge layers. Next set that layer to overlay the apply a gaussian blur that would blur out all details from the render leaving jus the colors. if the colors are too light jus duplicate the layer.
