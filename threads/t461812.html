Shadow' post='4877151 wrote on Oct 13 2010, 04:40 PM:
I know nothing about the requirements to run a game server, but note that people, as far as I know, have only managed to put Linux and not Windows on these things, and they make netbooks look positively speedy.
Generally speaking game servers can run on MUCH slower hardware than the actual game since they don't have to worry about the sound, graphics, physics, etc... depending on the game. Most of them just keep track of the map, a timer, player score, and where all the stuff on the map is. What game servers they can run depends on what platforms the servers can be compiled for. If they are x86 only then yeah, you can probably forget it.As for other servers (HTTP, FTP, SSH, IMAP/POP3/SMTP, Telnet, etc...) many of them are cross platform and open source so they shouldn't be a big deal. I mean yes, it is still setting up a server so there will be at least a little learning if a person hasn't done it before but it is still something most people should be able to learn and do in under a day if they put their minds to it. And once a Linux server is set up you can pretty much just let it sit there and run unless there is something in particular that you want to change.
