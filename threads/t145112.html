Here is the FAQ:MAME FAQ: (written by djnforce9) About This Document: This is aimed towards new MAME users and getting them started. Therefore, it purposely overlooks several fine/advanced details and features. For information on that, please consult MAME's Official FAQ.Q: What is MAME?A: MAME is a computer software program for personal computers. The purpose of MAME is to faithfully and precisely emulate as many arcade games as possible, with the intent of preserving gaming history and preventing vintage games from being lost or forgotten. The name is an acronym for Multiple Arcade Machine Emulator.Q: Where do I find the emulator for MAME roms?A: Download it from Mame's HomepagsQ: How do I use Mame roms?A: The absolute simplest way to play MAME roms is to:Extract the .zip file and place it in the roms directory (e.g C:\MAME\roms). It MUST be in the designated roms directory or else MAME will not recognize itCreate a "shortcut" to MAME and add the rom name at the end of the shortcut's "target" (e.g. C:\MAME\mame.exe simpsons.zip)Double click the shortcut whenever you want to playNOTES:You may also launch MAME from a command prompt, but it is not recommended as you'll have to type a command every time you wish to run a game. Steps 2 and 3 can be skipped if using Mame Plus! or a frontend (See below for details)Q: How do I adjust settings such as game controls and dipswitches?A: Press P while in-game to pause and then press the TAB key to enter the configuration menu. Do what you need to do and then press TAB again to close the menu followed by P to resume gameplay.Q: How do I adjust settings such as video resolution and audio sample rate?A: Those settings must be entered as part of the command line string. Consult this document for full details.Q: I hate the command line aspect of MAME and/or making dozens of shortcuts for each game. Is there a more user friendly version?A: You are in luck. There is in fact 2 solutions to this problem.Solution 1 (Recommended): Get the windows port of Mame. It is both user friendly and fully configurable. The name is Mame Plus!Solution 2: Get a MAME frontend. Frontends will provide you with an interface while their back end generates and executes the command line string for you. There are plenty of these available so pick your choice.Q: Games like "Gaunlet Legends", "Area 51", and the "Beatmania" series don't work!! What do I do?A: Certain MAME roms require CHD files. A CHD file is a compressed image of the hard drive used in an arcade cabinet. Hard drives are used in arcade games because of the huge storage available on them (potentially gigabytes!).Q: What ROMS require CHD files?A: Here's a list (from MAME v0.106u10):area51 (Area 51)area51mx (Area 51 / Maximum Force Duo v2.0)a51site4 (Area 51: Site 4)btltryst (Battle Tryst)btchamp (Beat the Champ)bm1stmix (beatmania)bm2ndmix (beatmania 2nd MIX)bm4thmix (beatmania 4th MIX)bm5thmix (beatmania 5th MIX)bm6thmix (beatmania 6th MIX)bmcompmx (beatmania complete MIX)bmcompm2 (beatmania complete MIX 2)bmcorerm (beatmania CORE REMIX)bmdct (beatmania f.
