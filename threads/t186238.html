SC file!", follow this link for a solution.Latest NewsFollow the instructions here to play The Legend of Zelda: Mugen no SunadokeiSlot-2 Supercards now support cheats with new firmware and patcher!The SuperCardThe SuperCard (commonly referred to as 'SC') is a flash cart that reads off common types of flash memory like SD and CF. Because of this, you can have an unlimited amount of storage as long as you buy more memory cards. The SuperCard is plugged into Slot-2, or the GBA game slot. To execute DS data from the GBA slot, the DS will need to be flashed (guide here) or you will need a passme device such as PassCard or SuperKey. However, if you are running the SuperCard in GBA mode (eg. for GBA games) then no passme device is required. The SuperCard CF and most SD models work on the GBA as well. No passme device is necessary to run ROMs on the GBA.Official SiteSuperCard PatcherGetting started...Now, at the official site, there are instructions on how to use the patcher (here). Unfortunately, the SuperCard is made by Chinese people who don't really know English, so it is slightly illegible (and out of date). For your convenience, I have put a legible copy below.Requirements:Patcher Software (latest is version 2.63 beta + firmware version 1.83): Official site: http://eng.supercard.cn/download.htm (select your SuperCard model) SCDev.org: http://scdev.org/index.php?cat=downloadsWindows 98 or above.InstallationAfter downloading the files, unzip them into a folder. Depending on your version, you'll get different files.SC-CFAfter unzipping the rar file, you should have 2 files: setupnewV258.exe and cf_170.bin. Run the setup file to install the patcher onto your computer. Put the .bin file onto your flash cart and run it just like a game. This will upgrade the firmware of your SuperCard.SC-SD / SC-MiniSDInside the rar file are 2 files: setupsdV258.exe and sd_170.bin. The setup file installs the patcher onto your computer. The .bin file should be put onto your flash cart and executed. This will upgrade your SuperCard so it works with the patcher.SC-Lite (MicroSD)Unzip the rar file to get 2 files: setupmicrosdV258.exe and micro_eng_170.bin. Run the setup file to install the patcher. Execute the .bin file on our flash cart to upgrade the firmware of your SuperCard to the latest version.SC-RumbleWithin the rar file are 2 files: setuprumbleV258.exe and UPGRADE.scu. Install the patcher using the setup file. Put the .scu file onto your SuperCard. The next time you start your DS, it'll run automatically. This will upgrade your SuperCard firmware.SuperCard DS(ONE)Download the OS files, unrar it and put everything straight onto the card (not in a folder).Download the "Saver Size Database" and put into the "SHELL" folder on your microSD.Patching is optional, but if you wish, you can download the patcher and install it. The setup file is called setupdsV258.exe.Slightly more detailed instructions hereWhen installing or upgrading the firmware, just follow all the on-screen instructions.Note: You cannot upgrade the firmware to another language, eg. if you have a SuperCard with the Chinese firmware, it won't allow you to upgrade it to the English firmware. Chinese downloads can be found here. You don't need to know Chinese; just click the link at the top (with the latest date).Usage - Optional for SuperCard DS(ONE)Run the SuperCard software. The first time you do so, you should click on the Options tab and select the output path. This is the folder where the patched files will be created. The box is named Out Path.Now you can go back to the Game List tab. Click the Add button, and a dialog box pops up. Select your games (you can select multiple games by holding down the Ctrl key) and click OK. All those games will be patched. Don't worry, those files will remain untouched, a patched copy of each game is created in the output directory you previously selected. Because a copy of the game is made, this means you must have free space more than the size of all the games you're patching.If you accidentally added a game you don't want to patch, click the obscurely named Del button which removes the game from the list only. It does not delete the actual game file.Double clicking a game (or Right Click -> Properties) brings up the properties box.DS game propertiesSaver patch: selecting "DS card" means the game will write your save data to a real cartridge. This means any data in your cartridge will be deleted. Selecting "SD Card" or "CF Card" will mean the game writes the save data to your memory card.ROM Position patch: selecting "Super Card" means the SuperCard will copy the entire game into its RAM (30MB only, not 32MB as most people think). This means faster yet smooth gameplay, but takes longer to load. Selecting "CF card" or "SD card" means the game will run directly off your memory card. Selecting this option is better as long as you select "Faster Play Game" option (see below), because the game will run at same speed (albeit not so smooth, but barely noticeable) and load faster.Enable Restart: If this option is checked, you can jump from the game back to the SuperCard menu by pressing A+B+X+Y+L+R together at the same time. Deselecting this option increases compatibility, but only a few games need this deselected. This restart does not reset some variables which may cause games loaded after this restart to not function correctly.Enable Trim ROM: Reduces the size of the ROM so you can fit more games onto your memory card. However, some ROMs with WiFi capabilities are incompatible with this option. Check the compatibility list at dualscene.net (see Resource A below) to see whether your game will be affected by this. Recommended.Faster Play Game: This option allows the game to skip frames in order to keep up with the actual speed of the game. Recommended at all times. Some games may be incompatible with this option.Enable DMA Mode: Allows the SuperCard to read off your memory card faster. Is supposed to increase compatibility. I have never tried it myself.iQue Game: Select this if the ROM is for the iQue DS. Highly unlikely you will need this option.Enable GBA Union: Used for games where having a specific game in the GBA slot plus a game in the DS slot allows extra content in the game. Slightly more detailed instructions here.Enable patch Cartridge access: Recommended. Higher compatibility rate.GBA game propertiesEnable Save: allows you to save the game from SRAM to your memory card. When saving a GBA game, you must press L+R+A+Select after a normal in-game save to write the save contents to your memory card.Enable more saver: allows you to have up to 4 save slots. Never tried myself.Enable saver patch: exactly what it says.Enable Real Time Save: allows you to do real time save like in VisualBoy Advance. Key combination L+R+B+Select sets it off. Real time save takes a long time and consumes a lot of battery power.Enable more Real Time Saver: supposedly gives you up to 4 save slots.Use external IPS File: use this to apply different IPS patch to the file while patching for the SuperCard. More here. (thanks felix)Enable Compress: has been disabled since version 2.55c.Enable restart: same as DS game restart.Add coercive Restart: no idea (help please!)Enable add text file: you can patch a walkthrough into the game so you can read it while playing the game. Use the key combination L+R+B+Start to view the file. (thanks felix)Enable cheat: exactly what it says. As of version 2.56, the cheat files are no longer in Chinese, but in English. You don't need to set any of the cheats here. You set them in-game by pressing L+R+A+Start to enter the cheat menu.Once you have selected your options, click Out and wait. When patching has finished, a little dialog box pops up saying "Complete!". Close the patching program.Copy ALL the files in the output directory onto your memory card. Put the memory card into the SuperCard, the SuperCard into the GBA slot, and run. Question about the SC MiniSD. What is the purpose of the backup battery other than to tell it from the fake ones? Since the MiniSD card is removable, I'm assuming it saves the game data on there? Or is it only the roms?
The backup battery is there to keep data in the RAM for longer when you turn off the power, making QPC (quick power cycle) saves easier. QPC saving is where you turn off the power then quickly turn it on again before the SRAM data is lost, and saving that instead of doing it in the game. Used mainly for GBA games.

Pphoenix121Mar 15 2007, 06:38 PM
No. It doesn't work on slot-2 flash carts because it needs a RAM expansion which coincidently goes into slot-2 as well. The only way to run this using flashcarts is to use a slot-1 flash cart and put a patch on a slot-2 Supercard or M3 (both which have RAM) and use that as the expansion pack. Otherwise, no.EDIT: of course, you can also use a slot-1 flashcart + real RAM expansion pack combination.So in total, there are 4 different combinations:Slot-1 flashcart + SupercardSlot-1 flashcart + M3Slot-1 flashcart + actual RAM expansionactual game cart + actual RAM expansion
