The Wii Console uses an interesting method similar to DG to handle downloading software. They use points that the use can purchase in packs of 10. The thing that makes them very interesting is that when you 'purchase' an item with Wii Points, your account is flagged as having 'paid for' that item. So now, say you delete the item, or your Wii breaks, has to have the system wiped, whatever. Then you can download it again for free, because Nintendo tracks which games you've purchased and allows you to re-download for free.The obvious parallel would be to make it so that when someone pays in DP to download an item they can download it as many times as they want, they would be limited to once a day to prevent idiotic wastes of bandwidth. But it would probably solve a lot of disappointment and issues where downloads stall, fail, or say an internet connection dies.

QqcarachatoApr 16 2007, 01:30 AM
Larger donation already gets more DPs:http://www.dgemu.com/forums/index.php?act=...&pid=886308US$5 = 250 DPs, while US$50 = 4250 DPs.Just like BR (Black 13) and Firebat pointed out, the main problem of allowing members to download the same ROM a 2nd, 3rd, , 7th, 1000th time is this would possible kill the site's month bandwidth quota.DP system is here to "limit" bandwidth usage.We don't "charge" members for downloading the ROMs. We "charge" them for consuming server's bandwidth.Like I said before, we don't really care if member is getting a ROM to use it only once or a lot of time. We don't even care if member gets a ROM, burn it to a CD-R, then go play it into multiple computers. And we don't care what ROM member gets (good, bad, amazing, awful). We just care about the amount of Bandwidth member consumes when they download. We just don't allow "free unlimited" download because bandwidth usage is not free.So, if you use up 1MB of server's bandwidth, you're "charged" 1DP. If you download 6x 10MB ROM, you're "charged" 60DP. If you get a 20MB file 3 times, you're "charged" 60DP, as well. Note that to us, that doesn't matter if you got 60MB of "unique" data (6 differente ROMs) or 60MB of same data (3x same ROM). On both case, you've transfered 60MB of data from the site's server to your computer.
