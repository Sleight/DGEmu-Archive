Installing and Using POPSLoader on 6XX PRO-B CFW

POPSLoader increases the compatibility of PSX games on the PSP, by allowing you to run PSX games using "POPS" from different firmwares. As POPS are the things in each firmware which allow the PSX game to run on that firmware, if you have a game which will not work on yours you can simply load the POPS of another through POPSLoader!

Installation: **Before you install POPSLoader, make sure that you are running at least PRO-B8 CFW**
1. Download POPSLoader through this link: http://ge.tt/9fEejB7?c. Be sure to download the correct file - the X00X one is for all models except the Go. Extract the files from the RAR archive using 7-Zip or WinRAR. Place the files in the root of your PSP's memory stick/internal memory for the Go ("root" here means "not inside any folder").

2. Unplug your PSP from your computer. Load the CFW on the PSP (for those running non-permanent CFWs), then launch the POPSLoader Installer inside the Games menu.

3. Press X to begin installing, and then wait patiently. The installer will do everything for you, but it might take a few minutes.

4. Once it is done, it will automatically exit to the main PSP menu. You can now delete the PBP and Installer files from your PSP's memory stick/internal memory.

Usage:
Hold R to choose the POPS as you load your PSX Eboot. You can find out which POPS to load on which game through the compatibility list here (find your PSX game, then look at the Notes column).

Note that some POPS do not work on some models of the PSP:
All POPS work with PSP 1000, 2000 and 3000 3g

PSP 3000 4g and 9g:
All POPS from 3.02 to 3.52 work
POPS from 3.71 to 6.00 do not work
All POPS from 6.20 onwards work

PSP GO:
All POPS from 3.02 to 3.52 work. Sound only works with Headphones though.
All POPS from 3.71 to 6.00 do not work
All POPS from 6.20 onwards work
