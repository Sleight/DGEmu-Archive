MmouseMay 06 2014, 08:49 PM

Have you tried getting into the backend of your router using the tablet? Look up your router type on this website to find the router's IP address, then type that into the URL bar. It will probably ask for a login and password, which usually defaults to something like admin/admin or admin/password. Depending on what type of router you have, it might have a menu option in the backend that will tell you what the router password is, or there might be an option to reset the password.

 

Edit: Actually, that website I linked to also has the default user name and password for some routers.

Guest_Strait Cougar wrote on May 07 2014, 01:42 AM:

To meru, yea if you don't use WEP/WPA even though WEPs are so called easy to crack, the person would have to be already equipped with proper tools and would have to have internet to get information and obtain of said tools.

WEP should be avoided, since that's just making is easy for people to gain access. I personally have a router with WPA2 security setup for main connections, and an alternate guest session with WEP so that people that come over can at least use Internet without accessing anything on my network.

 

Protecting your admin page with another password is another layer of security to help stop the person from going further.

 

And lastly, if you're really paranoid, you can always setup a ban on all devices except the white listed MAC addresses. That's the most secure way, but really painful to do.

One of my co-worker setup his router with no wireless password, but full MAC address filtering, so whatever is not white listed won't be able to connect.
