Which ROM ? 1,2 or 3?I'll assume that it's either 1 or 2: Extract the ROM from the zip (if you haven't already done so). Check your folder options (the folder that contains the rom) to see whether it's read only.(Right click > Properties. If 'Read only' is checked, Uncheck it. If it prompts you to apply changes to all subfolders and files, do that too.)If you have an SAV file in the folder, delete it. What emulator are you using? If you are using VBA, set the save type and set it to automatic (Although it is automatic by default)If you are not using VBA, Switch to VBA
