A rundown on how the Friends Roster will work with the Nintendo Wi-Fi Connection. Nintendo of America's newly launched website regarding the Nintendo Wi-Fi Connection contains new details regarding the process by which users can add friends to an existing Friends Roster. When the service debuts on November 14th, 2005, users will first insert a Wi-Fi enabled game into the Nintendo DS and connect to the network. The process by which you can determine your own unique twelve digit Friend Code varies per Wi-Fi equipped game. Details regarding the nature of the process can be found in the game manual on Nintendo's official web site for the service. For Mario Kart DS users first connect to the service by tapping "Nintendo Wi-Fi Connection" on the title's main menu. From there, they select "Friend Code" where twelve ten digit number can be found. Once this is established, users can then trade Friend Codes with others in multiple ways. Message boards across the internet have preexisting threads for their members to post their code once they are set up for the Nintendo Wi-Fi Connection. To play online against readers of the Advanced Media Network and even staff members, access our forums here. Other ways to obtain friend codes include email, phone conversations, or in person. In addition, if users wirelessly connect to others through multiple cartridge multiplayer modes, these people will automatically be added to each other's Friends Roster. Several important notes arise in regards to the Nintendo Wi-Fi Connection. For starters, those who utilize the service are forced to manage their Friends Roster, as a limit of 36 friends has been implemented. If the limit is exceeded, friends are randomly replaced by the service. To prevent potential loss of friends, some forthcoming games are set to incorporate a "lock" feature which will prevent a friend from being replaced. More importantly, Nintendo has issued a warning for those who may potentially use the online service. The Nintendo DS and the individual game work together to allow users to access the network. As such, if someone uses their game card on another's Nintendo DS to access the Nintendo Wi-Fi Connection, the system may potentially erase all the online information on the game card. It is strongly recommended that users do not play Wi-Fi enabled game's on anyone else's Nintendo DS system. Stay tuned to the Advance Media Network as we are compiling a complete FAQ pertaining to the Nintendo Wi-Fi Connection to be released before the service launches early next week.
