*BUMP (the thread bumping feature doesn't work XD )* After a few weeks of reflexion, I have come up with a new set of rules and I would like to replace PS' rules, which doesn't cover many points. Comments are welcome. If no one has objection, I would like to modify the competition forum rules.___________1. Posting RulesAll forum rules apply in the Competition sub-forum, especially:Don't make overly short posts even if the answer needs only one word.Don't flame others because their questions/answers are silly or not in your taste.Don't go off topic.2. Rules for Quiz MakersHere are the set of rules to follow when you want to run a quiz:Before starting a new quiz, please make sure the subject has not been done before.Don't pick a subject that is covered by a more general one, that is don't create a sub-quiz of existing ones.Make sure to include a score board.Quizzes are meant to be long running so that make sure to update them regularly.If there has been no reply in a quiz for more than two months, then it is considered as dead and can be overtaken by others wishing to continue it.If you want to continue a "dead" quiz, PM a moderator (preferably KV or myself) to ask for their permission.3. Rules for ContestantsFor members who answer quiz questions, please follow the following rules:Answer the current question, not the first.Don't reply with the same answer that a previous post already stated.If you don't agree with an answer, PM the quiz runner.Make sure to stay on topic.Anyone who doesn't follow the previous set of rules are subject to point deduction and warning.Thanks for your attention.
