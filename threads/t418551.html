Not really sure if this is the correct place to post this, so please move this topic if necessary. This is a hack that I have made for Harvest Moon: Island of Happiness that I call GxG, which has two meanings. As said in the topic description, this is a gender swap hack (One that works differently than the AR code), in which I made for fun and was inspired by a topic I read some time ago about sprite hacking Harvest Moon: Friends of Mineral Town in another forum site that I visit. I also made this hack because I've always wanted to try playing as the girl in HM games, but felt weird about trying to woo guys. This gender swap hack allows you to marry the person of the same gender as you. This is done by swapping the sprites but not the gender system, which the AR code does. There are still a few minor bugs (Mostly graphic related and some minor text) but nothing that should be stopping you from progressing, as far as I have tested with my save file. To find out more about them, just read the readme file I've included in the zip archive. A list of changes this patch makes and instructions on how to use the patch is also in there as well. Anyway, enjoy!Harvest Moon: Island of Happiness GxG PatchScreenshots (Taken while running the rom on No$GBA):Talking to Natalie as the girl sprite.A minor name and text hack of the supposed guy in the Assets menu. Girl picture is still present though.

This is because the islander sprites don't have their own tool using sprite, which would mean you'll have to make one yourself if you want the sprites to be perfect.
