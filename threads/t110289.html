AatomicknightFeb 21 2006, 12:59 AM
quefflung' post='1093807 wrote on Feb 20 2006, 03:42 PM:
If you use both sometimes the game spazzes out. Game states are cheating.
There is no reason for the game to "spaz out" if you use both types of saves. State saves are saved in SG_ files while in-game (battery) saves are saved in SAV files. They have absolutely no connection and therefore are completely unrelated.I personally use game states almost all the time because they are much more convenient - I can simply press 2 buttons and then close the emulator without having to navigate through menus and waiting for the data to be written. Also, some games only allow saves at specific points, so if you're midway through something, you'll have to start over from the start of that level (e.g. Minish Cap).In-game saves are still useful when they're available though.
