SShidou MariyaJan 09 2011, 07:19 AM
To sum it up and reiterate basically some of what others said:Unmountable boot volume simply means that the volume of which it's trying to load Windows is corrupted, either a file corruption caused by software or hardware.In the worst case scenario, it is a hard drive failure of which in that case will require you replacing the hard disk. (This is easily determinable with an extended SMART test)On the other hand, if it was simply a software issue, Huang's solution to reach the recovery console with XP or the system recovery options with Vista or 7 and run either the command to simply run a check disk or a boot sector repair.
