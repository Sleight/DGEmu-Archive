Maxoxpower' timestamp='1329280369' post='4991826 wrote:
can i run a snes or gba emulator better with my 3ds ?
No, at least, not now. The 3ds has been "hacked" but only the ds capabilities are available. Therefore, for now, the 3ds will only be capable of running ds homebrew for the moment. Further down the line however, you can expect the 3ds to be fully hacked and the homebrew from the system will also benefit from this, because the 3ds has more processing power and arguably can run snes games much better. Personally I wouldn't bother trying to run snes or gba roms on your 3ds or ds yet.There's one exception though. The dstwo, a ds flashcart that also works for dsi and 3ds, has a cpu built into the cartridge itself. The cpu makes it capable of processing more data and developers can get a development kit for the flashcart. This makes it much easier to make emulators for the dstwo. There are a dedicated gba emulator and a dedicated snes emulator for the dstwo. They run the games at acceptable speeds and only a few games will give you trouble. The price for a dstwo can be steep though, they are around 50 bucks.
