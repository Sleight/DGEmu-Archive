If any of you are having troubles with Worms Open Warfare 2 this solution seems to work for most people.(Cannot access save data. Turn off power and reinsirt DS card)First, extract the .nds file you downloaded. (Then, preferrably make a copy if the next few steps doesn't work)1. Get DSLazy here:http://l33t.spod.org/ratx/DS/dslazy/dslazy.zip2. Get the Arm7.bin file herehttp://files-ds-scene.net/triforce/arm7.bin3. Extract DSLazy and start it. Browse and choose the correct .nds file.4. Click NDS Unpack, you will get a new folder, called NDS_UNPACK or something like it.5. Overwrite the arm7.bin in that folder with the one you downloaded.6.
