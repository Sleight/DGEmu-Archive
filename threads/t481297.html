DdeelunaSep 04 2014, 03:49 AM
I'm surprised nobody suggested booting back to the old windows (on the HDD) and looking at the system profile. You know, if the system was running fine before the install of the SSD. That way you can compile a list of the devices you were using and what was needed... though if the computer isn't a custom build PC (does anybody use those here?) such as a Dell or HP then just look up your model number or in some cases the service code on the manufacturer's website and it should give you a list of drivers and possibly firmware updates. Might also be useful for custom jobs if you know your motherboard. You know, since you already installed to the SSD unlike imaging like Meru suggested.

also for booting windows within windows... not sure if it would work but there is VMware, Vitural box, Microsoft's own Virtual PC, and QEmu... never tried actually booting a legit drive before but in theory it could work, but you'd likely find that even if it did work that Windows on the HDD would scream bloody murder because the "Hardware" isn't the same profile as it was installed on.

as for suggestions as to how to use an SSD >.> anything that you read and especially write to often, or don't need to be fast, put to the HDD... I like to install my games to HDDs to reduce write cycles on the system drive though. It really depends on the game. I mean ROMs and emulation definitely on the HDD because I abuse save states, but for games that I can adujust the save game folders I would do my best to keep the save game folders to the HDD because alot of those games (especially the ones that auto save) will chew up write cycles like crazy.
