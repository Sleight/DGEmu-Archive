Dunno why nobody knows about this, but there is a really handy tool that's called NDSexlorerEX. It has been made a while back and the developer disappeared quite a while ago, but this is a really good tool to organize your roms with. It has a lot of features that can all be accessed from windows explorer:- Shows rom's icon- Shows info of the rom as a tooltip (hovering over the file)- Trimming AND un-trimming roms on right-click- Renaming roms by using the rom's details on right-click- Trimming/untrimming and renaming can be done in batchesI have been using this for a while and it works like a charm :) . It comes in two flavours: 32-bit and 64-bit (note: x86 is the 32-bit version). Odd thing is though that I couldn't get it to work on my windows 7 64-bit desktop, while it works perfectly on my laptop that runs on windows 7 64-bit...Linkety: http://gbatemp.net/t272486-nds-explorerex

A tool that I have been working with for many years is called Romcenter.It manages any kind of rom, whether zipped or not. You will first need the application found here:http://www.romcenter.com/On their site, they will provide sub-sites that offer DAT files to load with the application to rename all your roms.That being said, there are DAT files being updated not only for DS roms, but for all sorts of consoles. This tool comes in especially handy when you're an arcade rom collector such as myself, since rom naming is important for it to work.Note: If you use Kawaks for NeoGeo, CPS1, and CPS2 emulation, the emulator has a DAT generator for Romcenter integrated inside.
