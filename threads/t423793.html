DJ Night Force 9' post='4420626 wrote on Nov 7 2008, 03:20 PM:
I'm not sure if this actually runs a full search query in the same sense as it appears to work very quickly when compared to doing a conventional search. It also only returns a very limited number of results.
I'm not so much worried about the number of results as the number of times the query is being run. All types of searching for "similar" topics requires using LIKE (or MATCH AGAINST - this is likely why it seems very quick on those forums, as fulltext indexing would bypass the problem; we use InnoDB though, so that's not an option). If you're using LIKE with a wildcard on the left side of the argument, you're going to be using expensive table traversals on every topic view, which is definitely not going to be good. You could arguably cache the results (i.e. sacrifice freshness for performance), so that could be a possible solution. The relevancy of the topics chosen depends on the keywords though, and without an ontological map, those links would likely not be effective.
