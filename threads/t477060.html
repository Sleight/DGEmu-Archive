KKirie MotobaJul 10 2012, 08:18 PM
Consoles:
- A device where all the hardware is set standard, so you will never have a game that won't work here or there because you're lacking specs, or have a bug with these drivers and other such.
- A device easy to make more money off accessories: controllers, cameras, storage, etc.
- Slightly more control over piracy (though we can see how that fails in some departments, especially in the Wii)
- Method of forcing people to buy games that was published for x console, publishers and console maker win-win. (Publisher pays for licensing of game on console, probably SDK, testing units, etc, console maker gets more people using console, purchasing accessories, money from publisher for rights to run software on console, etc)

All in all, consoles = perfect for companies to milk money out of consumers.

Also, nowadays, you can built a very very decent PC for $600 to run most things. But people still prefer paying 200 for a console than 600 for a PC, even if it does more. Instead, they go with shitty budget PCs for like 300 or 400, and end up paying the same without realizing.
