There are no merits or rewards or anything like that (but we can keep a point system up to make things more interesting). We are all Touhou fans with at least one common interest, right. Running the main games and attempting the impossible bullet hell that make the series so famous. So my suggestion is this:

1. Post an introductory reply or anything that says you're joining in on the fun (serving as registering to compete). I'll edit this post every time someone new joins in and include a number with their name (since I started, I'll be number 1, then the next person is number 2, then the next number 3 and so on).
2. Every week the next person in the number list will post the next challenge. In the event that they don't post, I'll post a challenge in their place.
3. The challenges can be for any of the Touhou games (no fangames though). Example of challenges can be:
Breaking a certain spellcard.
Getting a certain high score.
Beating the game without continuing with a specific character.
Outlasting a certain spellcard without shooting.
...dunno what else.
4. Before stating the challenge, say which game the challenge will be for and for what difficulty setting (Easy, Normal, Hard, Lunatic, Extra)

That's about it, I guess. So I'll wait on you guys to say if you agree with the challenge or not. If it's a go, I'll set a starting date and initialize the list of players. If not, tough luck, lol.
