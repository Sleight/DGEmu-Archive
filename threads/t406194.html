Some reminders, some unique, some universal.Genesis screenshotters, make absolutely certain your aspect ratio is 1:1, your screenshots should all be either 256x224 or 320x224 sometimes a game will use both. If your window height is not 224, then your window is not the correct size. If a shot's width is not 256 or 320 then your window is not properly set.Genesis screenshotters, make sure emulator messages (shot #5 was saved. state #2 saved. state #0 loaded.) are not in the shot. Chances are you will still get a pass, but your shot will look nicer without such messages. This to my knowledge only applies to Genesis shotters because Gens the emulator we're using is silly about taking shots of things in the Gens window.Game Boy sets, set the emulator to emulate the Game Boy used to automatic, Game Boy Advance, or Game Boy Color. We will allow Game Boy Color games being played in monochrome to go through, but it would look nicer to use the highest compatible settings.Before you start downloading from your set, check all of your games for the following. A genre. A title screen shot. An in-game screenshot. If the game already has any of them, double check to make sure they are correct. This way, if they are wrong, you can inform a judge and we will delete any incorrect shots.You may get a set with multiple copies of the same game. Do not simply download one copy and use the same shots for all of the copies. Part of the blitz is to let people know if the game they are going to download works.
