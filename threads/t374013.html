Basically, ZEP is a full replacement for the language.ini and global.ini files for the DSOne's firmware.Download available from: http://www.scdev.org/forum/index.php?topic=12238.0
someone wrote:
FAQ:Q: What does this mod do?A: This mod consists of 2 files, Language.ini and Global.ini.Language.ini is the file which tells the MoonShell softwarewhat to display in menus etc. The Supercard Team, havingwritten a Chinese Language.ini file, decided to make an English version of it. Unfortunately for us they did a poorjob with translation and much of it ended up looking like"Chinglish". Basically, my Language.ini file is a completerewrite of the Supercard Team's version, but in properEnglish with better grammar, spelling, and punctuation.Q: How do I install it on my Supercard DSOne?A: Just download firmware version 3.0 SP1 for the regular DSOne,and install it. Then copy Skin.ini, Global.ini, and Language.inifrom the "default" directory, straight into /scshell, replacingthe old versions of the files.Q: How do I install it on my Supercard DSOne-SDHC?A: Using the same method as for the regular DSOne; except you needthe SDHC firmware instead.Q: I want to use ZEP in my own skin, how do I do this?A: Open /custom/Skin.ini for information on how to do this.Q: How much is changed?A: There are many changes; so what might be best is simply to read the changelogs.I'll put some screenshots up of the results soon.Q: What will the Language.ini file do?A: The Language.ini will make nearly all dialogue and text far easier to understand.Please note: This does not actually change the way the Supercard works, or actuallychange any of the programs themselves. It merely changes the wording of the dialogues,for example the "SetNext" window has been renamed to "Playback mode" to more accuratelyreflect its' purpose.Q: What will the Global.ini file do?A: The global.ini file contains the large majority of the settings for MoonShell andis actually a very useful file. These settings include menu text positioning, andbecause I changed the names of the menus from(Saver || Other || Options || Help)to (Savesize || Special || Options || Help)the first and second menu names are now longer.As a result the menu looks off-center and the spacingbetween the menu names is off. My global.ini file fixes this,and moves the menus to their proper positions.As an added bonus it adds OGG support.[Please note: When playing an OGG file, opening a video, image, or text file causes a crash. I'm looking into this issue, but as a simple solution: Press B before opening a different file!]Q: What are some of your other goals for this project?A: I aim to add documentation to the Supercard's INI files.While the Supercard Team already has documentation, it ispoorly translated and needs a complete rewrite to make it easyto understand. I also plan to make fully documented versions of the files to help people who want to make skins. These "verbose"versions will have far more information, not intended for actualuse as config files but moreso as "understanding" tools for theconfig files :PPlease note, you are completely free to use it, but...A) You must add a note to your skin.ini file to let your users know it uses ZEP.Example:"Name=Windows" becomes "Name=Windows with ZEP 1.01"B) It'd be appreciated if you have a note in your skin's thread saying it uses ZEP,maybe with a link back to this thread, and give credit where credit is due.Anyways, have fun!
[Also: I'll probably end up posting ZEP here, but atm I'd prefer to keep it at SCDev to make updating easier]
